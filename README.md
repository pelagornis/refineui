# RefineUI

RefineUI web represents a collection of utilities, React components, and web components for building web applications.

## Development

```bash
bun install   # or: pnpm install
bun run build
bun run docs
```

Workspace scripts detect Bun / pnpm / npm via `scripts/ws.mjs`.

## Design tokens (color · Alias · Semantic)

Figma Foundation is the single source; the chain is Primitive → Semantic (Alias) → Component Token → components.  
**Details:** [COLOR_TOKENS.md](COLOR_TOKENS.md)
