# RefineUI Design System & Component Library

> RefineUI is Pelagornis's unified design system. Foundation variables ship as `@refineui/tokens`; UI ships as `@refineui/react`. Docs render real components — not mockups.

## Installation & Setup

```bash
bun add @refineui/react @refineui/tokens
# or
npm install @refineui/react @refineui/tokens
```

Stylesheet (app root):

```css
@import "@refineui/tokens/tailwind.css";
@import "@refineui/web-icons/dist/fonts/refineui-system-icons.css";
@import "@refineui/react/refineui.css";
```

Or in JS:

```tsx
import "@refineui/react/refineui.css";
```

## Packages

- `@refineui/react` — Accessible React components (Tailwind + design tokens)
- `@refineui/tokens` — Color, typography, spacing, sizing, radius, elevation, motion, z-index
- `@refineui/utilities` — Helpers and layout algorithms
- `@refineui/web-icons` — RefineUI System Icons font (used by `WebIcon`)
- `@refineui/mcp` — MCP server for docs search, component pages, and design rules

## Usage notes for LLMs

- Import components from `@refineui/react` only; do not invent parallel APIs
- Use design tokens (`bg-refineui-alias-*`, `text-refineui-alias-*`, spacing/radius utilities) — no arbitrary px or hex in component styles
- Match Web Kit component scope; do not add variants or convenience props not in Figma Web Kit
- Prefer composition (`Field` + `Input`, `Command` + `CommandDialog`, `Sidebar` + `SidebarLink`) over raw HTML for forms, navigation, and feedback
