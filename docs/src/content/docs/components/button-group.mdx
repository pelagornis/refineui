---
title: Button Group
description: Button Group is not yet available in @refineui/react.
---

Button Group component is not currently shipped in `@refineui/react`.

For grouping buttons, use layout components like `Stack`:

```tsx
import { Button, Stack } from "@refineui/react";

<Stack direction="row" gap="sizeXSmall">
  <Button variant="outline">Cancel</Button>
  <Button variant="primary">Save</Button>
</Stack>
```
