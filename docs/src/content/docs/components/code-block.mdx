## Usage

```tsx
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopyButton,
  CodeBlockHeader,
  CodeBlockLine,
  CodeBlockTitle,
} from "@refineui/react";

const code = "export const ready = true";

<CodeBlock>
  <CodeBlockHeader>
    <CodeBlockTitle>status.ts</CodeBlockTitle>
    <CodeBlockActions>
      <CodeBlockCopyButton value={code} />
    </CodeBlockActions>
  </CodeBlockHeader>
  <CodeBlockContent lineNumbers wrap={false}>
    <CodeBlockLine>{code}</CodeBlockLine>
  </CodeBlockContent>
</CodeBlock>
```

Use `variant="highlighted"` on a `CodeBlockLine` to draw attention to a range.
Use `wrap` and `lineNumbers` on `CodeBlockContent` to control rendering without
changing the source passed to `CodeBlockCopyButton`.

## Actions and syntax highlighting

`CodeBlockActions` accepts `CodeBlockCopyButton` and ordinary RefineUI `Button`
components. That keeps application-specific actions, such as downloads and line
wrapping, under your control.

`CodeBlockLine` accepts any `ReactNode`, so a syntax-highlighting library can
provide tokenized spans directly. Keep the unformatted source in the copy
button's required `value` prop to make copying reliable.

The demo uses RefineUI semantic foreground tokens for its highlighted spans;
you can use the same approach or pass tokens from Shiki, as shadcn/ui does.

## API Reference

### CodeBlock and layout parts

`CodeBlock`, `CodeBlockHeader`, `CodeBlockTitle`, and `CodeBlockActions` accept
standard `div` attributes. Compose `CodeBlockHeader` and `CodeBlockContent`
inside the root; put the title and actions inside the header.
