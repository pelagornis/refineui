## Usage

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@refineui/react";

<Collapsible defaultOpen>
  <CollapsibleTrigger>Details</CollapsibleTrigger>
  <CollapsibleContent>
    Hidden until the trigger opens it.
  </CollapsibleContent>
</Collapsible>
```

`open` and `onOpenChange` make it controlled. `CollapsibleTrigger` renders a Button `ghost` by default (`layout`, `size`, and other Button props pass through); use `asChild` to merge onto a custom child. Closed content stays mounted and is hidden.
