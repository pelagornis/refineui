`DateInput` combines an input-style trigger, `Popover`, and `Calendar`. Selecting a day updates the value; the calendar stays open until you click outside it or press Escape. Set `mode="range"` to pick a start and end date across two months.

## Usage

```tsx
import { useState } from "react";
import { DateInput } from "@refineui/react";

const [date, setDate] = useState<Date>();

<DateInput
  value={date}
  onValueChange={setDate}
  placeholder="Choose a delivery date"
  locale="en-US"
  weekStartsOn={1}
  fullWidth
/>;
```

Use `defaultValue` for an uncontrolled field. `size="sm" | "md" | "lg"` uses the same control heights, padding, and typography as `Input`; it also inherits a surrounding `Field` size. Pass `error`, `success`, and `disabled` just as you would for an Input.
