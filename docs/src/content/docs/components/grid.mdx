`Grid` places children in columns. Use fixed `columns`, or `minItem` with a Foundation size for fluid auto-fit grids.

<div class="not-content my-6">
  <GridPreview client:load />
</div>

## Installation

<PackageInstall />

## Usage

```tsx
import { Grid, GridItem } from "@refineui/react";

<Grid columns={3} gap="sizeMedium">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</Grid>

<Grid minItem="foundationSize2560" gap="sizeLarge">
  <GridItem>Card</GridItem>
  <GridItem>Card</GridItem>
</Grid>
```
