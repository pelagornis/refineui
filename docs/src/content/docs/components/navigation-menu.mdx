## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuTrigger,
  NavigationMenuContent,
  NavigationMenuLink,
  Stack,
  Text
} from "@refineui/react";

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuLink href="/" active>
        Home
      </NavigationMenuLink>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Products</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/products/web">
          <Stack gap="sizeXXXSmall">
            <Text variant="bodyMd">Web</Text>
            <Text variant="bodyXs">Browser-based experience</Text>
          </Stack>
        </NavigationMenuLink>
        <NavigationMenuLink href="/products/mobile">
          <Stack gap="sizeXXXSmall">
            <Text variant="bodyMd">Mobile</Text>
            <Text variant="bodyXs">Optional supporting detail</Text>
          </Stack>
        </NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="/about">About</NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## Choose a panel layout

`NavigationMenuContent` remains content-agnostic and offers three Tailwind-backed
panel treatments: `dropdown` for compact trigger-aligned choices, `floating` for
a centered multi-column panel, and `overlay` for a header-connected full-width
product navigation layer. The application still owns the panel content and its
information architecture.

```tsx
<NavigationMenuContent>
  <NavigationMenuLink href="/components">Components</NavigationMenuLink>
  <NavigationMenuLink href="/tokens">Tokens</NavigationMenuLink>
</NavigationMenuContent>

<NavigationMenuContent layout="floating">
  <div className="grid grid-cols-2 gap-refineui-size-medium">
    {/* Compose a wider panel here. */}
  </div>
</NavigationMenuContent>

<NavigationMenuContent
  layout="overlay"
>
  <div className="grid max-w-refineui-navigation-menu-mega-width grid-cols-3 gap-refineui-size-xxx-small">
    {/* The consuming app owns categories and destinations. */}
  </div>
</NavigationMenuContent>
```

### NavigationMenuLink

Direct top-level links do not reserve space for a dropdown chevron. Every top-level item shares an 80px minimum width and a 28px minimum height, so typical labels remain the same size regardless of whether they have a chevron. Longer labels expand rather than truncate.
