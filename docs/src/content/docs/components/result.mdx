## Usage

```tsx
import { Result, ResultButton } from "@refineui/react";

<Result
  variant="success"
  title="Payment complete"
  description="Your receipt is ready in order history."
  actions={<ResultButton>View receipt</ResultButton>}
/>;
```

`Result` uses RefineUI System Icons by default. Pass `figure` to supply your own illustration, image, or icon. Use `ResultIcon`, `ResultTitle`, `ResultDescription`, and `ResultActions` for a fully composed layout.
