`TimeInput` combines an input-style trigger, `Popover`, and 140px fixed-height `ScrollArea` columns for hours and minutes. The active value stays centered while surrounding choices remain legible. A value is committed when its wheel settles, and remains selected if the popover is dismissed.

## Usage

```tsx
import { useState } from "react";
import { TimeInput } from "@refineui/react";

const [time, setTime] = useState("09:30");

<TimeInput value={time} onValueChange={setTime} minuteStep={15} hourCycle="12h" />;
```

Time values always use the 24-hour `HH:mm` format. Set `hourCycle="12h"` to show a leading, scrollable AM/PM column. `size="sm" | "md" | "lg"` matches `Input` and inherits a surrounding `Field` size.
