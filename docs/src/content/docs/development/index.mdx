RefineUI documentation is a **first-class consumer** of the design system — the same packages, tokens, and motion roles as production.

## Guides

- [Installation](/development/installation/) — add packages and load CSS
- [Theming](/development/theming/) — light/dark and token surfaces
- [Motion](/development/motion/) — CSS transitions vs motion runtime

## Principles

1. **Tokens only** — no arbitrary px, hex, or ms in component styles
2. **Real components** — docs render `@refineui/react`, never mockups
3. **Motion roles** — `fast`, `press`, `panel` via `--refineui-motion-*`
4. **Starlight = infrastructure** — visual language lives in docs-ui + RefineUI
