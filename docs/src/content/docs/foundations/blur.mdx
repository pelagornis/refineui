Scrim **tint** stays on `surfaceOverlay` / `--refineui-overlay-backdrop` (see [Opacity](/foundations/opacity/) and [Color](/foundations/color/)). Blur is the filter radius only.

`prefers-reduced-transparency: reduce` collapses Dialog/Drawer `backdrop-filter` to `none` in `refineui.css`.

## Usage

```css
.scrim {
  background: var(--refineui-overlay-backdrop);
  backdrop-filter: blur(var(--refineui-blur-overlay-scrim));
}
```
