Each step has two Foundation recipes: **Light** and **Dark**. CSS emits both, plus a theme-switching alias.

<div class="not-content">

      { use: "Dark only", css: "--refineui-elevation-8dark" },
    ]}
  />
</div>

Prefer the bare variable in product UI. Use `*light` / `*dark` when a surface must stay in one mode.

<div class="not-content">

## Usage

```css
.panel {
  box-shadow: var(--refineui-elevation-8);
}
```
