Foundations are the shared visual and interaction language for Pelagornis products. Product UI consumes **semantic tokens** from `@refineui/tokens` — not raw hex, arbitrary pixels, or one-off curves.

Layout primitives you compose in React live under **[Components → Layout](/components/stack/)**. System icons ship from **[refineui-system-icons](https://github.com/pelagornis/refineui-system-icons)** (separate from this docs site).
