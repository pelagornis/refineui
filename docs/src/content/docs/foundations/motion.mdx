Use **semantic roles** (`fast`, `press`, `panel`) — CSS `--refineui-motion-duration-fast`, `--refineui-motion-scale-press`. Do not write `150ms` or a one-off curve in a component. `refineui.css` already covers control hover and focus.

## Usage

```css
.control {
  transition: transform var(--refineui-motion-duration-fast)
    var(--refineui-motion-easing-standard);
}

.control[data-pressed] {
  transform: scale(var(--refineui-motion-scale-press));
}
```
