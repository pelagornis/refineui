`ButtonGroup`은 확대/축소 컨트롤이나 편집 / 복제 / 보관처럼 관련 있는 `Button`을 하나의 튜브 테두리로 묶습니다. 그룹에 `size`와 `variant`를 한 번만 지정하면 안의 Button이 모두 그 값을 따릅니다.

## 사용법

```tsx
import { Button, ButtonGroup, WebIcon } from "@refineui/react";

<ButtonGroup aria-label="확대/축소">
  <Button layout="icon" aria-label="확대"><WebIcon name="zoom-in" /></Button>
  <Button layout="icon" aria-label="축소"><WebIcon name="zoom-out" /></Button>
</ButtonGroup>;
```

## 예시

### Attached

기본값은 `attached`입니다. brand-subtle 트랙에 얇은 테두리를 두르고 그 안에 ghost 버튼을 담습니다. 테두리 모서리는 크기별 Button 반경을 따르기 때문에 안쪽 버튼과 동심원을 이룹니다.

```tsx
<ButtonGroup aria-label="캔버스">
  <Button layout="icon" aria-label="뒤로"><WebIcon name="chevron-left" /></Button>
  <Button layout="icon" aria-label="복사"><WebIcon name="copy" /></Button>
  <Button layout="icon" aria-label="잘라내기"><WebIcon name="cut" /></Button>
</ButtonGroup>
```

### Variant

`variant`(기본값 `"ghost"`)는 모든 Button에 전달됩니다. Button에 직접 `variant`를 주면 그 값이 우선합니다.

```tsx
<ButtonGroup aria-label="항목 작업" variant="outline">
  <Button>편집</Button>
  <Button>복제</Button>
  <Button>보관</Button>
</ButtonGroup>
```

### 선택이 아니라 실행

`ButtonGroup`은 동작을 실행하는 버튼만 묶습니다. 각 Button은 평소처럼 호버하거나 누를 때 반응하지만, 손을 떼면 선택 상태로 남지 않습니다. 눌린 상태나 선택이 유지돼야 하면 [Toolbar](/ko/components/toolbar/) 안의 `ToolbarToggleButton`을 쓰세요.

### 크기

`size`(`sm`, `md`, `lg`, 기본값 `md`)는 모든 Button에 전달됩니다. Button에 직접 `size`를 주면 그 값을 유지합니다.

```tsx
<ButtonGroup aria-label="확대/축소" size="sm">…</ButtonGroup>
```

### 세로

`orientation="vertical"`을 주면 같은 튜브 안에서 버튼이 세로로 쌓입니다.

```tsx
<ButtonGroup aria-label="확대/축소" orientation="vertical">
  <Button layout="icon" aria-label="확대"><WebIcon name="zoom-in" /></Button>
  <Button layout="icon" aria-label="축소"><WebIcon name="zoom-out" /></Button>
</ButtonGroup>
```

### 분리형

`attached={false}`를 주면 테두리 없이 작은 간격만 둡니다. 취소 / 저장 같은 버튼 쌍에 어울립니다.

```tsx
<ButtonGroup aria-label="폼 동작" attached={false}>
  <Button variant="outline">취소</Button>
  <Button variant="primary">저장</Button>
</ButtonGroup>
```

## 키보드

각 Button이 각자 Tab 정지점이고, `Enter` / `Space`로 실행합니다. Tab 정지점 하나에 방향키 이동이 필요하면 [Toolbar](/ko/components/toolbar/)를 사용하세요.

## API 레퍼런스

### ButtonGroup

`role="group"`인 `div`를 렌더링합니다. `aria-label`을 지정하세요. 나머지 props는 `div`에 전달됩니다.
