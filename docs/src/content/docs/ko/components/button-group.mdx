---
title: Button Group
description: Button Group은 아직 @refineui/react에 제공되지 않습니다.
---

Button Group 컴포넌트는 현재 `@refineui/react`에 포함되어 있지 않습니다.

버튼을 묶을 때는 `Stack` 같은 레이아웃 컴포넌트를 사용하세요:

```tsx
import { Button, Stack } from "@refineui/react";

<Stack direction="row" gap="sizeXSmall">
  <Button variant="outline">Cancel</Button>
  <Button variant="primary">Save</Button>
</Stack>
```
