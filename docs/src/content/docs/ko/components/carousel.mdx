## 사용법

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselControls,
  CarouselPrevious,
  CarouselNext,
  CarouselIndicators
} from "@refineui/react";

<Carousel>
  <CarouselContent>
    <CarouselItem>
      <img src="/slide1.jpg" alt="Slide 1" />
    </CarouselItem>
    <CarouselItem>
      <img src="/slide2.jpg" alt="Slide 2" />
    </CarouselItem>
    <CarouselItem>
      <img src="/slide3.jpg" alt="Slide 3" />
    </CarouselItem>
  </CarouselContent>
  <CarouselControls>
    <CarouselPrevious />
    <CarouselNext />
  </CarouselControls>
  <CarouselIndicators />
</Carousel>

<Carousel
  index={currentIndex}
  onIndexChange={setCurrentIndex}
  loop
/>
```

### CarouselContent

슬라이드 컨테이너.

### CarouselItem

개별 슬라이드.

### CarouselControls

내비게이션 버튼 컨테이너.

### CarouselPrevious

이전 슬라이드 버튼.

### CarouselNext

다음 슬라이드 버튼.

### CarouselIndicators

슬라이드 점 인디케이터.
