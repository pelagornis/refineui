## 사용법

```tsx
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopyButton,
  CodeBlockHeader,
  CodeBlockLine,
  CodeBlockTitle,
} from "@refineui/react";

const code = "export const ready = true";

<CodeBlock>
  <CodeBlockHeader>
    <CodeBlockTitle>status.ts</CodeBlockTitle>
    <CodeBlockActions>
      <CodeBlockCopyButton value={code} />
    </CodeBlockActions>
  </CodeBlockHeader>
  <CodeBlockContent lineNumbers>
    <CodeBlockLine>{code}</CodeBlockLine>
  </CodeBlockContent>
</CodeBlock>
```

`CodeBlockLine`의 `variant="highlighted"`는 강조 행을 만듭니다.
`CodeBlockContent`의 `wrap`, `lineNumbers`로 소스 문자열을 바꾸지 않고 표시를 제어할 수 있습니다.

## 액션과 구문 강조

`CodeBlockActions`에는 `CodeBlockCopyButton`과 일반 RefineUI `Button`을 함께
넣을 수 있습니다. 다운로드나 줄 바꿈처럼 앱에 따라 달라지는 동작은 이 영역에서
직접 구성하세요.

`CodeBlockLine`은 모든 `ReactNode`를 받을 수 있으므로, 구문 강조 라이브러리가
만든 토큰 span을 그대로 전달할 수 있습니다. 복사 기능에는 가공하지 않은 원문을
`CodeBlockCopyButton`의 필수 `value`로 전달하세요.

데모는 RefineUI 의미 색상 토큰으로 문법 span을 표시합니다. shadcn/ui처럼 Shiki가
반환한 토큰을 전달하거나 같은 방식으로 직접 구성할 수 있습니다.

## API 레퍼런스

### CodeBlock 및 레이아웃 파트

`CodeBlock`, `CodeBlockHeader`, `CodeBlockTitle`, `CodeBlockActions`는 표준
`div` 속성을 받습니다. 루트 안에는 `CodeBlockHeader`와 `CodeBlockContent`를,
헤더 안에는 제목과 액션을 조합합니다.
