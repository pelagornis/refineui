## 사용법

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@refineui/react";

<Collapsible defaultOpen>
  <CollapsibleTrigger>Details</CollapsibleTrigger>
  <CollapsibleContent>
    Hidden until the trigger opens it.
  </CollapsibleContent>
</Collapsible>
```

`open`과 `onOpenChange`로 제어형으로 사용할 수 있습니다. `CollapsibleTrigger`는 기본적으로 Button `ghost`를 렌더합니다(`layout`, `size` 등 Button props 전달 가능). `asChild`로 커스텀 자식에 병합할 수 있습니다. 닫힌 content는 마운트된 채 숨겨집니다.
