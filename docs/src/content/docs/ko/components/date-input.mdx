`DateInput`은 입력 형태의 트리거, `Popover`, `Calendar`를 결합합니다. 날짜를 선택하면 값이 갱신되며, 달력은 바깥을 클릭하거나 Escape를 누를 때 닫힙니다. `mode="range"`를 지정하면 두 달을 나란히 보며 시작일과 종료일을 고를 수 있습니다.

## 사용법

```tsx
import { useState } from "react";
import { DateInput } from "@refineui/react";

const [date, setDate] = useState<Date>();

<DateInput
  value={date}
  onValueChange={setDate}
  placeholder="배송 날짜 선택"
  locale="ko-KR"
  weekStartsOn={1}
  fullWidth
/>;
```

비제어 방식에는 `defaultValue`를 사용하세요. `size="sm" | "md" | "lg"`는 `Input`과 같은 컨트롤 높이, 여백, 타이포그래피를 사용하며, 상위 `Field`의 크기도 상속합니다. `Input`처럼 `error`, `success`, `disabled` 상태를 전달할 수 있습니다.
