## 사용법

```tsx
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuTrigger,
  NavigationMenuContent,
  NavigationMenuLink,
  Stack,
  Text
} from "@refineui/react";

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuLink href="/" active>
        Home
      </NavigationMenuLink>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Products</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/products/web">
          <Stack gap="sizeXXXSmall">
            <Text variant="bodyMd">Web</Text>
            <Text variant="bodyXs">브라우저 기반 경험</Text>
          </Stack>
        </NavigationMenuLink>
        <NavigationMenuLink href="/products/mobile">
          <Stack gap="sizeXXXSmall">
            <Text variant="bodyMd">Mobile</Text>
            <Text variant="bodyXs">선택적으로 보조 설명을 넣습니다.</Text>
          </Stack>
        </NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="/about">About</NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## 패널 레이아웃 선택

`NavigationMenuContent`는 콘텐츠 구조를 정하지 않으며, Tailwind 기반의 세 가지
패널 방식을 제공합니다. `dropdown`은 트리거에 맞춘 간결한 선택지에, `floating`은
중앙 정렬 다중 열 패널에, `overlay`는 헤더에 연결되는 전체 폭 제품 내비게이션
레이어에 사용합니다. 패널 내부의 정보 구조와 콘텐츠는 소비하는 앱이 구성합니다.

```tsx
<NavigationMenuContent>
  <NavigationMenuLink href="/components">Components</NavigationMenuLink>
  <NavigationMenuLink href="/tokens">Tokens</NavigationMenuLink>
</NavigationMenuContent>

<NavigationMenuContent layout="floating">
  <div className="grid grid-cols-2 gap-refineui-size-medium">
    {/* 더 넓은 패널을 자유롭게 구성합니다. */}
  </div>
</NavigationMenuContent>

<NavigationMenuContent
  layout="overlay"
>
  <div className="grid max-w-refineui-navigation-menu-mega-width grid-cols-3 gap-refineui-size-xxx-small">
    {/* 카테고리와 이동 경로는 소비하는 앱에서 구성합니다. */}
  </div>
</NavigationMenuContent>
```

### NavigationMenuTrigger

드롭다운 콘텐츠용 트리거 버튼.

### NavigationMenuContent

패널 콘텐츠입니다. 위치, 닫힘 동작, 포커스 복귀, 전환은 컴포넌트가 관리하고,
패널의 콘텐츠와 폭은 소비하는 앱이 구성합니다.

<div class="not-content">
  <PropSpec
    client:load
    rows={[
    { prop: "layout", default: '"dropdown"', type: '"dropdown" | "floating" | "overlay"', description: "트리거 정렬 compact 패널, 중앙 floating 패널 또는 헤더에 연결되는 전체 폭 패널입니다." }
    ]}
  />
</div>

### NavigationMenuLink

상단 직접 링크에는 드롭다운 화살표용 빈 공간을 남기지 않습니다. 모든 상단 항목은 최소 80px 너비와 28px 높이를 공유하므로, 일반적인 레이블 길이에서는 chevron 유무와 관계없이 같은 크기를 유지합니다. 더 긴 레이블은 잘리지 않도록 확장됩니다.
