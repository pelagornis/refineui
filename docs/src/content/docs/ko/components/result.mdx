## 사용법

```tsx
import { Result, ResultButton } from "@refineui/react";

<Result
  variant="success"
  title="결제가 완료되었어요"
  description="영수증은 주문 내역에서 확인할 수 있어요."
  actions={<ResultButton>영수증 보기</ResultButton>}
/>;
```

기본으로 RefineUI System Icon을 사용합니다. `figure`에 이미지나 일러스트, 아이콘을 전달해 바꿀 수 있으며, `ResultIcon`, `ResultTitle`, `ResultDescription`, `ResultActions`로 직접 조합할 수도 있습니다.
