`TimeInput`은 입력 형태의 트리거, `Popover`, 140px 고정 높이의 시·분 `ScrollArea` 목록을 결합합니다. 선택값 주변 항목도 읽기 쉽게 보이며, 열릴 때 선택된 값은 각 목록 가운데에 위치합니다. 휠이 멈출 때 값이 바로 반영되며 Popover를 닫아도 선택값이 유지됩니다.

## 사용법

```tsx
import { useState } from "react";
import { TimeInput } from "@refineui/react";

const [time, setTime] = useState("09:30");

<TimeInput value={time} onValueChange={setTime} minuteStep={15} hourCycle="12h" />;
```

시간 값은 항상 24시간제 `HH:mm` 형식을 사용합니다. `hourCycle="12h"`를 설정하면 시·분 앞에 스크롤 가능한 AM/PM 열이 표시됩니다. `size="sm" | "md" | "lg"`는 `Input`과 같은 크기를 사용하며 상위 `Field` 크기도 상속합니다.
