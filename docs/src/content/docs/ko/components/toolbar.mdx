`Toolbar`는 텍스트 서식, 정렬, 클립보드 같은 관련 컨트롤을 하나의 Tab 정지점으로 묶고, 그 안에서는 방향키로 이동하게 해 줍니다. `ToolbarGroup`, `ToolbarButton`, `ToolbarToggleButton`, `ToolbarDivider`를 조합해서 만듭니다. 툴바에 `size`를 한 번만 지정하면 안의 컨트롤이 모두 그 크기를 따릅니다.

## 사용법

```tsx
import {
  Toolbar,
  ToolbarButton,
  ToolbarGroup,
  ToolbarDivider,
  ToolbarToggleButton,
  WebIcon,
} from "@refineui/react";

<Toolbar label="텍스트 서식">
  <ToolbarGroup aria-label="텍스트 스타일">
    <ToolbarToggleButton aria-label="강조"><WebIcon name="highlight" /></ToolbarToggleButton>
    <ToolbarToggleButton aria-label="링크"><WebIcon name="link" /></ToolbarToggleButton>
  </ToolbarGroup>
  <ToolbarDivider />
  <ToolbarGroup aria-label="클립보드">
    <ToolbarButton aria-label="복사"><WebIcon name="copy" /></ToolbarButton>
    <ToolbarButton aria-label="잘라내기"><WebIcon name="cut" /></ToolbarButton>
  </ToolbarGroup>
</Toolbar>;
```

## 예시

### Attached

`attached`를 주면 둥근 모서리의 떠 있는 표면 위에 툴바가 올라갑니다. 캔버스나 에디터 위에 띄우는 액션 바에 어울립니다.

```tsx
<Toolbar label="텍스트 서식" attached>
  …
</Toolbar>
```

### 세로

`orientation="vertical"`이면 컨트롤이 세로로 쌓이고 위아래 방향키로 이동합니다. 그룹과 구분선도 같은 방향을 상속합니다.

```tsx
<Toolbar label="도구" orientation="vertical" attached>
  <ToolbarGroup aria-label="도구">…</ToolbarGroup>
  <ToolbarDivider />
  <ToolbarGroup aria-label="확대/축소">…</ToolbarGroup>
</Toolbar>
```

### 그룹

`ToolbarGroup`은 항상 [ButtonGroup](/ko/components/button-group/)과 같은 튜브로 ghost 버튼들을 감쌉니다. SegmentedControl과 같은 연한 트랙과 얇은 테두리를 쓰고, 모서리는 Button 반경을 따릅니다. 눌린 토글은 따로 색을 칠하지 않고 ghost에서 Button의 secondary variant로 바뀝니다. 툴바 안의 그룹은 모두 같은 모양이라 구분은 구분선으로 합니다.

### 토글 버튼

`ToolbarToggleButton`은 눌림 상태를 `aria-pressed`로 유지하고, 눌린 동안 Button의 secondary variant로 그립니다. `defaultPressed`로 비제어 방식으로 쓰거나, `pressed`와 `onPressedChange`로 제어할 수 있습니다. 정렬처럼 하나만 고르는 경우에는 공유 상태로 제어하세요.

```tsx
const [align, setAlign] = useState("left");

<ToolbarGroup aria-label="정렬">
  {["left", "center", "right"].map((value) => (
    <ToolbarToggleButton
      key={value}
      aria-label={`${value} 정렬`}
      pressed={align === value}
      onPressedChange={() => setAlign(value)}
    >
      <WebIcon name={`text-align-${value}`} />
    </ToolbarToggleButton>
  ))}
</ToolbarGroup>;
```

### 크기 전파

`size`(`sm`, `md`, `lg` 중 하나, 기본값 `sm`)는 `ToolbarButton`, `Button`, 그리고 `Input`, `Select` 같은 Field 컨트롤에 전파됩니다. `size`를 직접 지정한 자식은 자기 크기를 유지합니다.

## 키보드

| 키 | 동작 |
| --- | --- |
| `Tab` | 툴바 안(마지막으로 포커스된 항목)으로 들어가거나 밖으로 나갑니다. 툴바 전체가 하나의 Tab 정지점입니다. |
| `ArrowRight` / `ArrowLeft` | 가로 툴바에서 다음 또는 이전 항목으로 이동합니다. RTL에서는 반대입니다. |
| `ArrowDown` / `ArrowUp` | `orientation="vertical"`일 때 다음 또는 이전 항목으로 이동합니다. |
| `Home` / `End` | 첫 번째 또는 마지막 항목으로 이동합니다. 텍스트 필드 안에서는 대신 캐럿을 옮깁니다. |
| `Enter` / `Space` | 포커스된 버튼을 실행하거나 토글합니다. |

비활성화된 항목은 건너뛰고, `loop={false}`가 아니면 포커스가 처음과 끝 사이를 순환합니다. `SegmentedControl` 같은 복합 위젯은 하나의 정지점으로 취급되고, 텍스트 필드 안에서는 캐럿이 끝에 닿을 때까지 방향키가 캐럿을 옮깁니다.
