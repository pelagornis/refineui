RefineUI 문서는 디자인 시스템의 **1급 소비자**입니다 — 제품과 같은 패키지, 토큰, 모션 역할을 사용합니다.

## 가이드

- [시작하기](/ko/getting-started/) — 아키텍처, 설치, 첫 예제
- [설치](/ko/development/installation/) — 패키지 추가와 CSS 로드
- [테마](/ko/development/theming/) — 라이트/다크와 토큰 서피스
- [모션](/ko/development/motion/) — CSS 트랜지션 vs 모션 런타임

## 원칙

1. **토큰만** — 컴포넌트 스타일에 임의 px, hex, ms 금지
2. **실제 컴포넌트** — 문서는 `@refineui/react`를 렌더하며 목업을 쓰지 않음
3. **모션 역할** — `fast`, `press`, `panel` via `--refineui-motion-*`
4. **문서 = 제품** — 앱과 이 사이트에서 같은 패키지·토큰·스타일시트
