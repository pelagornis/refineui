## CSS

앱 루트에서 토큰 CSS와 컴포넌트 인터랙션 스타일을 한 번 로드하세요.

```css
@import "@refineui/tokens/tailwind.css";
@import "@refineui/web-icons/dist/fonts/refineui-system-icons.css";
@import "@refineui/react/refineui.css";
```

## 첫 컴포넌트

```tsx
import { Button } from "@refineui/react";

export function App() {
  return <Button variant="primary">Continue</Button>;
}
```

문서 프리뷰에서도 같은 import를 사용하세요 — 병렬 목 UI는 없습니다.
