Scrim **틴트**는 `surfaceOverlay` / `--refineui-overlay-backdrop`에 둡니다 ([투명도](/ko/foundations/opacity/), [컬러](/ko/foundations/color/) 참고). Blur는 필터 반경만 담당합니다.

`prefers-reduced-transparency: reduce`일 때 Dialog/Drawer `backdrop-filter`는 `refineui.css`에서 `none`으로 접힙니다.

## 사용법

```css
.scrim {
  background: var(--refineui-overlay-backdrop);
  backdrop-filter: blur(var(--refineui-blur-overlay-scrim));
}
```
