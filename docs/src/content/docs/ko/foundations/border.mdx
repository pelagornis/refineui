스트로크 너비는 Foundation 키입니다. 기본 UI 크롬은 `strokeWidthThin`을 사용합니다. 보더 **색**은 이 스케일이 아니라 컬러 별칭(`borderDefault`, `borderSubtle`, `borderFocus`)에서 옵니다.

## 사용법

```tsx
<Box
  border="strokeWidthThin"
  borderColor="borderDefault"
  radius="roundedLarge"
  padding="sizeLarge"
  background="backgroundSurface"
>
  Outlined surface
</Box>
```
