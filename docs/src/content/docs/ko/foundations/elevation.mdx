각 Elevation 스텝(`--refineui-elevation-N`)은 활성 테마에 따라 라이트·다크 값을 자동으로 전환합니다. bare 변수를 사용하세요 — 명시적 `*light` / `*dark` 접미사는 테마와 무관하게 한 모드로 고정해야 할 때만 필요합니다.

## 사용법

```css
.panel {
  box-shadow: var(--refineui-elevation-8);
}
```
