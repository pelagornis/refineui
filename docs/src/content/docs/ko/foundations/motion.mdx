**시맨틱 역할**(`fast`, `press`, `panel`)을 사용하세요 — CSS `--refineui-motion-duration-fast`, `--refineui-motion-scale-press`. 컴포넌트에 `150ms`나 일회성 커브를 쓰지 마세요. 컨트롤 hover와 focus는 이미 `refineui.css`가 담당합니다.

## 사용법

```css
.control {
  transition: transform var(--refineui-motion-duration-fast)
    var(--refineui-motion-easing-standard);
}

.control[data-pressed] {
  transform: scale(var(--refineui-motion-scale-press));
}
```
