## 예시

컨트롤 높이(버튼, 인풋)와 오버레이 너비는 `--refineui-size-button-min-height-md`, `--refineui-size-dialog-max-width` 같은 CSS 변수로 해석됩니다. 커스텀 크롬을 조합하는 경우가 아니면 제품 CSS에서 그 변수를 읽기보다 컴포넌트 props(`size="md"`)를 우선하세요.

```tsx
import { iconSizes } from "@refineui/tokens";
import { WebIcon } from "@refineui/react";

<WebIcon name="search" size={iconSizes.small} />
```
