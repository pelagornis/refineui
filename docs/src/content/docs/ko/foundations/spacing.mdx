## 아이콘 글리프 크기

아이콘 픽셀은 스페이싱과 별개입니다(`iconSizes`). `WebIcon` / 글리프 슬롯에만 사용하세요.

## 사용법

```tsx
<Stack gap="sizeMedium">
  <Box padding="sizeLarge" background="backgroundSurface" radius="roundedLarge">
    Inset
  </Box>
```
