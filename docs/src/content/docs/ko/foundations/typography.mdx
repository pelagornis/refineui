`Text`에 **시맨틱 역할**(`headingMd`, `bodyMd`, `labelSm`)을 사용하세요. 각 역할은 `typographys`의 Foundation 프리셋을 별칭합니다. 제품 UI에서 원시 `fontSize`나 `body2` 같은 Foundation 키를 넘기지 마세요.

## 사용법

```tsx
import { Text } from "@refineui/react";

<Text variant="headingMd" as="h2">
  Section title
</Text>
<Text variant="bodyMd" as="p">
  Body copy.
</Text>
```
