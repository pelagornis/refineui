# Accordion

Accordion is a stack of collapsible sections. Use it for FAQs, settings groups, and help copy when showing everything at once would be too long.

Each item has a trigger and a panel. `type="single"` keeps one panel open; `type="multiple"` allows several. For in-page view switching with a persistent bar, use **[Tabs](/components/tabs/)**.

## Interface

### Accordion

| Prop | Default | Type |
|------|---------|------|
| `type` | `"single"` | `"single"` \| `"multiple"` — One open panel versus several. |
| `collapsible` | `false` | `boolean` — In `single` mode, allow closing the open item. |
| `defaultValue` | — | `string` \| `string[]` — Uncontrolled initially open item(s). |
| `value` | — | `string` \| `string[]` — Controlled open item(s). |
| `onValueChange` | — | `(value: string \| string[] \| undefined) => void` — Called after open state changes. In `single` mode the value is the open id, or `undefined` when none are open. |
| `size` | `"md"` | `"sm"` \| `"md"` \| `"lg"` — Trigger and content typography, and icon size. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### AccordionItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Item identity. Required. Match this to Accordion `value` / `defaultValue`. |
| `icon` | — | `string` — WebIcon name shown before the trigger label. |

### Parts

| Part | Role |
|------|------|
| `AccordionTrigger` | Button that toggles the item. Renders the chevron. |
| `AccordionContent` | Collapsible panel. Hidden when closed (`pointer-events: none`). |
