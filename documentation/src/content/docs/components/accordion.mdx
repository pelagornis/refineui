# Accordion

Expand and collapse multiple panels. Web Kit **Accordion** `54:146` — trigger typography follows **`size`** **sm / md / lg**.

## Install & import

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Accordion
  type="single"
  collapsible
  defaultValue="shipping"
  className="max-w-lg"
>
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      We offer standard (5-7 days), express (2-3 days), and overnight shipping.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="returns">
    <AccordionTrigger>What is your return policy?</AccordionTrigger>
    <AccordionContent>
      Returns accepted within 30 days. Items must be unused and in original packaging.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"single"` \| `"multiple"` | `"single"` | Single vs multiple open items |
| `collapsible` | `boolean` | `false` | In `single` mode, allow closing the open item |
| `defaultValue` | `string` \| `string[]` | — | Initially open item(s) |
| `value` | `string` \| `string[]` | — | Controlled value |
| `onValueChange` | `(value) => void` | — | Change callback |
| `size` | `"small"` \| `"medium"` \| `"large"` | — | Trigger typography |

## Examples

### Icon

Pass `icon` on `AccordionItem` to show an icon before the title.

```tsx
<Accordion type="single" defaultValue="help">
  <AccordionItem value="help" icon="info">
    <AccordionTrigger>Help</AccordionTrigger>
    <AccordionContent>Item content with a leading icon.</AccordionContent>
  </AccordionItem>
</Accordion>
```
