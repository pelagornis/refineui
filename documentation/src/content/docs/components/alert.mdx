# Alert

페이지·섹션 상단 등에 쓰는 인라인 알림입니다. Web Kit **Alert** `384:885` 및 `docs/design-specs-web-kit.md` §5를 따릅니다.

## 설치·임포트

```tsx
import { Alert, AlertDescription, AlertTitle, WebIcon } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Alert className="max-w-md">
  <WebIcon name="checkmark" aria-hidden />
  <AlertTitle>Payment successful</AlertTitle>
  <AlertDescription>
    Your payment of $29.99 has been processed.
  </AlertDescription>
</Alert>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `variant` | `"default"` \| `"info"` \| `"success"` \| `"warning"` \| `"danger"` \| `"custom"` | 강조 색·기본 아이콘 |
| `icon` | `string` \| `ReactNode` | System Icons 이름 또는 커스텀 노드 |
| `title` | `ReactNode` | 제목 |
| `description` | `ReactNode` | 본문 |
| `onClose` | `() => void` | 닫기 버튼 |
| `actions` | `{ label, onClick }[]` | 우측 액션(최대 2개 권장) |

`children`으로 합성형(`AlertTitle`, `AlertDescription`)도 지원합니다.

## 예시

### 합성형

```tsx
<Alert>
  <WebIcon name="info" aria-hidden />
  <AlertTitle>New feature available</AlertTitle>
  <AlertDescription>
    We&apos;ve added dark mode support. You can enable it in account settings.
  </AlertDescription>
</Alert>
```

### Variant API

```tsx
<Alert
  variant="warning"
  title="High memory usage"
  description="The current process is using more memory than usual."
/>
```

### 닫기 + 액션

```tsx
<Alert
  variant="success"
  title="저장됨"
  description="변경 사항이 반영되었습니다."
  onClose={() => {}}
  actions={[{ label: "실행 취소", onClick: () => {} }]}
/>
```
