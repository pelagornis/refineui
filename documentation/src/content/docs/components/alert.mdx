# Alert

Alert is an inline notice in page or section chrome. Use it for status that should stay visible until the user acts or the condition changes — a saved confirmation, a warning, or an upgrade prompt.

It is not a modal. For a blocking decision, use **[Dialog](/components/dialog/)**. For feedback that should disappear on its own, use **[Toast](/components/toast/)**.

## Interface

### Alert

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"info"` | `"default"` \| `"info"` \| `"success"` \| `"warning"` \| `"danger"` \| `"custom"` — Color context for title, description, and default icon. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### AlertIcon

| Prop | Default | Type |
|------|---------|------|
| `name` | variant default | `string` — Web Icon name when `children` are omitted. |
| `children` | — | `ReactNode` — Custom leading node. Overrides `name`. |

### AlertClose

Native `button` attributes. Default: ghost icon **[Button](/components/button/)** with a dismiss icon and `aria-label="Close"`. You must handle dismiss in `onClick`.

### AlertAction

Native `button` attributes. Default: primary `sm` **[Button](/components/button/)**.

### Parts

| Part | Role |
|------|------|
| `AlertContent` | Inner column (applied automatically by `Alert`). |
| `AlertRow` | Icon + body + optional close. |
| `AlertBody` | Title and description column. |
| `AlertTitle` | `h5` title. |
| `AlertDescription` | Supporting copy. |
| `AlertActions` | Trailing row of actions. |
