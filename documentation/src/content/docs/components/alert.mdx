# Alert

Inline alert for page or section chrome. Follows Web Kit **Alert** `384:885` and `docs/design-specs-web-kit.md` §5.

## Install & import

```tsx
import {
  Alert,
  AlertAction,
  AlertActions,
  AlertBody,
  AlertClose,
  AlertDescription,
  AlertIcon,
  AlertRow,
  AlertTitle,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Alert className="max-w-md">
  <AlertRow>
    <AlertIcon name="checkmark" />
    <AlertBody>
      <AlertTitle>Payment successful</AlertTitle>
      <AlertDescription>
        Your payment of $29.99 has been processed.
      </AlertDescription>
    </AlertBody>
  </AlertRow>
</Alert>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `variant` | `"default"` \| `"info"` \| `"success"` \| `"warning"` \| `"danger"` \| `"custom"` | Color context |
| `className` | `string` | Extend root |
| `...props` | `HTMLAttributes<HTMLDivElement>` | Root `<div>` props |

## Examples

### Composed

```tsx
<Alert>
  <AlertRow>
    <AlertIcon name="info" />
    <AlertBody>
      <AlertTitle>New feature available</AlertTitle>
      <AlertDescription>
        We&apos;ve added dark mode support. You can enable it in account settings.
      </AlertDescription>
    </AlertBody>
  </AlertRow>
</Alert>
```

### Close + actions

```tsx
<Alert variant="success">
  <AlertRow>
    <AlertIcon name="checkmark" />
    <AlertBody>
      <AlertTitle>Saved</AlertTitle>
      <AlertDescription>Your changes were applied.</AlertDescription>
    </AlertBody>
    <AlertClose onClick={() => {}} />
  </AlertRow>
  <AlertActions>
    <AlertAction onClick={() => {}}>Undo</AlertAction>
  </AlertActions>
</Alert>
```
