# Alert

페이지·섹션 상단 등에 쓰는 인라인 알림입니다. Web Kit **Alert** `384:885` 및 `docs/design-specs-web-kit.md` §5를 따릅니다.

## 설치·임포트

```tsx
import {
  Alert,
  AlertAction,
  AlertActions,
  AlertBody,
  AlertClose,
  AlertDescription,
  AlertIcon,
  AlertRow,
  AlertTitle,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Alert className="max-w-md">
  <AlertRow>
    <AlertIcon name="checkmark" />
    <AlertBody>
      <AlertTitle>Payment successful</AlertTitle>
      <AlertDescription>
        Your payment of $29.99 has been processed.
      </AlertDescription>
    </AlertBody>
  </AlertRow>
</Alert>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `variant` | `"default"` \| `"info"` \| `"success"` \| `"warning"` \| `"danger"` \| `"custom"` | 색상 컨텍스트 |
| `className` | `string` | 루트 스타일 확장 |
| `...props` | `HTMLAttributes<HTMLDivElement>` | 루트 `<div>` 속성 |

## 예시

### 합성형

```tsx
<Alert>
  <AlertRow>
    <AlertIcon name="info" />
    <AlertBody>
      <AlertTitle>New feature available</AlertTitle>
      <AlertDescription>
        We&apos;ve added dark mode support. You can enable it in account settings.
      </AlertDescription>
    </AlertBody>
  </AlertRow>
</Alert>
```

### 닫기 + 액션

```tsx
<Alert variant="success">
  <AlertRow>
    <AlertIcon name="checkmark" />
    <AlertBody>
      <AlertTitle>저장됨</AlertTitle>
      <AlertDescription>변경 사항이 반영되었습니다.</AlertDescription>
    </AlertBody>
    <AlertClose onClick={() => {}} />
  </AlertRow>
  <AlertActions>
    <AlertAction onClick={() => {}}>실행 취소</AlertAction>
  </AlertActions>
</Alert>
```
