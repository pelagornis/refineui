# Alert

알림/경고 메시지 컴포넌트입니다. Web Kit Figma와 같이 **첫 줄**에 아이콘·제목/설명·닫기를 두고, **액션 버튼**은 그 아래 줄에서 우측 정렬됩니다.

## Preview

<div class="not-content">
  <AlertPreview client:load />
</div>

## Variants

- `default` / `info` / `success` / `warning` / `danger` / `custom` — variant마다 **RefineUI System Icons** 기본 글리프가 다릅니다 (`circle`, `info`, `checkmark`, `warning`, `error-circle`, `star`).
- `icon` prop으로 아이콘 이름을 바꿀 수 있습니다 (`@refineui/web-icons` 슬러그).

## 아이콘

Preview 아래쪽에서 **`icon` 문자열**(`settings`, `mail`, `calendar` 등)과 **`icon`에 `<WebIcon />` 노드**를 넘기는 예시를 함께 볼 수 있습니다. 전체 아이콘 목록은 `@refineui/web-icons` 메타데이터를 참고하세요.

## 닫기

닫기 버튼은 `dismiss` 아이콘을 사용합니다.
