# Avatars

여러 아바타를 한 줄로 묶는 그룹 컴포넌트입니다. Web Kit의 **Avater Stack**(겹침)과 **Avater Spread**(간격)에 대응합니다.

## Props

- `avatars` — AvatarItem[] (src?, alt)
- `size` — sm | md | lg
- `max` — 최대 표시 개수 (초과 시 +N 표시)
- `layout` — `stack`(기본, 겹침) | `spread`(겹치지 않고 gap만 둠)
