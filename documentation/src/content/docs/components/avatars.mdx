# Avatars

Aligned with Web Kit single **`Avatar`** (component set) and group **`Avatar` Stack** `69:3008` · **`Avatar` Spread** `69:3007`. Build overlap and rows with **`AvatarGroup`** and **`Avatar`**.

### MCP (`get_design_context`) — maps to Web Kit `Avatar`

Figma search/export names: **`Avatar`** / **`Avatar Stack`** / **`Avatar Spread`** / **`Avatar/Status`** (as of 2026-04). Stack frame `69:3008` has multiple rows; package **`AvatarSize`** nine steps (`xxxsmall` … `xxxlarge`) map to MCP `Avatar` **`size`** (XXXSmall … XXXLarge) and Foundation **`Global/Size/*`** (`foundationSizes`).

**Figma `Avatar` (`56:254`) `Color` × `Layout`:** In plugin variants, **`Image`→Neutral only**; **`Icon`** and **`Initials`** share the **same 10 colors** (Blue … Yellow). The **`69:3008` Stack** frame is a group demo only—not the full single-`Avatar` color matrix.

**Note:** Stack row variant names (`Size=Small`, etc.) may **differ** from the inner Figma `Avatar` **`size`** property names (per MCP export).

| `AvatarSize` | Diameter (`Global/Size/*`) | Figma `Avatar` MCP `size` (example) | Stack overlap (`foundationSizes`) |
|--------------|------------------------------|---------------------------------------|-----------------------------------|
| `xxxsmall` | `160` → 16px | `XXXSmall` | `40` → 4px |
| `xxsmall` | `200` | `XXSmall` | `40` |
| `xsmall` | `240` | `XSmall` | `40` |
| `small` | `280` | `Small` | `60` → 6px |
| `medium` | `320` | `Medium` | `60` |
| `large` | `360` | `Large` | `80` → 8px |
| `xlarge` | `480` | `XLarge` | `100` → 10px |
| `xxlarge` | `540` → 54px | `XXLarge` | `100` |
| `xxxlarge` | `600` → 60px | `XXXLarge` | `120` → 12px |

Values matching Foundation **`Global/Size/{n}`** flow to `--refineui-size-foundation-size-*` via **`foundationSizes`** in `packages/react`. **`Avatar/Status`** XXXLarge (14px) has no `Global/Size/140`, so use **`componentSizes.avatarStatusXxxlarge`**.

| | MCP (`Avatar`) | `packages/react` |
|---|----------------|------------------|
| `color` | `Neutral` \| `Red` \| `Orange` | `neutral` \| `red` \| `orange` |
| `layout` | `Icon` \| `Initials` \| `Image` | `icon` \| `initials` \| `image` |
| `showStatus` | Per `Avatar/Status` diameter row | `showStatus` or `<AvatarBadge />` |
| Orange initials typography | Body / Subtitle / Title per row | `xlarge`→subtitle-1, `xxlarge`→title-3, `xxxlarge`→title-2, else body-1 |
| `selectAvater` | Selection ring (raster overlay) | **Not implemented** |

**`Avatar` Spread** `69:3007`: Each row’s **`Size`** matches the Figma `size` on `Avatar` instances in that row. `avatarSpreadGap` maps per tier to `spacings` `sizeXSmall`–`sizeXLarge`.

import {

  AvatarIcon,
  AvatarImage,
  AvatarText,
} from "@refineui/react";

## Basic usage

Use Web Kit **`Avatar` `color` / `layout`** presets to compose stacks without long `className` strings.

```tsx
import {
  Avatar,
  AvatarGroup,
  AvatarIcon,
  AvatarImage,
  AvatarText,
} from "@refineui/react";

export function AvatarStackExample() {
  return (
    <AvatarGroup size="md" layout="stack">
      <Avatar size="md" showStatus>
        <AvatarImage src="/avatar.jpg" alt="User" />
      </Avatar>
      <Avatar size="md" color="neutral">
        <AvatarIcon name="person" />
      </Avatar>
      <Avatar size="md" color="orange" alt="Park Lee">
        <AvatarText>PL</AvatarText>
      </Avatar>
      <Avatar size="md" color="red">
        <AvatarIcon name="person" />
      </Avatar>
      <Avatar size="md">
        <AvatarIcon name="more-horizontal" />
      </Avatar>
    </AvatarGroup>
  );
}
```

### Overflow split

Pick a max count and `slice`—no extra utility required.

```tsx
import { Avatar, AvatarGroup, AvatarGroupCount } from "@refineui/react";

const maxInline = 4;
const inlineItems = names.slice(0, maxInline);
const overflowItems = names.slice(maxInline);

<AvatarGroup size="md" layout="stack">
  {inlineItems.map((name) => (
    <Avatar key={name} size="md" color="orange" alt={name} />
  ))}
  {overflowItems.length > 0 ? <AvatarGroupCount>+{overflowItems.length}</AvatarGroupCount> : null}
</AvatarGroup>;
```

Inside `Avatar`, use `AvatarIcon` for system icons; omitting `size` applies glyph sizes for Web Kit Person slots per tier (32·36·56px).

```tsx
<Avatar size="md">
  <AvatarFallback>
    <AvatarIcon name="person" color="var(--refineui-color-primary-black)" />
  </AvatarFallback>
</Avatar>
```

Use `AvatarGroup` with `layout="spread"` for horizontal spacing (gaps match Web Kit **`Avatar` Spread** `69:3007`).

```tsx
<AvatarGroup size="md" layout="spread">
  <Avatar size="md">…</Avatar>
  <Avatar size="md">…</Avatar>
</AvatarGroup>
```

## Props

**`className`** on `Avatar` applies to the **outer wrapper** for overlap/margin only. For inner shell background/border, use **`innerClassName`**.

### `Avatar`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string \| null` | — | Image URL (`AvatarImage` `src` wins when present) |
| `alt` | `string` | `""` | Alt text / initials extraction |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 32·36·56px diameters — maps to Figma `Avatar` Stack rows and MCP sizes (see table above) |
| `color` | `"neutral"` \| `"red"` \| `"orange"` | `"neutral"` | Web Kit `Avatar` `color` — shell and default icon tone |
| `layout` | `"image"` \| `"icon"` \| `"initials"` | — | Auto when `AvatarImage` / `AvatarIcon` / `AvatarText` slots omitted |
| `showStatus` | `boolean` | `false` | Web Kit `showStatus` — same as `AvatarBadge`; if `AvatarBadge` child exists, only that renders |
| `status` | `"online"` \| `"away"` \| `"unavailable"` \| `"offline"` | `"online"` | When `showStatus` — matches Figma `Avatar/Status` |
| `innerClassName` | `string` | — | **Inside** the circular mask — shell bg/border. Outer wrapper uses `className` |

### `AvatarGroup`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Overlap/spacing tier with child `Avatar`s |
| `layout` | `"stack"` \| `"spread"` | `"stack"` | Overlap (stack) vs spaced row (spread) |

Composed API: `AvatarImage`, `AvatarFallback`, `AvatarIcon`, `AvatarGroupCount`, `AvatarBadge`, etc.
