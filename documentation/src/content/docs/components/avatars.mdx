# Avatars

Web Kit 단일 **`Avatar`**(컴포넌트 세트)와 그룹 **`Avatar` Stack** `69:3008` · **`Avatar` Spread** `69:3007`에 맞춰, 겹침·나열은 **`AvatarGroup`**과 **`Avatar`** 조합으로 구성합니다.

### MCP(`get_design_context`) — Web Kit `Avatar`와 정확히 대응

Figma 검색·export 기준 컴포넌트 이름은 **`Avatar`** / **`Avatar Stack`** / **`Avatar Spread`** / **`Avatar/Status`**(2026-04 기준). 스택 프레임 `69:3008`에는 여러 행이 있으며, 패키지 **`AvatarSize` 9단계**(`xxxsmall` … `xxxlarge`)가 MCP `Avatar` **`size`**(XXXSmall … XXXLarge)와 Foundation **`Global/Size/*`**(`foundationSizes`)에 대응합니다.

**Figma `Avatar`(`56:254`) `Color` × `Layout`:** 플러그인 variant 기준 **`Image`→Neutral만**, **`Icon`**과 **`Initials`**는 **동일 10색**(Blue … Yellow). **`69:3008` Stack** 프레임은 그룹 데모일 뿐, 단일 `Avatar` 전체 색 목록과 동일하지 않다.

**주의:** 스택 행 변형 이름(`Size=Small` 등)과 내부 인스턴스의 Figma `Avatar` **`size`** 프로퍼티 이름이 **다를 수 있습니다**(MCP export 기준).

| `AvatarSize` | 지름 (`Global/Size/*`) | Figma `Avatar` MCP `size`(예) | Stack 겹침 (`foundationSizes`) |
|--------------|-------------------------|--------------------------------|------------------------------|
| `xxxsmall` | `160` → 16px | `XXXSmall` | `40` → 4px |
| `xxsmall` | `200` | `XXSmall` | `40` |
| `xsmall` | `240` | `XSmall` | `40` |
| `small` | `280` | `Small` | `60` → 6px |
| `medium` | `320` | `Medium` | `60` |
| `large` | `360` | `Large` | `80` → 8px |
| `xlarge` | `480` | `XLarge` | `100` → 10px |
| `xxlarge` | `540` → 54px | `XXLarge` | `100` |
| `xxxlarge` | `600` → 60px | `XXXLarge` | `120` → 12px |

Foundation **`Global/Size/{n}`**에 해당하는 값은 `packages/react`의 **`foundationSizes`**로 `--refineui-size-foundation-size-*`에 반영된다. **`Avatar/Status`** XXXLarge(14px)만 `Global/Size/140`이 없어 **`componentSizes.avatarStatusXxxlarge`**를 쓴다.

| 구분 | MCP (`Avatar` 단위) | `packages/react` |
|------|---------------------|-------------------|
| `color` | `Neutral` \| `Red` \| `Orange` | `neutral` \| `red` \| `orange` |
| `layout` | `Icon` \| `Initials` \| `Image` | `icon` \| `initials` \| `image` |
| `showStatus` | `Avatar/Status` 지름 행별 | `showStatus` 또는 `<AvatarBadge />` |
| Orange 이니셜 타이포 | 행별 Body / Subtitle / Title | `xlarge`→subtitle-1, `xxlarge`→title-3, `xxxlarge`→title-2, 그 외 body-1 |
| `selectAvater` | 선택 링(래스터 오버레이) | **미구현** |

**`Avatar` Spread** `69:3007`: 각 행의 **`Size` = 그 행 안 `Avatar` 인스턴스의 Figma `size`**와 같습니다. `avatarSpreadGap`은 티어별로 `spacings`의 `sizeXSmall`~`sizeXLarge`에 매핑됩니다.

## 기본 사용

Web Kit **`Avatar` `color` / `layout`**에 맞춘 프리셋으로 긴 `className` 없이 스택을 구성할 수 있습니다.

```tsx
import {
  Avatar,
  AvatarGroup,
  AvatarImage,
  AvatarOverflow,
} from "@refineui/react";

export function AvatarStackExample() {
  return (
    <AvatarGroup size="medium" layout="stack">
      <Avatar size="medium" layout="image" color="neutral" showStatus>
        <AvatarImage src="/avatar.jpg" alt="User" />
      </Avatar>
      <Avatar size="medium" layout="icon" color="neutral" />
      <Avatar size="medium" layout="initials" color="orange" alt="Park Lee" />
      <Avatar size="medium" layout="icon" color="red" />
      <AvatarOverflow size="medium" />
    </AvatarGroup>
  );
}
```

### 오버플로 분할

표시할 개수를 정한 뒤 `slice`로 나누면 됩니다(별도 유틸 없음).

```tsx
import { Avatar, AvatarGroup, AvatarGroupCount } from "@refineui/react";

const maxInline = 4;
const inlineItems = names.slice(0, maxInline);
const overflowItems = names.slice(maxInline);

<AvatarGroup size="medium" layout="stack">
  {inlineItems.map((name) => (
    <Avatar key={name} size="medium" layout="initials" color="orange" alt={name} />
  ))}
  {overflowItems.length > 0 ? <AvatarGroupCount>+{overflowItems.length}</AvatarGroupCount> : null}
</AvatarGroup>;
```

`Avatar` 안에서는 `AvatarIcon`으로 시스템 아이콘을 넣고, `size`를 생략하면 Web Kit Person 슬롯(32·36·56px 티어별)에 맞는 글리프 크기가 적용됩니다.

```tsx
<Avatar size="medium">
  <AvatarFallback>
    <AvatarIcon name="person" color="var(--refineui-color-primary-black)" />
  </AvatarFallback>
</Avatar>
```

나란히 배치는 `AvatarGroup`에 `layout="spread"`를 쓰면 됩니다 (간격은 Web Kit **`Avatar` Spread** `69:3007`과 동기).

```tsx
<AvatarGroup size="medium" layout="spread">
  <Avatar size="medium">…</Avatar>
  <Avatar size="medium">…</Avatar>
</AvatarGroup>
```

## Props

`Avatar`의 **`className`**은 겹침·여백용 **바깥 래퍼**에만 붙습니다. 원 안쪽 배경·테두리만 바꿀 때는 **`innerClassName`**을 사용합니다.

### `Avatar`

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `src` | `string \| null` | — | 이미지 URL (`AvatarImage`가 있으면 그쪽 `src` 우선) |
| `alt` | `string` | `""` | 이미지 대체 텍스트·이니셜 추출 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 지름 32·36·56px — Figma `Avatar` Stack 행 `Small`/`Medium`/`XLarge` 및 MCP `Avatar` `size` `Medium`/`Large`/`XXLarge`와 대응(위 MCP 표) |
| `color` | `"neutral"` \| `"red"` \| `"orange"` | `"neutral"` | Web Kit `Avatar` `color`(MCP 세 가지) — 셸·기본 아이콘 톤 |
| `layout` | `"image"` \| `"icon"` \| `"initials"` | — | Web Kit `Avatar` `layout` — 합성 `AvatarFallback` 등이 있으면 그쪽 우선 |
| `showStatus` | `boolean` | `false` | Web Kit `showStatus` — `AvatarBadge`와 같은 상태 표시. `AvatarBadge` 자식이 있으면 그쪽만 렌더 |
| `status` | `"online"` \| `"away"` \| `"unavailable"` \| `"offline"` | `"online"` | `showStatus`일 때만 — Figma `Avatar/Status` 변형과 대응 |
| `innerClassName` | `string` | — | 원형 마스크 **안쪽** 면 전용 — 셸 배경·테두리 덮어쓸 때(`AvatarOverflow` 참고). 바깥 래퍼는 `className` |

### `AvatarOverflow`

More 타일 전용 — 흰 셸, `thin` + `neutral300` 테두리, `more-horizontal` 아이콘. `AvatarGroupCount`와 같은 테두리 규칙입니다.

### `AvatarGroup`

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 자식 `Avatar`와 겹침/간격 티어 |
| `layout` | `"stack"` \| `"spread"` | `"stack"` | 겹침(stack) / 간격 나열(spread) |

합성형 API: `AvatarImage`, `AvatarFallback`, `AvatarIcon`, `AvatarGroupCount`, `AvatarBadge` 등.
