# Badge

Badge is a compact label for status or a numeric count. Use it next to a heading, tab, avatar, or control when the extra signal should stay secondary to the main text.

A `label` badge is a capsule for a word or two (`New`, `Beta`). A `number` badge is circular and is meant for a count. For a keyword or filter the user can remove, use **[Tag](/components/tag/)**.

## Interface

### Badge

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"default"` | `"default"` \| `"neutral"` \| `"outline"` \| `"success"` \| `"warning"` \| `"danger"` — Color pairing for the badge. |
| `layout` | `"label"` | `"label"` \| `"number"` — Capsule text versus circular count. |

Also accepts native `span` attributes (`className`, `style`, `aria-*`).
