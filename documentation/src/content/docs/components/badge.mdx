# Badge

상태·라벨용 배지입니다. Web Kit Figma **Badge**(`270:3353`)와 동기화되어 있습니다.

## Props

- `variant` — `default` | `neutral` | `outline` | `success` | `warning` | `danger`

## Variants (Figma `color` 매핑)

- `default` — 검정 배경 · 흰 글자 (`Default`)
- `neutral` — 연한 회색 배경 · 검정 글자 (`Secondary` / `primaryLightGray`)
- `outline` — `neutral300` 테두리 · 투명 배경 (`Outline`)
- `success` — `green500` 배경 · 흰 글자
- `warning` — `orange500` 배경 · 흰 글자 (노랑이 아닌 오렌지 톤)
- `danger` — `red500` 배경 · 흰 글자

`@refineui/react/refineui.css`를 쓰면 hover·pressed 배경/테두리가 Figma 상태와 비슷하게 바뀝니다.
