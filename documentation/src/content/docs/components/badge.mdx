Status badge or numerical counter tag.

## Installation

```bash
bun add @refineui/react @refineui/tokens
```

## Usage

```tsx
import { Badge } from "@refineui/react";

<Badge>New</Badge>

<Badge variant="success">5</Badge>

<Badge variant="warning" layout="number">12</Badge>

<Badge variant="danger">Error</Badge>

<Badge variant="outline">Draft</Badge>
```
