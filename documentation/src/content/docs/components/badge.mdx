# Badge

Short status or count label. Web Kit **Badge** `270:3353` · **Badge Number** `276:515`. Hover and pressed states come from **`refineui.css`**.

## Install & import

```tsx
import { Badge } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Badge variant="default">New</Badge>
<Badge layout="number" variant="danger">
  9
</Badge>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default"` \| `"neutral"` \| `"outline"` \| `"success"` \| `"warning"` \| `"danger"` | — | Color pairing |
| `layout` | `"label"` \| `"number"` | `"label"` | Capsule vs circular count |

## Examples

### Count badge

```tsx
<Badge layout="number" variant="danger" aria-label="3 unread">
  3
</Badge>
```
