# Badge

짧은 상태·개수 표시에 씁니다. Web Kit **Badge** `270:3353` · **Badge Number** `276:515`를 따릅니다. Hover·pressed는 **`refineui.css`**입니다.

## 설치·임포트

```tsx
import { Badge } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Badge variant="default">New</Badge>
<Badge layout="number" variant="danger">
  9
</Badge>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `variant` | `"default"` \| `"neutral"` \| `"outline"` \| `"success"` \| `"warning"` \| `"danger"` | — | 색 조합 |
| `layout` | `"label"` \| `"number"` | `"label"` | 캡슐 / 원형 숫자 |

## 예시

### 개수 알림

```tsx
<Badge layout="number" variant="danger" aria-label="읽지 않음 3건">

</Badge>
```
