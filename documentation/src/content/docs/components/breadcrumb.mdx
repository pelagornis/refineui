# Breadcrumb

현재 위치까지의 경로를 보여 줍니다. Web Kit **Breadcrumb** `283:688`(Figma: Caption1 Medium, `gap` sizeMedium, `py` sizeSmall, 구분자 `/`, 링크 tertiary · 현재 primary)를 따릅니다.  
일반적인 **합성 컴포넌트** 패턴으로 조립합니다.

## 설치·임포트

```tsx
import {
  breadcrumbLinkClassName,
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbEllipsisTrigger,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
  Menu,
  MenuItem,
  MenuList,
  MenuPopover,
  MenuTrigger,
} from "@refineui/react";
```

## 기본 사용

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">홈</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/docs">문서</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>컴포넌트</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Next.js `Link` 와 함께

`BreadcrumbLink`는 시맨틱 `<a>`입니다. App Router에서는 **`breadcrumbLinkClassName`**을 `Link`에 넘겨 동일한 Web Kit 스타일을 맞춥니다.

```tsx
import Link from "next/link";
import { breadcrumbLinkClassName } from "@refineui/react";

<Link href="/" className={breadcrumbLinkClassName}>
  Home
</Link>
```

## 구성 요소

| 컴포넌트 | 역할 |
|----------|------|
| `Breadcrumb` | 루트 `nav` (`data-refineui="breadcrumb"`) |
| `BreadcrumbList` | `ol` 목록 (flex·wrap) |
| `BreadcrumbItem` | 각 세그먼트 `li` (기본 `overflow-clip` — ⋯ 메뉴 열 때는 아래 절 참고) |
| `BreadcrumbLink` | 이전 단계 링크 (`a`; Next.js 등은 `breadcrumbLinkClassName`) |
| `BreadcrumbPage` | 현재 페이지 (`aria-current="page"`) |
| `BreadcrumbSeparator` | 구분자 `li` (기본 `/`) |
| `BreadcrumbEllipsis` | ⋯ 아이콘만 (`span`, 정적 표시용) |
| `BreadcrumbEllipsisTrigger` | Web Kit ellipsis용 `button` (`ref` 전달) — `MenuTrigger` / `Dropdown` `trigger`에 사용 |

### 생략 + 메뉴 (Long)

Figma **Long**은 링크 / ⋯ / 링크 / 링크 / 현재 순입니다. **`BreadcrumbEllipsisTrigger`**(`button[data-refineui="breadcrumb-ellipsis"]`)를 쓰면 `refineui.css` 호버·포커스와 맞습니다. **`Button`**으로 감싸면 Web Kit 토큰 높이와 겹쳐 레이아웃이 어긋날 수 있습니다.

**메뉴 패널:** **`Menu`**(Web Kit `633:4268`) 컴파운드 API를 권장합니다(`MenuPreview` 참고).

**중요:** `BreadcrumbItem`은 시맨틱 셀마다 **`overflow-clip`** 이 기본이라, 패널이 **`absolute`** 인 **`Menu`** 는 세로로 펼칠 때 잘립니다. ⋯ 칸에는 **`className="overflow-visible"`** 을 함께 넣어 주세요. **`Dropdown`** 은 메뉴를 **`document`** 로 포털 처리하므로 보통 같은 제약이 없습니다.

```tsx
<BreadcrumbItem className="overflow-visible">
  <Menu positioning={{ autoSize: true }}>
    <MenuTrigger>
      <BreadcrumbEllipsisTrigger aria-label="경로 메뉴" />
    </MenuTrigger>
    <MenuPopover>
      <MenuList className="w-refineui-menu-panel-width">
        <MenuItem onClick={() => {}}>문서</MenuItem>
        <MenuItem onClick={() => {}}>가이드</MenuItem>
      </MenuList>
    </MenuPopover>
  </Menu>
</BreadcrumbItem>
```
