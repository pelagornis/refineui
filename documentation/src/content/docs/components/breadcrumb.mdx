# Breadcrumb

Shows the path to the current location. Follows Web Kit **Breadcrumb** `283:688` (Figma: Caption1 Medium, `gap` sizeMedium, `py` sizeSmall, `/` separator, link tertiary · current primary).  
Use the usual **composed component** pattern. For top-level site navigation with dropdown panels, use [Navigation Menu](/components/navigation-menu/).

## Install & import

```tsx
import {
  breadcrumbLinkClassName,
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbEllipsisTrigger,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
  Menu,
  MenuItem,
  MenuList,
  MenuPopover,
  MenuTrigger,
} from "@refineui/react";
```

## Basic usage

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/docs">Docs</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Components</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## With Next.js `Link`

`BreadcrumbLink` is a semantic `<a>`. In the App Router, pass **`breadcrumbLinkClassName`** to `Link` for the same Web Kit styles.

```tsx
import Link from "next/link";
import { breadcrumbLinkClassName } from "@refineui/react";

<Link href="/" className={breadcrumbLinkClassName}>
  Home
</Link>
```

## Building blocks

| Component | Role |
|-----------|------|
| `Breadcrumb` | Root `nav` (`data-refineui="breadcrumb"`) |
| `BreadcrumbList` | `ol` list (flex·wrap) |
| `BreadcrumbItem` | Segment `li` (default `overflow-clip` — see ellipsis note below) |
| `BreadcrumbLink` | Previous-step link (`a`; Next.js uses `breadcrumbLinkClassName`) |
| `BreadcrumbPage` | Current page (`aria-current="page"`) |
| `BreadcrumbSeparator` | Separator `li` (default `/`) |
| `BreadcrumbEllipsis` | ⋯ icon only (`span`, static) |
| `BreadcrumbEllipsisTrigger` | Web Kit ellipsis `button` (`ref` pass-through) — use with `MenuTrigger` / Dropdown `trigger` |

### Ellipsis + menu (Long)

Figma **Long** is link / ⋯ / link / link / current. **`BreadcrumbEllipsisTrigger`** (`button[data-refineui="breadcrumb-ellipsis"]`) matches `refineui.css` hover/focus. Wrapping with **`Button`** can misalign heights vs Web Kit tokens.

**Menu panel:** Prefer the **`Menu`** compound API (Web Kit `633:4268`; see `MenuPreview`).

**Important:** `BreadcrumbItem` defaults to **`overflow-clip`** per cell, so an **`absolute`** **`Menu`** panel can clip when expanding vertically. Add **`className="overflow-visible"`** on the ⋯ cell.

**`Dropdown`** portals the menu to **`document`**, so it usually avoids this clipping.

```tsx
<BreadcrumbItem className="overflow-visible">
  <Menu positioning={{ autoSize: true }}>
    <MenuTrigger>
      <BreadcrumbEllipsisTrigger aria-label="Path menu" />
    </MenuTrigger>
    <MenuPopover>
      <MenuList className="w-refineui-menu-panel-width">
        <MenuItem onClick={() => {}}>Docs</MenuItem>
        <MenuItem onClick={() => {}}>Guide</MenuItem>
      </MenuList>
    </MenuPopover>
  </Menu>
</BreadcrumbItem>
```
