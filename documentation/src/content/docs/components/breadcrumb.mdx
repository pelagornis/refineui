# Breadcrumb

Breadcrumb shows where the current page sits in the hierarchy. Use it under the header so the user can step back toward home without using the browser back button.

Each previous step is a link; the last step is the current page. For top-level site destinations with flyouts, use **[Navigation Menu](/components/navigation-menu/)**. For a single in-copy URL, use **[Link](/components/link/)**.

## Interface

### Parts

| Part | Role |
|------|------|
| `Breadcrumb` | Root `nav`. |
| `BreadcrumbList` | Ordered list (`ol`). |
| `BreadcrumbItem` | Segment (`li`). Defaults to clipping overflow — set `overflow-visible` on a menu cell. |
| `BreadcrumbLink` | Previous-step link (`a`). |
| `BreadcrumbPage` | Current page. |
| `BreadcrumbSeparator` | Separator (`li`). Default `/`. |
| `BreadcrumbEllipsis` | Static ⋯ (`span`). |
| `BreadcrumbEllipsisTrigger` | ⋯ `button` for a menu trigger. Forwards `ref`. |
| `breadcrumbLinkClassName` | Class string to style a custom `Link` like `BreadcrumbLink`. |

Parts accept the matching native attributes (`nav`, `ol`, `li`, `a`, `span`, `button`).
