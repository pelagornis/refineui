# Breadcrumb

현재 위치까지의 경로를 보여 줍니다. Web Kit **Breadcrumb** `283:688`(Figma: Caption1 Medium, `gap` sizeMedium, `py` sizeSmall, 구분자 `/`, 링크 tertiary · 현재 primary)를 따릅니다.  
[shadcn/ui](https://ui.shadcn.com/docs/components/breadcrumb)처럼 **합성 컴포넌트**로 조립합니다.

## 설치·임포트

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbEllipsisTrigger,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@refineui/react";
```

## 기본 사용

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">홈</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/docs">문서</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>컴포넌트</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Next.js `Link` 와 함께 (`asChild`)

```tsx
import Link from "next/link";

<BreadcrumbLink asChild>
  <Link href="/">Home</Link>
</BreadcrumbLink>
```

## 구성 요소

| 컴포넌트 | 역할 |
|----------|------|
| `Breadcrumb` | 루트 `nav` (`data-refineui="breadcrumb"`) |
| `BreadcrumbList` | `ol` 목록 (flex·wrap) |
| `BreadcrumbItem` | 각 세그먼트 `li` |
| `BreadcrumbLink` | 이전 단계 링크 (`a` 또는 `asChild`) |
| `BreadcrumbPage` | 현재 페이지 (`aria-current="page"`) |
| `BreadcrumbSeparator` | 구분자 `li` (기본 `/`) |
| `BreadcrumbEllipsis` | ⋯ 아이콘만 (`span`, 정적 표시용) |
| `BreadcrumbEllipsisTrigger` | Web Kit ellipsis용 `button` (`ref` 전달) — `Dropdown` `trigger`에 사용 |

### 생략 + 메뉴 (Long)

Figma **Long**은 링크 / ⋯ / 링크 / 링크 / 현재 순입니다. `Dropdown` 트리거는 **`BreadcrumbEllipsisTrigger`**(`button[data-refineui="breadcrumb-ellipsis"]`)를 쓰면 `refineui.css` 호버·포커스와 맞습니다. `Button`으로 감싸면 Web Kit 토큰 높이와 겹쳐 레이아웃이 어긋날 수 있습니다.

```tsx
<BreadcrumbItem>
  <Dropdown
    align="start"
    trigger={<BreadcrumbEllipsisTrigger aria-label="경로 메뉴" />}
    items={[
      { id: "1", label: "문서", onClick: () => {} },
      { id: "2", label: "가이드", onClick: () => {} },
    ]}
  />
</BreadcrumbItem>
```
