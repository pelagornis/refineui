# Bubble

Bubble is the message surface in a conversation. Use it for chat text, short structured replies, and emoji reactions. Avatars, display names, and timestamps belong in the row around the bubble — not inside `Bubble`.

Incoming messages usually sit at `align="start"`; outgoing at `align="end"`. For long copy that needs show more / show less, compose **[Accordion](/components/accordion/)** inside `BubbleContent`.

## Interface

### Bubble

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"default"` | `"default"` \| `"secondary"` \| `"muted"` \| `"tinted"` \| `"outline"` \| `"ghost"` \| `"destructive"` — Visual treatment. `ghost` is unframed. |
| `align` | `"start"` | `"start"` \| `"end"` — Inline alignment in the column. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### BubbleReactions

| Prop | Default | Type |
|------|---------|------|
| `side` | `"bottom"` | `"top"` \| `"bottom"` — Edge of the bubble to attach to. |
| `align` | opposite of `Bubble` | `"start"` \| `"end"` — Inline inset. Defaults toward the conversation center. |

### Parts

| Part | Role |
|------|------|
| `BubbleContent` | Message body. Inherits variant styles from `Bubble`. |
| `BubbleGroup` | Stack of consecutive bubbles from the same sender. |
