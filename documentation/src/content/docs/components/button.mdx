# Button

클릭 가능한 액션을 나타냅니다. Web Kit **Button** `79:3304`와 `docs/design-specs-web-kit.md` §1을 따릅니다. Figma에서는 **`Style`**(variant)·**`Size`**·**`Layout`**(라벨 / 아이콘만) 조합으로 정의됩니다. **`@refineui/react/refineui.css`**를 불러오면 hover·active·focus-visible 스타일이 적용됩니다.

## 설치·임포트

```tsx
import { Button } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Button type="button" onClick={() => console.log("clicked")}>
  저장
</Button>
```

`type`을 생략하면 기본값은 **`button`** 입니다(폼 안에서 의도치 않은 submit을 막기 위함).

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `variant` | `"primary"` \| `"secondary"` \| `"outline"` \| `"ghost"` | `"primary"` | Figma `Style`과 동일 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 최소 높이·패딩·타이포(`Layout=Label`) 또는 아이콘 히트 영역(`Layout=Icon`) |
| `layout` | `"label"` \| `"icon"` | `"label"` | Figma **`Layout`**: 텍스트(및 선택 시 좌우 아이콘) vs **아이콘만** |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | — | 비활성 |

나머지는 **`ButtonHTMLAttributes`** (`onClick`, `type`, `aria-*`, `className` 등)를 지원합니다.

## Variants

| 값 | 용도 |
|----|------|
| `primary` | 주요 액션 — 검정 배경 |
| `secondary` | 보조 — 흰 배경 + 테두리 |
| `outline` | 덜 강조 — 투명 배경 + 테두리 |
| `ghost` | 텍스트 수준 — 배경·테두리 최소 |

## Sizes

`layout="label"`(기본)일 때 행 높이·좌우 패딩·타이포가 Size에 따라 달라집니다.

| 값 | 대략적 최소 높이 |
|----|------------------|
| `sm` | 28px |
| `md` | 36px |
| `lg` | 48px |

## Layout · 아이콘만 (`layout="icon"`)

Figma **Button** `79:3304`에는 **`Layout=Icon`** 변형이 따로 있습니다. **텍스트 없이** `children`으로 `WebIcon` 등만 넣을 때 사용합니다.

- **히트 영역**: `Size`와 동일한 **정사각**(`sm` 28×28, `md` 36×36, `lg` 48×48).
- **패딩·모서리**: Web Kit MCP 기준 — `sm`은 전면 `sizeXSmall`(4px) + `roundedSmall`, `md`는 `sizeSmall`(6px) + `roundedMedium`, `lg`는 `sizeMedium`(10px) + `roundedLarge`. (MCP에서 **Primary·Ghost** `Layout=Icon`은 테두리 없음 — 구현도 `border-0`로 라벨용 `border` 1px이 안쪽을 잡아먹지 않게 맞춤.)
- **아이콘 글리프 크기(MCP 슬롯)**: `sm` → `iconSizes.small`(20px), `md` → `iconSizes.medium`(24px), `lg` → `iconSizes.large`(28px).
- **접근성**: 보이는 레이블이 없으면 **`aria-label`**(또는 `aria-labelledby`)을 필수로 두세요.

`variant="ghost"` + `layout="icon"` + `size="sm"` 조합은 **Dialog** 헤더 닫기 버튼(`393:1181`)과 같은 축입니다.

### Dialog 닫기 예시

```tsx
import { Button, WebIcon } from "@refineui/react";
import { iconSizes } from "@refineui/tokens";

<Button type="button" variant="ghost" size="sm" layout="icon" aria-label="닫기" onClick={onClose}>
  <WebIcon name="dismiss" size={iconSizes.small} color="currentColor" iconStyle="regular" aria-hidden />
</Button>
```

## 예시

### 링크처럼 쓰기

```tsx
<Button variant="ghost" type="button" onClick={openPanel}>
  더 보기
</Button>
```

### 전체 너비

```tsx
<Button variant="primary" fullWidth type="submit">
  가입 완료
</Button>
```

### 비활성

```tsx
<Button variant="primary" disabled>
  처리 중…
</Button>
```

## 접근성

- 키보드 포커스 시 `refineui.css`가 **focus-visible** 링을 그립니다.
- 의미 있는 레이블이 없을 때는 `aria-label`을 고려하세요.
