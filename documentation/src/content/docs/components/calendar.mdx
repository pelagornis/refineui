# Calendar

월 그리드에서 날짜를 고릅니다. Web Kit **Calendar / Day** MCP `639:7052` · `docs/design-specs-web-kit.md` Calendar 절을 따릅니다.

## 설치·임포트

```tsx
import { Calendar } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용 (단일)

```tsx
const [d, setD] = useState(new Date());
<Calendar mode="single" value={d} onChange={setD} />;
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `mode` | `"single"` \| `"range"` | 기본 `single` |
| `value` | `Date` | 단일 선택 값 |
| `onChange` | `(date: Date) => void` | 단일 모드 변경 |
| `rangeStart` / `rangeEnd` | `Date` | 범위 모드 |
| `onRangeChange` | `(start, end) => void` | 범위 변경 |
| `weekStartsOn` | `0` \| `1` | 0=일요일 시작 |
| `defaultMonth` | `Date` | 초기 표시 월 |

## 예시

### 범위 선택

```tsx
<Calendar
  mode="range"
  rangeStart={start}
  rangeEnd={end}
  onRangeChange={(s, e) => {
    setStart(s);
    setEnd(e);
  }}
/>
```
