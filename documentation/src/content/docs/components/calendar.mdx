# Calendar

Calendar is a month grid for picking dates. Use it when the user chooses a day, or a start and end, from a visible calendar — booking, filters, or a date field overlay.

Single mode takes one `Date`. Range mode takes a start and an end. For typing a date without a grid, use **[Input](/components/input/)** (or a date field you compose). Calendar is not a date-time picker.

## Interface

### Calendar

| Prop | Default | Type |
|------|---------|------|
| `mode` | `"single"` | `"single"` \| `"range"` — One day, or a start and end. |
| `value` | — | `Date` — Selected day in single mode. |
| `onChange` | — | `(date: Date) => void` — Called when a day is picked in single mode. |
| `rangeStart` | — | `Date` — Range start. |
| `rangeEnd` | — | `Date` — Range end. |
| `onRangeChange` | — | `(start: Date \| undefined, end: Date \| undefined) => void` — Called as the range is built. Either end may be `undefined` while the user is still picking. |
| `weekStartsOn` | `0` | `0` \| `1` — `0` is Sunday; `1` is Monday. |
| `defaultMonth` | — | `Date` — Initial visible month when no `value` or `rangeStart` is set. |

Also accepts native `div` attributes (`className`, `style`).
