# Calendar

Pick dates from a month grid. Follows Web Kit **Calendar / Day** MCP `639:7052` and the Calendar section in `docs/design-specs-web-kit.md`.

## Install & import

```tsx
import { Calendar } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage (single)

```tsx
const [d, setD] = useState(new Date());
<Calendar mode="single" value={d} onChange={setD} />;
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `mode` | `"single"` \| `"range"` | Default `single` |
| `value` | `Date` | Single selection |
| `onChange` | `(date: Date) => void` | Single mode change |
| `rangeStart` / `rangeEnd` | `Date` | Range mode |
| `onRangeChange` | `(start, end) => void` | Range change |
| `weekStartsOn` | `0` \| `1` | 0 = week starts Sunday |
| `defaultMonth` | `Date` | Initial visible month |

## Examples

### Range selection

```tsx
<Calendar
  mode="range"
  rangeStart={start}
  rangeEnd={end}
  onRangeChange={(s, e) => {
    setStart(s);
    setEnd(e);
  }}
/>
```
