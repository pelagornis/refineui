# Card

카드 컴포넌트입니다. Web Kit과 같이 **그림자(elevated)** 또는 **테두리(outlined)** 를 선택할 수 있습니다.

## Preview

<div class="not-content">
  <CardPreview client:load />
</div>

## Props

- `variant` — `elevated`(기본, Shadow 4) | `outlined` (hairline 테두리)

## 예시

```tsx
import { Card } from "@refineui/react";

<Card variant="elevated">
  <h3>제목</h3>
  <p>내용</p>
</Card>
```
