# Card

Container for content. Follows Web Kit **Card** and `docs/design-specs-web-kit.md` §7.

## Install & import

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardHeaderMain,
  CardTitle,
} from '@refineui/react';
```

## Basic usage

`Card` is only the **root container**; inside it use **`CardHeader` · `CardContent` · `CardFooter`**, etc. Like Web Kit §7, the root uses `gap` between regions and padding lives on each slot.

For a title, description, and right-side action (e.g. Sign up), wrap the title block with **`CardHeaderMain`** and place **`CardAction`** beside it.

```tsx
import { Button } from '@refineui/react';

<Card className='w-full max-w-sm'>
  <CardHeader>
    <CardHeaderMain>
      <CardTitle>Login to your account</CardTitle>
      <CardDescription>Enter your email below to login to your account</CardDescription>
    </CardHeaderMain>
    <CardAction>
      <Button variant='ghost' type='button'>
        Sign Up
      </Button>
    </CardAction>
  </CardHeader>
  <CardContent></CardContent>
  <CardFooter className='flex-col gap-refineui-size-small'>
    <Button type='button' className='w-full'>
      Login
    </Button>
  </CardFooter>
</Card>;
```

`Button variant="link"` is not in Web Kit; for a link-like control use the **`Link`** component or **`Button variant="ghost"`** plus optional `className` for underline.

### Simple block

For body-only content without a header, add vertical padding on `CardContent` via `className`.

```tsx
<Card>
  <CardContent className='py-refineui-size-large'>
    <p className='refineui-typo-body-2 text-refineui-neutral-600'>Body only</p>
  </CardContent>
</Card>
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `variant` | `"elevated"` \| `"outlined"` | `"elevated"` | Shadow or border |
| `state` | `"default"` \| `"hover"` \| `"pressed"` \| `"disabled"` | `"default"` | Force visual state |
| `interactive` | `boolean` | `false` | Hover/active interaction |

Other props follow **`HTMLAttributes<HTMLDivElement>`** (`className`, `style`, `onClick`, etc.).  
`CardHeader`, `CardContent`, `CardFooter`, etc. can override layout with `className` the same way.

## Examples

### Outlined only

```tsx
import { Card, CardContent } from '@refineui/react';

<Card variant='outlined'>
  <CardContent className='py-refineui-size-large'>Settings panel</CardContent>
</Card>;
```

### Elevated (default)

```tsx
import { Card, CardContent } from '@refineui/react';

<Card variant='elevated'>
  <CardContent className='py-refineui-size-large'>Dashboard widget</CardContent>
</Card>;
```

### State preview

```tsx
<Card state='hover'>
  <CardHeader>
    <CardHeaderMain>
      <CardTitle>RefineUI is now available</CardTitle>
      <CardDescription>RefineUI Description</CardDescription>
    </CardHeaderMain>
  </CardHeader>
  <CardContent>RefineUI web represents a collection of utilities.</CardContent>
</Card>
```
