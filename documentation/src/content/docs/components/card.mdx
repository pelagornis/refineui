# Card

Card is a container for related content. Use it when a title, supporting copy, and actions should read as one unit — a login panel, a feature summary, or a selectable option.

The root is only the shell. Compose **`CardHeader`**, **`CardContent`**, and **`CardFooter`** inside it. Padding lives on those slots; the root spaces them with gap.

## Interface

### Card

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"elevated"` | `"elevated"` \| `"outlined"` — Shadowed surface versus bordered surface. |
| `interactive` | `false` | `boolean` — Enables hover and pressed interaction chrome. |
| `state` | `"default"` | `"default"` \| `"hover"` \| `"pressed"` \| `"disabled"` — Forced visual state. `disabled` sets `aria-disabled`. |

Also accepts native `div` attributes (`className`, `style`, `onClick`, `aria-*`).

### Parts

| Part | Role |
|------|------|
| `CardHeader` | Top row: title block and optional action. |
| `CardHeaderMain` | Title and description column. |
| `CardTitle` | Heading (`h3`). |
| `CardDescription` | Supporting copy (`p`). |
| `CardAction` | Trailing slot in the header (menus, sign-up, overflow). |
| `CardContent` | Main body. |
| `CardFooter` | Actions row. |
