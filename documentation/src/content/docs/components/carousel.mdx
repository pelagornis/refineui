# Carousel

Carousel is a horizontal slide stage. Use it when a few full-width panels should move as a sequence — product shots, onboarding cards — and the user can drag, swipe, or step through them.

Nav never overlays the stage. Put Previous, Indicators, and Next inside `CarouselControls` under the content. For split panes the user resizes, use **[Resizable](/components/resizable/)**. For overflow without paging, use **[Scroll Area](/components/scroll-area/)**.

## Interface

### Carousel

| Prop | Default | Type |
|------|---------|------|
| `index` | — | `number` — Controlled slide index (0-based). |
| `defaultIndex` | `0` | `number` — Uncontrolled start. |
| `onIndexChange` | — | `(index: number) => void` — Called when the logical index changes. |
| `loop` | `false` | `boolean` — Wrap from last to first and first to last. |

Also accepts native `div` attributes (`className`, `style`). The root is focusable.

### Parts

| Part | Role |
|------|------|
| `CarouselContent` | Stage + drag surface. |
| `CarouselItem` | Full-width slide. |
| `CarouselControls` | Bottom row for nav and the indicator. |
| `CarouselPrevious` / `CarouselNext` | Outline icon `Button`s. Native `button` attributes; `disabled` also follows the ends when `loop` is off. |
| `CarouselIndicators` | Sliding brand pill in a track. |
