# Chart

Chart is a composable SVG chart for a single series of numbers. Use it when you need bars or a line in a card — monthly revenue, active users — and a title already explains the series.

Single-series charts do not need a legend; the card title is enough. Hover and click use `data-state` (`default` / `hover` / `selected`) plus an optional `ChartTooltip`. For tabular values the user must compare cell by cell, use **[Table](/components/table/)** instead.

## Interface

### ChartBars

| Prop | Default | Type |
|------|---------|------|
| `values` | — | `number[]` — Data points. Required. |
| `max` | auto | `number` — Y scale maximum. Nice-rounded from `values` when omitted. |
| `seriesColor` | `"brand"` | `"brand"` \| `"info"` \| `"success"` \| `"warning"` \| `"error"` \| `"discovery"` — Semantic series color. |
| `showTrack` | `false` | `boolean` — Full-height track behind each bar. |

### ChartLine

| Prop | Default | Type |
|------|---------|------|
| `values` | — | `number[]` — Data points. Required. |
| `max` | auto | `number` — Y scale maximum. Nice-rounded from `values` when omitted. |
| `seriesColor` | `"brand"` | `"brand"` \| `"info"` \| `"success"` \| `"warning"` \| `"error"` \| `"discovery"` — Semantic series color. |
| `showArea` | `false` | `boolean` — Area fill under the line. |
| `showPoints` | `false` | `boolean` — Point markers on each value. Hover still shows the active point when this is `false`. |

### ChartGrid / ChartYAxisLabels

| Prop | Default | Type |
|------|---------|------|
| `lines` | `5` | `number` — Tick / grid line count (includes the baseline). |
| `values` | — | `number[]` — Derive a nice Y scale when `max` is omitted. |
| `max` | auto | `number` — Fixed Y scale. |

`ChartYAxisLabels` also accepts `formatTick?: (value: number) => string`.

### ChartAxisLabels

| Prop | Default | Type |
|------|---------|------|
| `labels` | — | `string[]` — Category labels. Required. |
| `align` | `"bar"` | `"bar"` \| `"line"` — Center on bar bands or line points. |

### ChartPlot

| Prop | Default | Type |
|------|---------|------|
| `aria-label` | — | `string` — Accessible name for the chart graphic (`role="img"`). |

### ChartLegendItem

| Prop | Default | Type |
|------|---------|------|
| `seriesColor` | — | `"brand"` \| `"info"` \| `"success"` \| `"warning"` \| `"error"` \| `"discovery"` — Swatch color. Required. |

### Parts

| Part | Role |
|------|------|
| `Chart` | Root + hover / selected context. |
| `ChartBody` | Y-axis + plot row. |
| `ChartContent` | Plot + X-axis column. |
| `ChartYAxisLabels` | Left Y-axis tick labels (`aria-hidden`). |
| `ChartPlot` | Plot frame + SVG viewport. |
| `ChartGrid` | Horizontal grid lines. |
| `ChartTooltip` | Hover value. Place inside `ChartPlot`. |
| `ChartLegend` | Optional list for multiple series. |
| `ChartLegendItem` | One legend row + swatch. |
