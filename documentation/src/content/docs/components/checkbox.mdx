# Checkbox

Checkbox input. Follows Web Kit **Checkbox** `327:2539`. **`refineui.css`** adds hover, checked, and focus-visible styles.

## Install & import

```tsx
import { Checkbox } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Checkbox name="agree" defaultChecked={false} aria-label="Accept terms" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default"` \| `"circular"` | `"default"` | Square vs circular |
| `disabled` | `boolean` | — | Disabled |

Other props from **`InputHTMLAttributes`** except `type` (`checked`, `defaultChecked`, `onChange`, `name`, etc.).

## Examples

### Controlled

```tsx
const [on, setOn] = useState(false);
<Checkbox checked={on} onChange={(e) => setOn(e.target.checked)} />;
```

### Circular (radio-like appearance)

```tsx
<Checkbox variant="circular" aria-label="Enable notifications" />
```
