# Checkbox

체크박스 입력입니다. Web Kit **Checkbox** `327:2539`를 따릅니다. **`refineui.css`**에서 hover·checked·focus-visible을 보강합니다.

## 설치·임포트

```tsx
import { Checkbox } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Checkbox name="agree" defaultChecked={false} aria-label="약관 동의" />
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `variant` | `"default"` \| `"circular"` | `"default"` | 사각 / 원형 |
| `disabled` | `boolean` | — | 비활성 |

그 외 **`InputHTMLAttributes`**에서 `type`을 제외한 속성(`checked`, `defaultChecked`, `onChange`, `name` 등)을 사용합니다.

## 예시

### 제어 컴포넌트

```tsx
const [on, setOn] = useState(false);
<Checkbox checked={on} onChange={(e) => setOn(e.target.checked)} />;
```

### 원형 (라디오형 외형의 체크)

```tsx
<Checkbox variant="circular" aria-label="알림 받기" />
```
