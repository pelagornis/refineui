# Checkbox

Checkbox lets the user turn a single option on or off. Use it for agreements, preferences, and lists where more than one item can be selected.

For a mutually exclusive set, use **[Radio](/components/radio/)**. For an immediate on/off with no label in the control itself, use **[Switch](/components/switch/)**.

## Interface

### Checkbox

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"default"` | `"default"` \| `"circular"` — Square vs circular control. |
| `label` | — | `string` — Primary name beside the control. |
| `description` | — | `string` — Supporting line under the label. |
| `disabled` | — | `boolean` — Blocks interaction. |

Also accepts native `input` attributes except `type` (`checked`, `defaultChecked`, `onChange`, `name`, `id`, `aria-*`, `className`).
