# Command

Command is a composable command palette: search, groups, and keyboard selection. Use it for jump-to actions, settings search, or a list the user filters by typing.

The query control is **[Search Field](/components/search-field/)**. List chrome follows **[Menu](/components/menu/)**. `CommandDialog` wraps **[Dialog](/components/dialog/)** at `size="lg"` with no panel padding so the command chrome fills the modal.

## Interface

### Command

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Controlled search query. |
| `defaultValue` | — | `string` — Uncontrolled initial query. |
| `onValueChange` | — | `(search: string) => void` — Query change. |
| `shouldFilter` | `true` | `boolean` — When `false`, items are not filtered locally. |
| `filter` | substring match | `(value: string, search: string, keywords?: string[]) => number` — Score; `0` hides the item. |
| `selectedValue` | — | `string` — Controlled highlighted item `value`. |
| `defaultSelectedValue` | — | `string` — Uncontrolled initial highlight. |
| `onSelectedValueChange` | — | `(value: string) => void` — Highlight change. |
| `label` | `"Command menu"` | `string` — Accessible name (`aria-label`) for the root and input. |

Also accepts native `div` attributes (`className`, `style`, `onKeyDown`).

### CommandDialog

Extends **[Dialog](/components/dialog/)** (`open`, `defaultOpen`, `onOpenChange`, `size`).

| Prop | Default | Type |
|------|---------|------|
| `size` | `"lg"` | `"lg"` \| `"sm"` — Dialog panel size. |
| `commandProps` | — | `Omit<CommandProps, "children">` — Forwarded to the inner `Command`. |

### CommandInput

| Prop | Default | Type |
|------|---------|------|
| `placeholder` | `"Type a command or search…"` | `string` — Input placeholder. |
| `startIcon` | search glyph | `ReactNode` — Leading icon in the search field. |
| `disabled` | — | `boolean` — Disables the search field. |

Omits native `value` / `onChange` / `size` — the query is owned by `Command`.

### CommandItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Identity for filter, highlight, and `onSelect`. Required. |
| `keywords` | — | `string[]` — Extra strings included in the default filter. |
| `onSelect` | — | `(value: string) => void` — Click or Enter. |
| `forceMount` | `false` | `boolean` — Keep mounted when filtered out. |
| `startIcon` | — | `ReactNode` — Leading icon. |
| `endIcon` | — | `ReactNode` — Trailing icon (with shortcut). |
| `shortcut` | — | `ReactNode` — Trailing hint. `CommandShortcut` children are also collected. |
| `disabled` | `false` | `boolean` — Visible but not activatable. |

Also accepts native `button` attributes (`className`, `onClick`).

### Parts

| Part | Role |
|------|------|
| `CommandList` | Scrollable listbox. |
| `CommandEmpty` | Shown when the query has no visible items. |
| `CommandGroup` | Group; hides when empty after filter. |
| `CommandGroupHeading` | Group label. |
| `CommandSeparator` | Horizontal divider. |
| `CommandShortcut` | Trailing keyboard hint as a child of `CommandItem`. |
