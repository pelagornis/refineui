# Dialog

Dialog is a modal panel with a scrim. Use it when the user must finish or dismiss a task before continuing — confirmations, short forms, or blocking messages.

It portals to `document.body` (or `DialogContent` `container`), traps focus, and closes on Escape or scrim click. For a side panel that does not cover the whole flow, use **[Drawer](/components/drawer/)**. For extra context next to a control, use **[Popover](/components/popover/)**. For a searchable action list inside a large dialog, use **[Command](/components/command/)**.

## Interface

### Dialog

| Prop | Default | Type |
|------|---------|------|
| `open` | — | `boolean` — Controlled visibility. |
| `defaultOpen` | — | `boolean` — Uncontrolled initial open. Omit for closed. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when the dialog requests open or close. |
| `size` | `"lg"` | `"lg"` \| `"sm"` — Panel max width (`lg` 600px / `sm` 300px tokens). |

### DialogContent

| Prop | Default | Type |
|------|---------|------|
| `container` | `document.body` | `Element` \| `DocumentFragment` \| `null` — Portal root. |
| `scrollable` | `true` | `boolean` — When `true`, children wrap in a hover **[ScrollArea](/components/scroll-area/)**. Set `false` when a child (for example Command) owns scrolling. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### DialogHeader

| Prop | Default | Type |
|------|---------|------|
| `showClose` | `true` | `boolean` — Renders `DialogClose` in the header. |

### DialogTrigger

Same props as **[Button](/components/button/)** (`variant`, `size`, `type`, and so on). Click opens the dialog unless `preventDefault()` is called.

### Parts

| Part | Role |
|------|------|
| `DialogTitle` | `h2`, wired to `aria-labelledby`. |
| `DialogDescription` | `p`, wired to `aria-describedby`. |
| `DialogClose` | Ghost icon button that closes the dialog. Included in the header by default. |
