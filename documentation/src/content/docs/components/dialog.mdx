# Dialog

Use **`Dialog`**, **`DialogTrigger`**, **`DialogContent`**, etc. as **composed** components. Follows Web Kit **Dialog** `393:1181` and the Dialog section in `docs/design-specs-web-kit.md`. Renders with **`createPortal`** to `document.body` (or `DialogContent` `container`) with a focus trap.

## Install & import

```tsx
import {
    Dialog,
    DialogContent,
    DialogDescription,
    DialogHeader,
    DialogTitle,
    DialogTrigger,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Dialog>
    <DialogTrigger type="button">Open</DialogTrigger>
    <DialogContent>
        <DialogHeader>
            <DialogTitle>Title</DialogTitle>
            <DialogDescription>Description paragraph.</DialogDescription>
        </DialogHeader>
        <p>More body copy</p>
    </DialogContent>
</Dialog>
```

## Controlled mode

Control open state with `open` and `onOpenChange`.

```tsx
const [open, setOpen] = useState(false);

<Dialog open={open} onOpenChange={setOpen}>
    <DialogTrigger type="button">Open</DialogTrigger>
    <DialogContent>...</DialogContent>
</Dialog>;
```

For uncontrolled usage, pass `defaultOpen` only.

## Subcomponents

| Component | Description |
|-----------|-------------|
| `Dialog` | Context root. `size`, `open` / `onOpenChange`, `defaultOpen` |
| `DialogTrigger` | Opens dialog — same props as Web Kit `Button` (`variant`, `size`, etc.) |
| `DialogContent` | Scrim + panel portal. Optional `container` for portal root |
| `DialogHeader` | Title region + close button (`showClose`, default `true`) |
| `DialogTitle` | `h2`, wired to `aria-labelledby` |
| `DialogDescription` | `p`, wired to `aria-describedby` |
| `DialogClose` | Close control (included in header by default; can be used alone) |

## Props (`Dialog`)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled visibility |
| `onOpenChange` | `(open: boolean) => void` | — | Open state change |
| `defaultOpen` | `boolean` | — | Uncontrolled initial open |
| `size` | `"lg"` \| `"sm"` | `"lg"` | Panel width (Large 600px / Small 300px tokens) |

`DialogContent` accepts standard div props and `container`, etc. `DialogTrigger` matches the `Button` API.

## Examples

### Small confirmation

```tsx
<Dialog size="sm">
    <DialogTrigger type="button">Delete</DialogTrigger>
    <DialogContent>
        <DialogHeader>
            <DialogTitle>Delete this item?</DialogTitle>
            <DialogDescription>This action cannot be undone.</DialogDescription>
        </DialogHeader>
    </DialogContent>
</Dialog>
```
