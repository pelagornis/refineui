# Divider

**Horizontal** separator between content. Web Kit **Divider** `346:722`. **Vertical dividers are not supported.**

## Install & import

```tsx
import { Divider } from "@refineui/react";
```

## Layout

| `layout` | Description |
|----------|-------------|
| `default` | Full-width 1px line |
| `content` | Text in the middle (or per `align`) with lines on both sides |
| `icon` | Icon slot in the middle with lines (`children` for icon, etc.) |

For `content` and `icon`, `align` is `"center"` \| `"left"` \| `"right"` (horizontal alignment).

## Basic usage

```tsx
<Divider />
```

## Examples

### Text in the middle

```tsx
<Divider layout="content" align="center">
  or
</Divider>
```

### Icon

```tsx
<Divider layout="icon" align="center">
  <span aria-hidden>◎</span>
</Divider>
```
