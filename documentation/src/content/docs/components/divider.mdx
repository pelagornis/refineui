# Divider

콘텐츠를 나누는 **수평** 구분선입니다. Web Kit **Divider** `346:722`를 따릅니다. **세로 Divider는 지원하지 않습니다.**

## 설치·임포트

```tsx
import { Divider } from "@refineui/react";
```

## 레이아웃

| `layout` | 설명 |
|----------|------|
| `default` (기본) | 전폭 1px 선 |
| `content` | 가운데(또는 `align`에 따라) 텍스트 + 양쪽 선 |
| `icon` | 가운데 아이콘 슬롯 + 양쪽 선 (`children`에 아이콘 등) |

`content`·`icon`에서 `align`은 `"center"` \| `"left"` \| `"right"` (수평 정렬).

## 기본 사용

```tsx
<Divider />
```

## 예시

### 텍스트 구분

```tsx
<Divider layout="content" align="center">
  또는
</Divider>
```

### 아이콘

```tsx
<Divider layout="icon" align="center">
  <span aria-hidden>◎</span>
</Divider>
```
