# Divider

Divider is a horizontal separator. Use it to split stacked content — a form from a footer, or two blocks in a column — when spacing alone is not enough.

It is horizontal only. There is no vertical divider. For in-page section switching, use **[Tabs](/components/tabs/)**. For chat or list grouping, prefer layout gap or **[Bubble](/components/bubble/)** grouping instead of a line.

## Interface

### Divider

| Prop | Default | Type |
|------|---------|------|
| `layout` | `"default"` | `"default"` \| `"content"` \| `"icon"` — Full-width line, labeled line, or line with a built-in circle. |
| `align` | `"center"` | `"center"` \| `"left"` \| `"right"` — Horizontal placement for `content` and `icon`. Ignored on `default`. |
| `children` | — | `ReactNode` — Required for `layout="content"`. The text in the line. Not used for `icon`. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).
