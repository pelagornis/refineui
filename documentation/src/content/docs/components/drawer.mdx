# Drawer

화면 좌·우에서 슬라이드되는 패널입니다. Web Kit **Drawer** `635:1756` (Overlay)를 따릅니다.

## 설치·임포트

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerBody,
  DrawerFooter,
  DrawerClose,
  Button,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent placement="right" size="medium">
    <DrawerHeader>
      <DrawerTitle>필터</DrawerTitle>
      <DrawerDescription>필터 조건을 선택하세요.</DrawerDescription>
    </DrawerHeader>
    <DrawerBody>
      <p>내용</p>
    </DrawerBody>
    <DrawerFooter>
      <DrawerClose>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
      <Button>Apply</Button>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `Drawer` `open` | `boolean` | — | 제어 모드 열림 상태 |
| `Drawer` `defaultOpen` | `boolean` | `false` | 비제어 초기 열림 상태 |
| `Drawer` `onOpenChange` | `(open: boolean) => void` | — | 열림 상태 변경 콜백 |
| `DrawerContent` `placement` | `"left"` \| `"right"` | `"right"` | 어느 쪽에서 등장 |
| `DrawerContent` `size` | `"small"` \| `"medium"` \| `"large"` | `"small"` | 패널 폭 토큰 |
