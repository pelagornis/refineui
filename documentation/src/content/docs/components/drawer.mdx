## Props

- `open` — 열림 상태
- `onClose` — 닫기 콜백
- `title` — 제목 (있으면 헤더 오른쪽에 **dismiss** 닫기 아이콘 버튼 표시)
- `placement` — left | right (기본: right)
- `children` — 내용
