# Drawer

Panel that slides in from the left or right. Follows Web Kit **Drawer** `635:1756` (Overlay).

## Install & import

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerBody,
  DrawerFooter,
  DrawerClose,
  Button,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent placement="right" size="md">
    <DrawerHeader>
      <DrawerTitle>Filters</DrawerTitle>
      <DrawerDescription>Select filter criteria.</DrawerDescription>
    </DrawerHeader>
    <DrawerBody>
      <p>Content</p>
    </DrawerBody>
    <DrawerFooter>
      <DrawerClose variant="outline">Cancel</DrawerClose>
      <Button>Apply</Button>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `Drawer` `open` | `boolean` | — | Controlled open state |
| `Drawer` `defaultOpen` | `boolean` | `false` | Uncontrolled initial open |
| `Drawer` `onOpenChange` | `(open: boolean) => void` | — | Open state callback |
| `DrawerContent` `placement` | `"left"` \| `"right"` | `"right"` | Edge the drawer enters from |
| `DrawerContent` `size` | `"sm"` \| `"md"` \| `"lg"` | `"sm"` | Panel width tokens |
