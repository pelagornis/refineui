# Drawer

화면 좌·우에서 슬라이드되는 패널입니다. Web Kit **Drawer** `635:1756` (Overlay)를 따릅니다.

## 설치·임포트

```tsx
import { Drawer } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Drawer
  open={open}
  onClose={() => setOpen(false)}
  title="필터"
  placement="right"
  size="medium"
>
  <p>내용</p>
</Drawer>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `open` | `boolean` | (필수) | 표시 여부 |
| `onClose` | `() => void` | (필수) | 닫기 |
| `title` | `ReactNode` | — | 헤더 제목 |
| `placement` | `"left"` \| `"right"` | — | 어느 쪽에서 등장 |
| `size` | `"small"` \| `"medium"` \| `"large"` | — | 패널 폭 토큰 |

## 예시

### 좌측 네비게이션

```tsx
<Drawer open={navOpen} onClose={() => setNavOpen(false)} placement="left" size="small" title="메뉴">
  …
</Drawer>
```
