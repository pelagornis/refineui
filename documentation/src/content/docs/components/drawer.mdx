# Drawer

Drawer is a panel that slides in from the left or right. Use it for filters, navigation, or a detail sheet that should stay beside the page instead of blocking the center.

Overlay drawers portal to the body, show a scrim, trap focus, and lock scroll. Inline drawers render in flow with no scrim. For a centered modal, use **[Dialog](/components/dialog/)**. For a compact anchored panel, use **[Popover](/components/popover/)**.

## Interface

### Drawer

| Prop | Default | Type |
|------|---------|------|
| `open` | — | `boolean` — Controlled visibility. |
| `defaultOpen` | `false` (overlay) / `true` (inline) | `boolean` — Uncontrolled initial open. Inline defaults to open when this is omitted. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when the drawer requests open or close. |
| `type` | `"overlay"` | `"overlay"` \| `"inline"` — Overlay portals with a scrim; inline stays in flow. |
| `showFooter` | `true` | `boolean` — When `false`, `DrawerFooter` renders nothing. |
| `placement` | `"right"` | `"left"` \| `"right"` — Edge the panel is anchored to. |
| `size` | `"sm"` | `"sm"` \| `"md"` \| `"lg"` — Panel width tokens. |

### DrawerContent

| Prop | Default | Type |
|------|---------|------|
| `container` | `document.body` | `Element` \| `DocumentFragment` \| `null` — Portal root for overlay. |
| `type` | from `Drawer` | `"overlay"` \| `"inline"` — Overrides the root type. |
| `showFooter` | from `Drawer` | `boolean` — Overrides the root footer flag. |
| `placement` | from `Drawer` | `"left"` \| `"right"` — Overrides the root placement. |
| `size` | from `Drawer` | `"sm"` \| `"md"` \| `"lg"` — Overrides the root size. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### DrawerHeader

| Prop | Default | Type |
|------|---------|------|
| `showClose` | `true` | `boolean` — Renders `DrawerClose` in the header. |
| `actions` | — | `ReactNode` — Optional trailing controls before the close button. |

### DrawerFooter

| Prop | Default | Type |
|------|---------|------|
| `state` | from child count | `"icons"` \| `"single"` \| `"split"` — Footer layout. Omitted: 1 child → `single`, 2 → `split`, else `icons`. |

### DrawerTrigger

Same props as **[Button](/components/button/)**. Click opens the drawer unless `preventDefault()` is called.

### Parts

| Part | Role |
|------|------|
| `DrawerTitle` | `h2`, wired to `aria-labelledby`. |
| `DrawerDescription` | `p`, wired to `aria-describedby`. |
| `DrawerBody` | Scrollable main region. |
| `DrawerClose` | Closes the drawer. No children: dismiss icon. Children: labeled button (`outline` / `md` by default). |
