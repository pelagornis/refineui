# Dropdown

Dropdown is a compact action menu anchored to a trigger. Use it for account menus, overflow actions, and short grouped lists.

While it is open, page scroll on `body` / `html` is locked. For a wider panel with icons and descriptions, use **[Menu](/components/menu/)**. For site destinations with flyouts, use **[Navigation Menu](/components/navigation-menu/)**. For type-to-filter commands, use **[Command](/components/command/)**.

## Interface

### Dropdown

| Prop | Default | Type |
|------|---------|------|
| `open` | — | `boolean` — Controlled visibility. |
| `defaultOpen` | `false` | `boolean` — Uncontrolled initial open. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when the menu opens or closes. |

Also accepts native `div` attributes (`className`, `style`).

### DropdownContent

| Prop | Default | Type |
|------|---------|------|
| `align` | `"start"` | `"start"` \| `"end"` \| `"center"` — Horizontal alignment to the trigger. |
| `side` | `"auto"` | `"auto"` \| `"top"` \| `"bottom"` — Preferred side. `auto` flips to stay on screen. |
| `sideOffset` | `sizeXXSmall` (4px) | `number` — Gap between trigger and panel, in pixels. |

Also accepts native `div` attributes (`className`, `style`).

### DropdownItem

| Prop | Default | Type |
|------|---------|------|
| `selected` | `false` | `boolean` — Marks the row as the selected menuitem. |
| `disabled` | — | `boolean` — Blocks activation. Native `button` disabled. |

Also accepts native `button` attributes (`onClick`, `className`).

### Parts

| Part | Role |
|------|------|
| `DropdownTrigger` | Opens the menu. Merges onto a single child element when possible. |
| `DropdownGroup` | `role="group"`. |
| `DropdownLabel` | Group heading. |
| `DropdownSeparator` | Horizontal divider. |
| `DropdownShortcut` | Trailing shortcut text. |
| `DropdownSub` / `DropdownSubTrigger` / `DropdownSubContent` | Nested submenu. |
| `DropdownPortal` | Compatibility wrapper — renders children only. |
