# Dropdown

Figma Web Kit **Dropdown** `503:2985`와 동일 토큰·시각입니다.

| 방식 | 컴포넌트 | 설명 |
|------|----------|------|
| **합성(기본)** | `Dropdown`, `DropdownTrigger`, `DropdownContent`, `DropdownItem`, … | 라벨·단축키·서브메뉴를 JSX로 조합 |

열리면 **`body` / `html`에 `overflow: hidden`** 이 걸려 페이지 배경 스크롤이 멈춥니다.

---

## 설치·임포트

```tsx
import {
  Button,
  Dropdown,
  DropdownContent,
  DropdownGroup,
  DropdownItem,
  DropdownLabel,
  DropdownPortal,
  DropdownSeparator,
  DropdownShortcut,
  DropdownSub,
  DropdownSubContent,
  DropdownSubTrigger,
  DropdownTrigger,
} from '@refineui/react';
import '@refineui/react/refineui.css';
```

---

## 기본 사용 — 합성

```tsx
<Dropdown>
  <DropdownTrigger>
    <Button variant='outline' size='sm' type='button'>
      Open
    </Button>
  </DropdownTrigger>
  <DropdownContent className='w-40' align='start'>
    <DropdownGroup>
      <DropdownLabel>My Account</DropdownLabel>
      <DropdownItem>
        Profile
        <DropdownShortcut>⇧⌘P</DropdownShortcut>
      </DropdownItem>
      <DropdownItem>
        Billing
        <DropdownShortcut>⌘B</DropdownShortcut>
      </DropdownItem>
    </DropdownGroup>
    <DropdownSeparator />
    <DropdownGroup>
      <DropdownItem>Team</DropdownItem>
      <DropdownSub>
        <DropdownSubTrigger>Invite users</DropdownSubTrigger>
        <DropdownPortal>
          <DropdownSubContent>
            <DropdownItem>Email</DropdownItem>
            <DropdownItem>Message</DropdownItem>
          </DropdownSubContent>
        </DropdownPortal>
      </DropdownSub>
    </DropdownGroup>
  </DropdownContent>
</Dropdown>
```

- **`DropdownItem`** 을 누르면 기본으로 메뉴가 닫힙니다. `onClick`에서 `preventDefault()` 하면 유지할 수 있습니다.
- **`DropdownPortal`** 은 이전 API 호환용으로 자식만 렌더합니다. 서브 패널은 내부에서 이미 `document.body`로 그립니다.

### 구성 요소

| 컴포넌트 | 역할 |
|----------|------|
| `Dropdown` | 루트 · 열림 상태 |
| `DropdownTrigger` | 단일 자식이면 `PopoverTrigger`처럼 자동 병합 |
| `DropdownContent` | 본문 패널(포털) |
| `DropdownGroup` | `role="group"` |
| `DropdownLabel` | 그룹 제목 |
| `DropdownItem` | `role="menuitem"` |
| `DropdownSeparator` | 구분선 |
| `DropdownShortcut` | 단축키 텍스트 |
| `DropdownSub` / `SubTrigger` / `SubContent` | 서브메뉴 |
| `DropdownPortal` | 호환 래퍼 |

### Props (요지)

**`DropdownContent`:** `align` · `side` · `sideOffset` + `className`  
**`DropdownTrigger`:** 자식이 하나의 컴포넌트면 ref·클릭을 그 요소에 합성  
**`DropdownItem`:** 평소 `<button>` 과 동일(`disabled`, `onClick` 등).
