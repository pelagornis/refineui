# Dropdown

버튼 등 **트리거**를 눌러 메뉴를 띄웁니다. Web Kit **Dropdown** `503:2985`를 따릅니다.

## 설치·임포트

```tsx
import { Dropdown, Button } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Dropdown
  trigger={<Button variant="secondary">메뉴</Button>}
  items={[
    { id: "1", label: "편집", onClick: () => {} },
    { id: "2", label: "삭제", disabled: true },
  ]}
  menuTitle="작업"
/>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `trigger` | `ReactNode` | 보통 [Button](/components/button/) |
| `items` | `DropdownItem[]` | `id`, `label`, 선택 `shortcut`, `onClick`, `disabled` |
| `align` | `"start"` \| `"end"` | 메뉴 정렬 |
| `showTriggerChevron` | `boolean` | 트리거에 셰브론 표시 |
| `menuTitle` | `ReactNode` | 메뉴 상단 제목 |

## 예시

### 단축키 표시

<Dropdown
