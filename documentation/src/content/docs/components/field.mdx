# Field

폼 필드를 **라벨 + 자식 컨트롤 + (선택) 힌트/에러**로 묶습니다. Web Kit **Field** `525:1074`의 라벨 타이포·간격에 맞춥니다.

## 설치·임포트

```tsx
import { Field, FieldError, FieldHint, FieldLabel, FieldRequired, Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Field>
  <FieldLabel>
    이메일
    <FieldRequired />
  </FieldLabel>
  <Input id="email" name="email" type="email" fullWidth />
  <FieldHint>로그인에 사용됩니다.</FieldHint>
</Field>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 라벨 타이포 (sm→caption1, md→body2, lg→body1) |
| `children` | `ReactNode` | — | 합성형 슬롯 (`FieldLabel`, `FieldHint`, `FieldError` 등) |

`children`에 [Input](/components/input/), [Select](/components/select/), [Textarea](/components/textarea/) 등을 둡니다.

## 예시

### 에러 상태

```tsx
<Field>
  <FieldLabel>
    비밀번호
    <FieldRequired />
  </FieldLabel>
  <Input id="pw" type="password" error fullWidth />
  <FieldError>대소문자를 포함하세요.</FieldError>
</Field>
```

### 힌트만 (라벨 없음)

`FieldLabel` 없이 `FieldHint`만 둘 수 있습니다. 스크린 리더 연결은 자식에 `aria-label` 또는 별도 [Label](/components/label/)을 사용하세요.
