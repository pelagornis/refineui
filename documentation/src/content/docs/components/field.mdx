# Field

Field wraps a form control as a label, the control itself, and optional hint or error copy. Use it whenever a field needs a name and supporting text in one stack.

`FieldLabel` and `FieldRequired` reuse **[Label](/components/label/)** (`Label` / `LabelRequired`) so size and required marks stay in sync. Place [Input](/components/input/), [Select](/components/select/), [Textarea](/components/textarea/), [Input OTP](/components/input-otp/), or another control as children. Child controls inherit Field `size` when they omit their own.

## Interface

### Field

| Prop | Default | Type |
|------|---------|------|
| `size` | `"lg"` | `"sm"` \| `"md"` \| `"lg"` — Label type and inherited control size when children omit `size`. |

Also accepts native `div` attributes (`className`, `children`, `style`).

### FieldLabel

Same props as [Label](/components/label/). `size` defaults from the nearest Field.

### FieldRequired

Same as `LabelRequired` — decorative `*` (`aria-hidden`).

### FieldHint

| Prop | Default | Type |
|------|---------|------|
| `children` | — | `ReactNode` — Helper copy under the control. |

### FieldError

| Prop | Default | Type |
|------|---------|------|
| `children` | — | `ReactNode` — Validation message. Renders with `role="alert"`. |
