# Field

Wraps a form field as **label + control + optional hint/error**. Matches Web Kit **Field** `525:1074` label typography and spacing.

## Install & import

```tsx
import { Field, FieldError, FieldHint, FieldLabel, FieldRequired, Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Field>
  <FieldLabel>
    Email
    <FieldRequired />
  </FieldLabel>
  <Input id="email" name="email" type="email" fullWidth />
  <FieldHint>Used for sign-in.</FieldHint>
</Field>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Label typography (sm→caption1, md→body2, lg→body1) |
| `children` | `ReactNode` | — | Slots (`FieldLabel`, `FieldHint`, `FieldError`, etc.) |

Place [Input](/components/input/), [Select](/components/select/), [Textarea](/components/textarea/), etc. as children.

## Examples

### Error state

```tsx
<Field>
  <FieldLabel>
    Password
    <FieldRequired />
  </FieldLabel>
  <Input id="pw" type="password" error fullWidth />
  <FieldError>Include upper and lower case letters.</FieldError>
</Field>
```

### Hint only (no label)

You can use `FieldHint` without `FieldLabel`. For screen readers, use `aria-label` on the control or a separate [Label](/components/label/).
