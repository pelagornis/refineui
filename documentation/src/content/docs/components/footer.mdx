# Footer

Footer is the site-wide landmark at the bottom of a page. Use it when you need a wrapping sitemap and a quiet legal bar — social links, a brand lockup, and a locale control.

Put the sitemap in `FooterExplore`. Put social, lockup, and locale in `FooterMeta`. For in-page section links, use **[Tabs](/components/tabs/)** or **[Navigation Menu](/components/navigation-menu/)** instead.

## Interface

### Footer

Accepts native `footer` attributes (`className`, `style`, `aria-*`).

### FooterNav

| Prop | Default | Type |
|------|---------|------|
| `aria-label` | `"Footer"` | `string` — Landmark name. Override when multiple footers exist. |

Also accepts native `nav` attributes.

### Parts

| Part | Role |
|------|------|
| `FooterExplore` | Upper region — wrapping sitemap. Alias: `FooterContent`. |
| `FooterNav` | Sitemap columns (`nav`). |
| `FooterGroup` | One labeled link column. |
| `FooterGroupLabel` | Column heading. |
| `FooterLink` | Footer `<a>`. Density follows `FooterSocial` / `FooterLocale`. |
| `FooterMeta` | Lower bar — social · lockup · locale. Alias: `FooterBottom`. |
| `FooterSocial` | Icon (or text) social links, start. |
| `FooterBrand` | Center lockup. |
| `FooterLogo` | Optional logo mark. |
| `FooterBrandName` | Optional product / brand name. |
| `FooterBrandDescription` | Optional tagline. |
| `FooterCopyright` | Legal line. |
| `FooterMetaEnd` | End cluster — locale pill. |
| `FooterLocale` | Locale control slot (usually `Select`). |
