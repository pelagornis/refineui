# Input OTP

Input OTP is a row of separate soft cells — one character each. Use it for a verification code from email or SMS.

It is not a merged Input. For a single-line secret, use **[Input](/components/input/)** with `type="password"`. Wrap the group in **[Field](/components/field/)** when you need a label or `FieldError`. When `size` is omitted inside Field, cells inherit Field’s size.

## Interface

### InputOTP

| Prop | Default | Type |
|------|---------|------|
| `maxLength` | — | `number` — Slot count. Required. Must match rendered `InputOTPSlot` indices. |
| `value` | — | `string` — Controlled OTP string. |
| `defaultValue` | `""` | `string` — Uncontrolled initial value. |
| `onValueChange` | — | `(value: string) => void` — Called when the filtered value changes. |
| `size` | `"lg"` | `"sm"` \| `"md"` \| `"lg"` — Cell size and digit type. Inherits from [Field](/components/field/) when omitted. |
| `disabled` | `false` | `boolean` — Disables every slot. |
| `pattern` | `/\d/` | `RegExp` — Per-character allowlist. Characters that fail are dropped. |
| `inputMode` | `"numeric"` | HTML `inputMode` — Mobile keyboard hint, applied to each slot. |
| `autoComplete` | `"one-time-code"` | HTML `autoComplete` — Applied to the first slot. |
| `autoFocus` | `false` | `boolean` — Focuses the first slot on mount. |
| `name` | — | `string` — Base `name` for slots (`name-0`, `name-1`, …). |
| `id` | — | `string` — Applied to the first slot; later slots append `-{index}`. |
| `aria-label` | `"One-time password"` | `string` — Accessible name for the group. |

Also accepts native `div` attributes except `onChange` and `defaultValue` (`className`, `style`).

### InputOTPSlot

| Prop | Default | Type |
|------|---------|------|
| `index` | — | `number` — Zero-based slot index. Required. |

Also accepts native `input` attributes except `type`, `value`, `defaultValue`, `maxLength`, `disabled`, `size`, and `children`.
