# Input

Input is a single-line text field. Use it when the answer is a short string — an email, a name, a password, or a number.

Pair it with **[Label](/components/label/)** or wrap it in **[Field](/components/field/)** for a label, hint, and error message. For multi-line copy, use **[Textarea](/components/textarea/)**. For a query with an icon and clear, use **[Search Field](/components/search-field/)**. For a bounded integer with steppers, use **[SpinButton](/components/spin-button/)**.

## Interface

### Input

| Prop | Default | Type |
|------|---------|------|
| `size` | `"lg"` | `"sm"` \| `"md"` \| `"lg"` — Height, padding, radius, and type. Not the HTML `size` attribute. Inherits from [Field](/components/field/) when wrapped and `size` is omitted. |
| `error` | `false` | `boolean` — Error border. Also sets `aria-invalid`. |
| `success` | `false` | `boolean` — Success border. |
| `fullWidth` | `false` | `boolean` — Stretch to the parent width. |
| `disabled` | — | `boolean` — Disabled background and border. |

Also accepts native `input` attributes (`type`, `value`, `onChange`, `name`, `id`, `placeholder`, `autoComplete`, `aria-*`, `className`).
