# Input

Single-line text field. Follows Web Kit **Input** `518:7373` and `docs/design-specs-web-kit.md` §2. Focus, placeholder, and disabled styles pair with **`refineui.css`** `[data-refineui="input"]` rules.

## Install & import

```tsx
import { Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Input name="email" type="email" placeholder="name@example.com" autoComplete="email" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"lg"` | Height, padding, radius, typography (not the HTML `size` attribute). Inherits from [Field](/components/field/) when wrapped and `size` is omitted. |
| `error` | `boolean` | `false` | Error border |
| `success` | `boolean` | `false` | Success border |
| `fullWidth` | `boolean` | `false` | Full width |
| `disabled` | `boolean` | — | Disabled background and border |

Also supports **`InputHTMLAttributes`** (`type`, `value`, `onChange`, `name`, `id`, `aria-*`, etc.).

## Examples

### Password

```tsx
<Input type="password" placeholder="Password" autoComplete="current-password" />
```

### With validation copy (Field recommended)

Use `error` for border only; place messages in [Field](/components/field/) error slot or adjacent text.

```tsx
<Input id="pw" type="password" error aria-invalid />
<p role="alert">Use at least 8 characters.</p>
```

### Number and search

```tsx
<Input type="number" inputMode="numeric" min={0} />
<Input type="search" name="q" placeholder="Search" />
```

## Accessibility

- With `error`, also set `aria-invalid` when appropriate (implementation may wire this automatically).
- Connect labels via [Label](/components/label/) or `<label htmlFor>`.
