# Input

한 줄 텍스트 입력 필드입니다. Web Kit **Input** `518:7373`과 `docs/design-specs-web-kit.md` §2를 따릅니다. 포커스·placeholder·disabled 스타일은 **`refineui.css`**의 `[data-refineui="input"]` 규칙과 맞물립니다.

## 설치·임포트

```tsx
import { Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Input name="email" type="email" placeholder="name@example.com" autoComplete="email" />
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 높이·패딩·모서리·타이포 (HTML `size` 속성과 다름) |
| `error` | `boolean` | `false` | 에러 테두리 |
| `success` | `boolean` | `false` | 성공 테두리 |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | — | 비활성 배경·테두리 |

그 외 **`InputHTMLAttributes`** (`type`, `value`, `onChange`, `name`, `id`, `aria-*` 등)를 사용할 수 있습니다.

## 예시

### 비밀번호

```tsx
<Input type="password" placeholder="비밀번호" autoComplete="current-password" />
```

### 검증 메시지와 함께 (Field 권장)

입력만 쓸 때는 `error`로 테두리를 바꾸고, 문구는 [Field](/components/field/)의 `error` 슬롯이나 별도 텍스트로 붙입니다.

```tsx
<Input id="pw" type="password" error aria-invalid />
<p role="alert">8자 이상 입력하세요.</p>
```

### 숫자·검색

```tsx
<Input type="number" inputMode="numeric" min={0} />
<Input type="search" name="q" placeholder="검색" />
```

## 접근성

- `error`일 때 `aria-invalid`를 함께 쓰는 것을 권장합니다(구현에서 `error` 시 속성 연동 가능).
- 라벨은 [Label](/components/label/) 또는 `<label htmlFor>`로 연결하세요.
