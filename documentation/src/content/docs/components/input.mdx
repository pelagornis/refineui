# Input

입력 필드 컴포넌트입니다. **포커스해보세요** — focus 시 테두리 스타일이 적용됩니다.

## Preview

<div class="not-content">
  <InputPreview client:load />
</div>

## Props

- `error` — 에러 상태 스타일
- `success` — 성공 상태 스타일
- `disabled` — 비활성
- `fullWidth` — 전체 너비

## 예시

```tsx
import { Input } from "@refineui/react";

<Input placeholder="이메일" />
<Input type="password" placeholder="비밀번호" error />
```
