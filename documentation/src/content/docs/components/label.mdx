# Label

Styled native `<label>`. Web Kit **Label** `216:1681`. Default size **`md`** — same scale as [Field](/components/field/) / [Input](/components/input/).

`FieldLabel` / `FieldRequired` are thin wrappers around **`Label`** / **`LabelRequired`** so form shells and standalone labels share one atom.

## Install & import

```tsx
import { Label, LabelRequired, Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

Prefer composing `LabelRequired` (same pattern as Field):

```tsx
<>
  <Label htmlFor="name">
    Name
    <LabelRequired />
  </Label>
  <Input id="name" name="name" />
</>
```

`required` on `Label` still appends the same mark when you want a shorter form.

## Props

### `Label`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Typography (`caption1` / `body2` / `body1`) |
| `disabled` | `boolean` | `false` | Text `foregroundDisabled` |
| `required` | `boolean` | `false` | Convenience — renders `LabelRequired` |

Also accepts **`LabelHTMLAttributes`** (`htmlFor`, `children`, `className`, …).

### `LabelRequired`

Decorative `*` (`aria-hidden`). Same atom as `FieldRequired`.

## Examples

### With Field

```tsx
<Field size="md">
  <FieldLabel>
    Email
    <FieldRequired />
  </FieldLabel>
  <Input id="email" fullWidth />
</Field>
```

`FieldLabel` inherits `Field`’s `size` unless you pass `size` on the label.
