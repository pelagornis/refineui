# Label

Styled native `<label>`. Matches Web Kit **Label** `216:1681`; default size is **`md`** (same as [Field](/components/field/) and [Input](/components/input/)).

## Install & import

```tsx
import { Label, Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

Connect to an input with `htmlFor` / `id`.

```tsx
<>
  <Label htmlFor="name" required>
    Name
  </Label>
  <Input id="name" name="name" />
</>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Typography |
| `disabled` | `boolean` | `false` | Text color `neutral400` |
| `required` | `boolean` | `false` | Shows `*` (`red700`) |

Supports **`LabelHTMLAttributes`** such as `htmlFor`, `children`, `className`.

## Examples

### Label only (without Field)

```tsx
<Label htmlFor="city" size="sm">
  City
</Label>
<Input id="city" size="sm" />
```
