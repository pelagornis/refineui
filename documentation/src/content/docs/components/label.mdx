# Label

Label is a styled native `<label>`. Use it to name an input, select, or other control, and to associate that name with the control via `htmlFor`.

`FieldLabel` and `FieldRequired` are the same atoms as `Label` and `LabelRequired`, so a standalone label and a [Field](/components/field/) shell stay in sync. For the full row (label, control, hint, error), prefer Field.

## Interface

### Label

| Prop | Default | Type |
|------|---------|------|
| `size` | `"md"` | `"sm"` \| `"md"` \| `"lg"` — Label type scale. |
| `disabled` | `false` | `boolean` — Disabled label color. |
| `required` | `false` | `boolean` — Appends `LabelRequired`. Prefer composing `<LabelRequired />`. |

Also accepts native `label` attributes (`htmlFor`, `children`, `className`).

### LabelRequired

| Prop | Default | Type |
|------|---------|------|
| `children` | `"*"` | `ReactNode` — Decorative required mark (`aria-hidden`). Same atom as `FieldRequired`. |

Also accepts native `span` attributes (`className`).
