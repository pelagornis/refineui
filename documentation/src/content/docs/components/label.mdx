# Label

네이티브 `<label>`을 스타일한 컴포넌트입니다. Web Kit **Label** `216:1681`과 맞추며, 기본값은 **`md`**([Field](/components/field/)·[Input](/components/input/)과 동일)입니다.

## 설치·임포트

```tsx
import { Label, Input } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

`htmlFor`로 입력 `id`와 연결합니다.

```tsx
<>
  <Label htmlFor="name" required>
    이름
  </Label>
  <Input id="name" name="name" />
</>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 타이포 |
| `disabled` | `boolean` | `false` | 글자색 `neutral400` |
| `required` | `boolean` | `false` | `*` 표시 (`red700`) |

`htmlFor`, `children`, `className` 등 **`LabelHTMLAttributes`**를 지원합니다.

## 예시

### Field 대신 라벨만

```tsx
<Label htmlFor="city" size="sm">
  도시
</Label>
<Input id="city" size="sm" />
```
