# Link

Link is a styled `<a>` for navigation. Use it in running copy, breadcrumbs you compose yourself, or anywhere a URL is the primary action.

For a control that looks like a button, use **[Button](/components/button/)**. For a trail of pages, prefer **[Breadcrumb](/components/breadcrumb/)**.

## Interface

### Link

| Prop | Default | Type |
|------|---------|------|
| `showExternalIcon` | auto for `target="_blank"` | `boolean` — Force the open icon on, or set `false` to hide it even for new windows. |
| `disabled` | `false` | `boolean` — Marks the link non-interactive (`aria-disabled`, no pointer events). |

Also accepts native `a` attributes (`href`, `target`, `rel`, `className`, `children`).
