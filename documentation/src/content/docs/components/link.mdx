## Variants

- `default` — 기본 (파란색)
- `subtle` — 은은한 스타일 (회색)

## Props

- `variant` — `default` | `subtle`
- `showExternalIcon` — `target="_blank"`일 때 외부 링크 아이콘 표시 (기본 `true`)

## 외부 링크

`target="_blank"`이면 기본으로 **open** 아이콘이 붙습니다. `showExternalIcon={false}`로 끌 수 있습니다.
