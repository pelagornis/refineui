# Link

Styled `<a>` link. Web Kit **Link** `226:158` — color, underline, hover via **`refineui.css`** `[data-refineui="link"]`.

## Install & import

```tsx
import { Link } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Link href="/docs">Documentation</Link>
<Link href="https://example.com" target="_blank" rel="noopener noreferrer">
  External site
</Link>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default"` \| `"subtle"` | `"default"` | Emphasis level |
| `showExternalIcon` | `boolean` | (auto) | With `target="_blank"`, external icon is shown by default |
| `disabled` | `boolean` | `false` | `aria-disabled` and blocks clicks |

Uses **`AnchorHTMLAttributes`**: `href`, `children`, `className`, etc.

## Examples

### Hide new-window icon

```tsx
<Link href="https://…" target="_blank" showExternalIcon={false}>
  Link
</Link>
```
