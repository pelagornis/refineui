# Link

`<a>` 스타일 링크입니다. Web Kit **Link** `226:158` — 색·밑줄·호버는 **`refineui.css`** `[data-refineui="link"]`입니다.

## 설치·임포트

```tsx
import { Link } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Link href="/docs">문서</Link>
<Link href="https://example.com" target="_blank" rel="noopener noreferrer">
  외부 사이트
</Link>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `variant` | `"default"` \| `"subtle"` | `"default"` | 강조 / 덜 강조 |
| `showExternalIcon` | `boolean` | (자동) | `target="_blank"`이면 기본으로 외부 아이콘 |
| `disabled` | `boolean` | `false` | `aria-disabled`·클릭 차단 |

`href`, `children`, `className` 등 **`AnchorHTMLAttributes`**를 사용합니다.

## 예시

### 새 창 아이콘 숨김

```tsx
<Link href="https://…" target="_blank" showExternalIcon={false}>
  링크
</Link>
```
