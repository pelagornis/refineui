# Menu

Menu panel with a list of items. Matches Web Kit **Menu** `633:4268` (simple text list). **Dropdown** includes trigger + open behavior; **Menu** is for **panel-only** use cases. Composed dropdowns (`Dropdown`, `DropdownTrigger`, …) are documented under [Dropdown](/components/dropdown/).

## Install & import

```tsx
import {
  Button,
  Menu,
  MenuDivider,
  MenuItem,
  MenuList,
  MenuPopover,
  MenuSection,
  MenuTrigger,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Menu positioning={{ autoSize: true }}>
  <MenuTrigger>
    <Button>Toggle menu</Button>
  </MenuTrigger>
  <MenuPopover>
    <MenuList>
      <MenuSection>Section Header</MenuSection>
      <MenuItem>Copy</MenuItem>
      <MenuItem shortcut="Cmd+V">Paste</MenuItem>
      <MenuItem disabled>Delete</MenuItem>
      <MenuDivider />
      <MenuSection>Advanced</MenuSection>
      <MenuItem>Preferences</MenuItem>
    </MenuList>
  </MenuPopover>
</Menu>
```
