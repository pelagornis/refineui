# Menu

항목 목록만 있는 메뉴 패널입니다. Web Kit **Menu** `633:4268` (단순 텍스트 리스트)에 맞춥니다. **Dropdown**은 트리거+열기까지 포함하고, **Menu**는 패널만 둘 때 쓸 수 있습니다.

## 설치·임포트

```tsx
import { Menu } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Menu
  items={[
    { id: "a", label: "복사", onClick: () => {} },
    { id: "b", label: "붙여넣기", onClick: () => {} },
  ]}
/>
```

| Prop | 타입 | 설명 |
|------|------|------|
