# Menu

Menu is a wider action panel: sections, icons, descriptions, shortcuts, and nested submenus. Use it when a list of commands needs that extra row chrome.

For a compact trigger menu, use **[Dropdown](/components/dropdown/)**. For site or app destinations with flyout panels, use **[Navigation Menu](/components/navigation-menu/)**. For a searchable palette, use **[Command](/components/command/)**.

## Interface

### Menu

| Prop | Default | Type |
|------|---------|------|
| `positioning` | — | `{ autoSize?: boolean }` — When `autoSize` is true, the popover width follows content. |

Also accepts native `div` attributes (`className`, `style`).

### MenuItem

| Prop | Default | Type |
|------|---------|------|
| `description` | — | `ReactNode` — Secondary line under the label. |
| `shortcut` | — | `ReactNode` — Trailing key combo. |
| `startIcon` | — | `ReactNode` — Leading icon slot. |
| `endIcon` | — | `ReactNode` — Trailing icon slot (after shortcut). |
| `state` | `"default"` | `"default"` \| `"hover"` \| `"pressed"` \| `"active"` \| `"disabled"` — Visual state. `disabled` also blocks activation. |
| `disabled` | — | `boolean` — Blocks activation and closes. |

Also accepts native `button` attributes (`onClick`, `className`).

### MenuSubTrigger

| Prop | Default | Type |
|------|---------|------|
| `description` | — | `ReactNode` — Secondary line under the label. |
| `startIcon` | — | `ReactNode` — Leading icon slot. |
| `state` | `"default"` | `"default"` \| `"hover"` \| `"pressed"` \| `"active"` \| `"disabled"` — Visual state. Open submenus resolve to `active`. |
| `disabled` | — | `boolean` — Blocks opening the submenu. |

### Parts

| Part | Role |
|------|------|
| `MenuTrigger` | Toggles the popover. Merges onto a single child element when possible. |
| `MenuPopover` | Portaled panel. |
| `MenuList` | `role="menu"` list. |
| `MenuSection` | Group heading. |
| `MenuDivider` | Horizontal separator. |
| `MenuSub` | Nested branch context. |
| `MenuSubContent` | Portaled nested `role="menu"`. |
