# Menu

항목 목록만 있는 메뉴 패널입니다. Web Kit **Menu** `633:4268` (단순 텍스트 리스트)에 맞춥니다. **Dropdown**은 트리거+열기까지 포함하고, **Menu**는 패널만 둘 때 쓸 수 있습니다. **합성 드롭다운**(`Dropdown`, `DropdownTrigger`, …)은 [Dropdown](/components/dropdown/) 문서에 정리되어 있습니다.

## 설치·임포트

```tsx
import {
  Button,
  Menu,
  MenuDivider,
  MenuItem,
  MenuList,
  MenuPopover,
  MenuSection,
  MenuTrigger,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Menu positioning={{ autoSize: true }}>
  <MenuTrigger>
    <Button>Toggle menu</Button>
  </MenuTrigger>
  <MenuPopover>
    <MenuList>
      <MenuSection>Section Header</MenuSection>
      <MenuItem>복사</MenuItem>
      <MenuItem shortcut="Cmd+V">붙여넣기</MenuItem>
      <MenuItem disabled>삭제</MenuItem>
      <MenuDivider />
      <MenuSection>고급</MenuSection>
      <MenuItem>환경설정</MenuItem>
    </MenuList>
  </MenuPopover>
</Menu>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `positioning` | `{ autoSize?: boolean }` | popover 너비 자동 조절 옵션 |

`Menu`는 `MenuTrigger`, `MenuPopover`, `MenuList`, `MenuItem`으로 조합하는 컴파운드 API만 사용합니다.
