# Navigation Menu

Navigation Menu is horizontal site or app navigation. Use it when top destinations need flyout panels — products, docs, pricing — and a few plain links sit next to them.

Each item is a slot: a trigger plus content, or a top-level link. For actions and nested command lists, use **[Menu](/components/menu/)**. For a vertical app nav, use **[Sidebar](/components/sidebar/)**. For a path trail, use **[Breadcrumb](/components/breadcrumb/)**. For in-page section panels, use **[Tabs](/components/tabs/)**. For a compact mode switch, use **[Segmented Control](/components/segmented-control/)**.

## Interface

### NavigationMenu

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Controlled open item. `""` is closed. |
| `defaultValue` | `""` | `string` — Uncontrolled initial open item. |
| `onValueChange` | — | `(value: string) => void` — Called when the open item changes. |
| `delayDuration` | semantic `duration.normal` | `number` — Hover-open delay in milliseconds. |
| `skipDelayDuration` | semantic `duration.fast` | `number` — Delay when switching between open items, in milliseconds. |
| `aria-label` | `"Main"` | `string` — Landmark name. |

Also accepts native `nav` attributes (`className`, `style`).

### NavigationMenuItem

| Prop | Default | Type |
|------|---------|------|
| `value` | auto-generated | `string` — Stable id for open state. Pass this when you control `value` on the root. |

Also accepts native `li` attributes.

### NavigationMenuLink

| Prop | Default | Type |
|------|---------|------|
| `active` | `false` | `boolean` — Current page (`aria-current="page"`). |
| `href` | — | `string` — Destination. |

Also accepts native `<a>` attributes. Top-level links use the same plate as triggers; links inside `NavigationMenuContent` use menu-row density.

### Parts

| Part | Role |
|------|------|
| `NavigationMenuList` | Top-level list (`ul`). |
| `NavigationMenuTrigger` | Opens the panel. Chevron is built-in. Native `button` attributes. |
| `NavigationMenuContent` | Flyout panel (`role="region"`). |
| `NavigationMenuIndicator` | Optional underline under the open trigger. Render inside the list if you need it. |
