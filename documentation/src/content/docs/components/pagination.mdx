# Pagination

Pagination splits a long list into pages. Use it under a table or result list when the user needs to jump by number, not only scroll.

Previous and next are buttons. Page numbers are links. For a linear wizard with named stages, use **[Stepper](/components/stepper/)** or **[ProgressStepper](/components/progress-stepper/)**. For in-page panels, use **[Tabs](/components/tabs/)**.

## Interface

### Pagination

Accepts native `nav` attributes (`className`, `style`, `aria-*`). `aria-label="Pagination"` is set on the root.

### PaginationLink

| Prop | Default | Type |
|------|---------|------|
| `isActive` | `false` | `boolean` — Marks the current page (`aria-current="page"`). |

Also accepts native `a` attributes (`href`, `className`, `children`).

### PaginationPrevious / PaginationNext

Native `button` attributes (`onClick`, `disabled`, `type`). `type` defaults to `"button"`. Chevrons and `aria-label` are built in.

### Parts

| Part | Role |
|------|------|
| `Pagination` | Root `nav` (`aria-label="Pagination"`). Same as `PaginationRoot`. |
| `PaginationContent` | List (`ul`) of items. |
| `PaginationItem` | Item wrapper (`li`). |
| `PaginationLink` | Page number link. |
| `PaginationPrevious` | Previous-page button. |
| `PaginationNext` | Next-page button. |
| `PaginationEllipsis` | Hidden-range placeholder (`span`). |
