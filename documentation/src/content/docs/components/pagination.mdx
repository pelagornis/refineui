# Pagination

목록의 페이지를 바꿀 때 씁니다. Web Kit **Pagination** `558:1989` · **Pagination / Item** `570:2332`를 참고합니다.

## 설치·임포트

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious type="button" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">3</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext type="button" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `className` | `string` | 루트 컨테이너 스타일 확장 |
| `...props` | `HTMLAttributes<HTMLElement>` | 루트 `<nav>` 속성 |

`aria-label="Pagination"`이 `<nav>`에 설정됩니다.

### 합성형 컴포넌트

| 컴포넌트 | 설명 |
|------|------|
| `PaginationContent` | 페이지 아이템을 담는 리스트 래퍼 |
| `PaginationItem` | 각 아이템 래퍼 (`li`) |
| `PaginationLink` | 페이지 링크 (`isActive` 지원) |
| `PaginationPrevious` | 이전 페이지 버튼 |
| `PaginationNext` | 다음 페이지 버튼 |
| `PaginationEllipsis` | 생략 표시 아이템 |

## 예시

### 라우터 링크와 함께 사용

```tsx
<PaginationLink href="/products?page=3">3</PaginationLink>
```
