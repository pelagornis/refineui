# PopOver

트리거를 클릭해 패널을 엽니다. Web Kit **PopOver** `553:5669` — **`default`** / **`inverted`** 배경. Figma의 **beak(화살표)·세부 정렬**은 미구현이며, 패널 토큰만 스펙에 맞춥니다.

## 설치·임포트

```tsx
import { PopOver, Button } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<PopOver
  trigger={<Button variant="secondary">정보</Button>}
  content={<p>추가 설명</p>}
  placement="bottom"
  variant="default"
/>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `trigger` | `ReactNode` | (필수) | 클릭 요소 |
| `content` | `ReactNode` | (필수) | 패널 내용 |
| `placement` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"bottom"` | 기준 위치 |
| `variant` | `"default"` \| `"inverted"` | `"default"` | 밝은 / 어두운 패널 |

## 예시

### 다크 패널

```tsx
<PopOver trigger={<Button variant="ghost">?</Button>} content="도움말" variant="inverted" />
```
