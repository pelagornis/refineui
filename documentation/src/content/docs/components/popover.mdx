# Popover

Popover is a panel that opens when its trigger is clicked. Use it for extra fields, a short explanation, or a small editor that should stay next to the control.

The page stays interactive behind it — no modal scrim. For a blocking task, use **[Dialog](/components/dialog/)**. For an action list with shortcuts and nested panels, use **[Menu](/components/menu/)** or **[Dropdown](/components/dropdown/)**. For hover-only helper text, use **[Tooltip](/components/tooltip/)**.

## Interface

### Popover

| Prop | Default | Type |
|------|---------|------|
| `open` | — | `boolean` — Controlled visibility. |
| `defaultOpen` | `false` | `boolean` — Uncontrolled initial open. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when the panel opens or closes. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### PopoverContent

| Prop | Default | Type |
|------|---------|------|
| `placement` | `"bottom"` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` — Side of the trigger. |
| `align` | `"center"` | `"start"` \| `"center"` \| `"end"` — Alignment along that side. |

Also accepts native `div` attributes (`className`, `style`).

### PopOver

| Prop | Default | Type |
|------|---------|------|
| `trigger` | — | `ReactNode` — Click target. Required. |
| `content` | — | `ReactNode` — Panel body. Required. |
| `placement` | `"bottom"` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` — Same as `PopoverContent`. |
| `align` | `"center"` | `"start"` \| `"center"` \| `"end"` — Same as `PopoverContent`. |

Also accepts native `div` attributes (`className`, `style`).

### Parts

| Part | Role |
|------|------|
| `PopoverTrigger` | Opens and closes the panel. Merges onto a single child element when possible. |
| `PopoverContent` | Beak + floating panel (`role="dialog"`). |
