# PopOver

Opens a panel when the trigger is clicked. Web Kit **PopOver** `553:5669` — **`placement`** (= Figma `position`), **`align`** (= Figma `Start` \| `Center` \| `End`); panel, border, and beak use MCP dimensions and color tokens.

## Install & import

```tsx
import { PopOver, Button } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage (composed API)

```tsx
import {
  Button,
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@refineui/react";
import "@refineui/react/refineui.css";

export function Example() {
  return (
    <Popover>
      <PopoverTrigger>
        <Button variant="secondary">Open</Button>
      </PopoverTrigger>
      <PopoverContent placement="bottom" align="center">
        <p>Additional description</p>
      </PopoverContent>
    </Popover>
  );
}
```

Default panel width follows Web Kit **`componentSizes.popoverPanelWidth`** (325px min). Override with **`PopoverContent`** `className` or `style` as needed (the Preview uses `width: componentSizes.popoverPanelWidth`).

**`PopoverTrigger`** with a **single child** (e.g. `Button`) merges trigger behavior and a11y props onto that element. Plain text children are wrapped in an internal `button`.

### Single-component API (optional)

```tsx
<PopOver
  trigger={<Button variant="secondary">Info</Button>}
  content={<p>Additional description</p>}
  placement="bottom"
/>
```

## Props

### `Popover` (root)

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controlled open |
| `defaultOpen` | `boolean` | Uncontrolled initial open |
| `onOpenChange` | `(open: boolean) => void` | Open state change |

### `PopoverContent`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placement` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"bottom"` | Figma `position` |
| `align` | `"start"` \| `"center"` \| `"end"` | `"center"` | Figma `align` |

### `PopOver` (single component · optional)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `trigger` | `ReactNode` | (required) | Click target |
| `content` | `ReactNode` | (required) | Panel body |
| `placement` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"bottom"` | |
| `align` | `"start"` \| `"center"` \| `"end"` | `"center"` | |
