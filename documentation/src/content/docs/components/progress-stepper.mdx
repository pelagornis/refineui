# ProgressStepper

ProgressStepper combines a progress bar and a stepper. Use it when you want to show how far a task has moved through ordered stages, and what comes next, at a glance.

A compact rail fits checkout headers, onboarding, and short wizards. For numbered 32px indicators with a title and description, use **[Stepper](/components/stepper/)** instead. For a percent-complete bar with no stages, use **[Progress](/components/progress/)**.

## Interface

### ProgressStepper

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Controlled active step. Match this to a `ProgressStepperItem` `value`. |
| `defaultValue` | `0` | `number` — Uncontrolled initial step. |
| `onValueChange` | — | `(value: number) => void` — Called when a step is activated. With this callback (or when uncontrolled), items are focusable and can be activated with click, Enter, or Space. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### ProgressStepperItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Step identity. Required. Compared with the stepper `value` to resolve state. |
| `disabled` | `false` | `boolean` — Blocks activation. The step still shows its visual state. |

### Parts

| Part | Role |
|------|------|
| `ProgressStepperList` | Ordered list (`ol`) and the built-in progress track. |
| `ProgressStepperMarker` | 8px color pip on the 16px rail. Render empty — do not pass icons. |
| `ProgressStepperLabel` | Optional caption under the marker. First label starts at the leading pip; last label ends at the trailing pip. |
