# Progress

Shows task progress. Follows Web Kit **Progress bar** `452:3994`.

For labeled steps on the same Progress track, use **[ProgressStepper](/components/progress-stepper/)**.

## Install & import

```tsx
import { Progress } from "@refineui/react";
```

## Basic usage

```tsx
<Progress value={45} max={100} />
```

## Preview

<div class="not-content">
  <ProgressPreview client:load />
</div>

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | (required) | Current value |
| `max` | `number` | `100` | Maximum |
| `size` | `"sm"` \| `"lg"` | `"sm"` | Track height (2px / 4px) |

Fill color matches Web Kit: single `primaryBlack` tone.

## Examples

### With a percentage label

Layout the label outside the component.

```tsx
<div style={{ display: "flex", alignItems: "center", gap: 8 }}>
  <Progress value={72} style={{ flex: 1 }} />
  <span>72%</span>
</div>
```
