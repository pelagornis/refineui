# Progress

Progress is a determinate bar. Use it when you know how far work has gone and how far is left — an upload, a download, or a percent complete.

There are no named stages. For stages on a compact rail, use **[ProgressStepper](/components/progress-stepper/)**. For numbered stages with a title and description, use **[Stepper](/components/stepper/)**. For an unknown wait, use **[Spinner](/components/spinner/)**.

## Interface

### Progress

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Current amount. Required. Mapped to fill width against `max`. |
| `max` | `100` | `number` — Maximum amount. Used for fill percent and `aria-valuemax`. |
| `size` | `"sm"` | `"sm"` \| `"lg"` — Track height. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).
