# Radio

Radio is a single option in a mutually exclusive group. Use several radios with the **same `name`** so the browser treats them as one field.

For independent on/off choices, use **[Checkbox](/components/checkbox/)**. For an instant settings toggle, use **[Switch](/components/switch/)**.

## Interface

### Radio

| Prop | Default | Type |
|------|---------|------|
| `label` | — | `string` — Primary name beside the control. |
| `description` | — | `string` — Supporting line under the label. |
| `allowUncheck` | `true` | `boolean` — When `true`, clicking the selected radio clears it. |
| `disabled` | — | `boolean` — Blocks interaction. |

Also accepts native `input` attributes except `type` (`value`, `checked`, `defaultChecked`, `onChange`, `name`, `id`, `aria-*`, `className`).

### RadioInput

Control-only radio (`type="radio"`). Use it when you compose the label yourself.

Also accepts native `input` attributes except `type`.
