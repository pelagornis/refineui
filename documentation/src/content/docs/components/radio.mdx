# Radio

Single radio item. Web Kit **Radio** `397:1001` supports optional title and description. Use the **same `name`** on multiple radios so the browser groups them.

## Install & import

```tsx
import { Radio } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Radio name="plan" value="free" defaultChecked title="Free" />
<Radio name="plan" value="pro" title="Pro" description="Billed monthly" />
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `title` | `ReactNode` | Primary label |
| `description` | `ReactNode` | Supporting caption |
| `disabled` | `boolean` | Disabled |

Uses **`InputHTMLAttributes`** except `type`: `value`, `checked`, `defaultChecked`, `onChange`, `name`, etc.

## Examples

### Fieldset group label

```tsx
<fieldset>
  <legend>Payment method</legend>
  <Radio name="pay" value="card" label="Card" />
  <Radio name="pay" value="bank" label="Bank transfer" />
</fieldset>
```
