# Resizable

Resizable is a group of panels the user can drag or resize with the keyboard. Use it for split layouts — sidebar and main, or a nested editor with a preview — when the user should own the widths and heights.

Each panel is a slot. Place `ResizableHandle` between adjacent panels as siblings. For overflow inside a pane, compose **[Scroll Area](/components/scroll-area/)**. For a sliding slide stage, use **[Carousel](/components/carousel/)** instead.

## Interface

### ResizablePanelGroup

| Prop | Default | Type |
|------|---------|------|
| `orientation` | `"horizontal"` | `"horizontal"` \| `"vertical"` — Layout axis. |
| `onLayout` | — | `(sizes: number[]) => void` — Panel sizes (%) after a resize settles. |

Also accepts native `div` attributes (`className`, `style`).

### ResizablePanel

| Prop | Default | Type |
|------|---------|------|
| `defaultSize` | `50` | `number` — Initial size (%). |
| `minSize` | `10` | `number` — Minimum size (%). |
| `maxSize` | `100` | `number` — Maximum size (%). |
| `size` | — | `number` — Controlled size (%). |
| `onResize` | — | `(size: number) => void` — Fires while resizing. |

Also accepts native `div` attributes.

### ResizableHandle

| Prop | Default | Type |
|------|---------|------|
| `withHandle` | `false` | `boolean` — Show a short center bar on the separator. |
| `disabled` | `false` | `boolean` — Disable drag and keyboard. |

Also accepts native `div` attributes.

### Parts

| Part | Role |
|------|------|
| `ResizablePanelGroup` | Flex container; owns size state. |
| `ResizablePanel` | Flexible pane (`flex-grow` from size %). |
| `ResizableHandle` | Focusable separator between adjacent panels. |
