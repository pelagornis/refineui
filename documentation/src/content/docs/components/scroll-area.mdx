# Scroll Area

Overflow container with a thin custom scrollbar. Built from Foundation spacing, radius, surface, and motion tokens. Not a Web Kit primitive — same **token-based composition** approach as Carousel / Bubble / Stepper.

## Install & import

```tsx
import {
  ScrollArea,
  ScrollAreaViewport,
  ScrollAreaScrollbar,
  ScrollAreaThumb,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<ScrollArea className="h-64">
  <ScrollAreaViewport>
    {/* long content */}
  </ScrollAreaViewport>
  <ScrollAreaScrollbar orientation="vertical">
    <ScrollAreaThumb />
  </ScrollAreaScrollbar>
</ScrollArea>
```

Set a finite height (or max-height) on `ScrollArea` — the viewport fills the root and scrolls when content overflows.

## Composition

```
ScrollArea
├── ScrollAreaViewport
└── ScrollAreaScrollbar (orientation)
    └── ScrollAreaThumb
```

Compose a second `ScrollAreaScrollbar` with `orientation="horizontal"` when both axes overflow.

## Props

### ScrollArea

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"hover"` \| `"always"` | `"hover"` | Show scrollbar on hover/focus/scroll, or always when overflow exists |

### ScrollAreaScrollbar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"vertical"` \| `"horizontal"` | `"vertical"` | Scroll axis |

### Parts

| Part | Role |
|------|------|
| `ScrollAreaViewport` | Scrollable region (native overflow; native bar hidden) |
| `ScrollAreaScrollbar` | Track; click jumps the thumb |
| `ScrollAreaThumb` | Draggable thumb sized to the visible ratio |

## Behavior

- Native scrollbar is hidden; pointer wheel / trackpad / keyboard still scroll the viewport.
- Outer rail is inset (`sizeXXXSmall`) with an inner **track** fill (`backgroundSurfaceSelected`, pill radius).
- Rail thickness is spacing `sizeMedium` (10px) — track and thumb share the full width.
- Thumb length/offset use px against that inner track (`clientSize / scrollSize`), floored at spacing `sizeXLarge`.
- Thumb uses `borderStrong` → `foregroundSecondary` on hover / drag.
- `type="hover"` fades the bar in on root hover, viewport focus, scroll, or thumb drag.

## Accessibility

- Viewport is focusable (`tabIndex={0}`) so keyboard users can scroll with arrow keys / Page Up·Down.
- Prefer labeling long regions with `aria-label` / `aria-labelledby` on `ScrollArea` or the viewport when the purpose is not obvious from surrounding copy.
