# Search Field

Search Field is a composable search control: a leading icon, a query input, and an optional clear button. Use it for filtering a list, a command palette row, or a page search.

It is not a validated text field — there is no error or success chrome. For that, use **[Input](/components/input/)** inside **[Field](/components/field/)**. The soft plate matches **[Input OTP](/components/input-otp/)** slots.

## Interface

### SearchField

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Controlled query. |
| `defaultValue` | `""` | `string` — Uncontrolled initial query. |
| `onValueChange` | — | `(value: string) => void` — Called when the query changes. |
| `disabled` | `false` | `boolean` — Disables the input and clear. |
| `appearance` | `"filled"` | `"filled"` \| `"plain"` — `filled` is a sunken control; `plain` is flush (for example Command). |
| `id` | — | `string` — Applied to the inner input. |
| `aria-label` | `"Search"` | `string` — Accessible name for the input. |

Also accepts native `div` attributes except `onChange` and `defaultValue` (`className`, `style`).

### SearchFieldInput

Extends native `<input>` attributes except `type`, `value`, `defaultValue`, `size`, and `disabled` (those come from the root). Renders `type="search"`. `autoComplete` defaults to `"off"`; `enterKeyHint` defaults to `"search"`.

### SearchFieldIcon / SearchFieldClear

Optional `children` replace the default search / dismiss glyphs. `SearchFieldClear` accepts native `button` attributes except `type` (`aria-label` defaults to `"Clear search"`).
