# Search Field

Composable search control. Soft plate matches **Input OTP** slots (`surfaceSelected`). One size: `control-height-md` (44px), `roundedXLarge`, horizontal padding `sizeLarge` (16px). Search glyph is regular `iconSizes.medium` (24px); clear is filled `iconSizes.small` (20px). No Web Kit COMPONENT_SET; visuals use **`@refineui/tokens`** only.

Search is not a validated text field — no error / success chrome.

## Install & import

```tsx
import {
  SearchField,
  SearchFieldClear,
  SearchFieldIcon,
  SearchFieldInput,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
const [query, setQuery] = useState("");

<SearchField value={query} onValueChange={setQuery}>
  <SearchFieldIcon />
  <SearchFieldInput placeholder="Search" />
  <SearchFieldClear />
</SearchField>
```

## Composition

```
SearchField
├── SearchFieldIcon (optional — defaults to search glyph)
├── SearchFieldInput
└── SearchFieldClear (optional — shown when the query is not empty)
```

## Signature

Same soft-plate states as [Input OTP](/components/input-otp/) slots (light mode):

| State | Token | Light |
| --- | --- | --- |
| **Rest** | `backgroundSurfaceSelected` | neutral200 |
| **Hover** | `backgroundSurfaceActive` | neutral150 |
| **Focus** | `backgroundSurfaceSelected` + `borderDefault` | grey plate + thin border |
| **Disabled** | `backgroundSurfaceDisabled` | neutral150 |

Focus keeps the soft plate and only adds a thin `borderDefault` outline (same as OTP slots).

## Props

### SearchField

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Controlled query |
| `defaultValue` | `string` | `""` | Uncontrolled initial query |
| `onValueChange` | `(value: string) => void` | — | Query callback |
| `disabled` | `boolean` | `false` | Disables input and clear |
| `appearance` | `"filled" \| "plain"` | `"filled"` | `filled` = sunken control; `plain` = flush (e.g. Command) |
| `id` | `string` | — | Applied to the inner input |
| `aria-label` | `string` | `"Search"` | Accessible name for the input |

### SearchFieldInput

Extends native `<input>` attributes except `type` / `value` / `size` / `disabled` (those come from the root). Renders `type="search"`.

### SearchFieldIcon / SearchFieldClear

Optional `children` replace the default search / dismiss glyphs.

## Accessibility

- Root `aria-label` defaults to `"Search"` and is forwarded to `SearchFieldInput`.
- **Escape** clears a non-empty query and keeps focus in the field.
- `SearchFieldClear` is `aria-label="Clear search"` and focuses the input after clearing.
- Native browser search decorations are hidden; use `SearchFieldClear` instead.
