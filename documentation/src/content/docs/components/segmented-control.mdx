# Segmented Control

Segmented Control is a compact mutually exclusive choice. Use it when a few options sit on one pill track — Day / Week / Month, or Overview / Analytics — and you only need the selected value.

The control reports selection. It does not own panels. For page or section panels with `tablist` / `tabpanel`, use **[Tabs](/components/tabs/)**. For site destinations with flyouts, use **[Navigation Menu](/components/navigation-menu/)**.

## Interface

### SegmentedControl

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Controlled selected value. Match this to a `SegmentedControlItem` `value`. |
| `defaultValue` | `""` | `string` — Uncontrolled initial value. |
| `onValueChange` | — | `(value: string) => void` — Called when selection changes. |

Also accepts native `div` attributes (`aria-label`, `className`, `style`).

### SegmentedControlItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Option identity. Required. |
| `disabled` | `false` | `boolean` — Blocks activation. The item still shows its visual state. |

Also accepts native `button` attributes (`className`, `aria-*`). Children are the visible label.
