# Select

Figma Web Kit `Select` — trigger `1116:1429`, menu `1117:1177`, item COMPONENT_SET `1144:2411` (State nodes: Default `1144:2410`, Hover `1144:2417`, Pressed `1144:2429`, Selected `1144:2435`, Disabled `1144:2423`), section `1144:2756`. Because MCP `get_design_context` returns one node at a time, specify each variant node id for per-state specs.

## Install & import

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectPortal,
  SelectContent,
  SelectItem,
  SelectSection,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

Put `SelectContent` inside `SelectPortal` so the panel renders in a portal.

```tsx
<Select placeholder="Choose country" onValueChange={(next) => console.log(next)}>
  <SelectTrigger>
    <SelectValue placeholder="Select an option" />
  </SelectTrigger>
  <SelectPortal>
    <SelectContent>
      <SelectSection>Asia</SelectSection>
      <SelectItem value="kr">Korea Standard Time</SelectItem>
      <SelectItem value="jp">Japan Standard Time</SelectItem>
    </SelectContent>
  </SelectPortal>
</Select>;
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placeholder` | `string` | — | Label when nothing is selected |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Field height, padding, typography |
| `fullWidth` | `boolean` | `false` | Full width |
| `disabled` | `boolean` | `false` | Disabled |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled initial value (`undefined` = empty) |
| `open` | `boolean` | — | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Open state change |
| `onValueChange` | `(value: string) => void` | — | Selection change |

## Composition

- `SelectTrigger` — field trigger
- `SelectValue` — current label / placeholder
- `SelectPortal` — portals menu to `document.body` (or `container`)
- `SelectContent` — menu panel
- `SelectGroup` — group
- `SelectSection` — section title
- `SelectItem` — option
