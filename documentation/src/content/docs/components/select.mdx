# Select

Figma Web Kit `Select` — 트리거 `1116:1429`, 메뉴 `1117:1177`, 항목 COMPONENT_SET `1144:2411`(State 변형 노드: Default `1144:2410`, Hover `1144:2417`, Pressed `1144:2429`, Selected `1144:2435`, Disabled `1144:2423`), 섹션 `1144:2756`. MCP `get_design_context`는 단일 노드만 반환하므로 State별 스펙은 변형 노드 id를 각각 지정합니다.

## 설치·임포트

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectPortal,
  SelectContent,
  SelectItem,
  SelectSection,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

메뉴는 `SelectPortal` 안에 `SelectContent`를 두고, 패널은 포털로 렌더링합니다.

```tsx
<Select placeholder="국가 선택" onValueChange={(next) => console.log(next)}>
  <SelectTrigger>
    <SelectValue placeholder="선택하세요" />
  </SelectTrigger>
  <SelectPortal>
    <SelectContent>
      <SelectSection>Asia</SelectSection>
      <SelectItem value="kr">Korea Standard Time</SelectItem>
      <SelectItem value="jp">Japan Standard Time</SelectItem>
    </SelectContent>
  </SelectPortal>
</Select>;
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `placeholder` | `string` | — | 미선택 상태 라벨 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 필드 높이·패딩·타이포 |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | `false` | 비활성화 |
| `value` | `string` | — | 제어 값 |
| `defaultValue` | `string` | — | 비제어 초기값 (`undefined`면 미선택) |
| `open` | `boolean` | — | 제어 열림 상태 |
| `onOpenChange` | `(open: boolean) => void` | — | 열림 상태 변경 |
| `onValueChange` | `(value: string) => void` | — | 선택 값 변경 |

## Composition

- `SelectTrigger` — 필드 트리거
- `SelectValue` — 현재 선택 라벨/placeholder
- `SelectPortal` — 메뉴를 `document.body`(또는 `container`)로 포털
- `SelectContent` — 메뉴 패널
- `SelectGroup` — 그룹
- `SelectSection` — 섹션 제목
- `SelectItem` — 선택 항목
