# Select

네이티브 `<select>` 요소를 래핑한 컴포넌트입니다. Figma Web Kit에는 **단독 Select COMPONENT_SET**이 없고, 필드 스타일은 **[Input](/components/input/)** `518:7373`과 동일한 `size`(sm / md / lg) 규칙을 따릅니다.

## 설치·임포트

```tsx
import { Select } from "@refineui/react";
import type { SelectOption } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

`options`에 `{ value, label }` 배열을 넘깁니다. 플레이스홀더는 빈 값 `<option>`으로 렌더됩니다.

```tsx
const options: SelectOption[] = [
  { value: "kr", label: "한국" },
  { value: "us", label: "미국" },
];

<Select
  options={options}
  placeholder="국가 선택"
  defaultValue=""
  onChange={(e) => console.log(e.target.value)}
  aria-label="국가"
/>;
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `options` | `SelectOption[]` | (필수) | `{ value, label }` 목록 |
| `placeholder` | `string` | — | 첫 옵션에 빈 값으로 표시 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 필드 높이·패딩·타이포 (Input과 동일) |
| `error` | `boolean` | `false` | 에러 시 테두리 `red500` |
| `success` | `boolean` | `false` | 성공 시 테두리 `green500` |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | — | 비활성 스타일 |

그 외 **`SelectHTMLAttributes`** (`name`, `value`, `defaultValue`, `onChange`, `required` 등)를 그대로 전달할 수 있습니다. HTML 속성 `size`(표시 행 수)는 `SelectProps`에서 제외되어 있으며, **`size` prop은 Web Kit 필드 크기**만 의미합니다.

## 예시: 제어 컴포넌트

```tsx
const [v, setV] = useState("a");

<Select
  options={options}
  value={v}
  onChange={(e) => setV(e.target.value)}
  aria-label="제어 예시"
/>
```
