# Select

Select is a custom field that opens a menu of options. Use it when the user must pick one value from a known list — a country, a timezone, a plan.

Put `SelectContent` inside `SelectPortal` so the panel renders in a portal. For a short mutually exclusive set that should stay visible, use **[Radio](/components/radio/)**. For a labeled form shell, wrap Select in **[Field](/components/field/)**.

## Interface

### Select

| Prop | Default | Type |
|------|---------|------|
| `placeholder` | — | `string` — Label when nothing is selected. `SelectValue` can override this. |
| `size` | `"md"` | `"sm"` \| `"md"` \| `"lg"` — Trigger height, padding, and type. Inherits from [Field](/components/field/) when omitted. |
| `fullWidth` | `false` | `boolean` — Stretch the trigger to the parent width. |
| `disabled` | `false` | `boolean` — Blocks opening and selection. |
| `value` | — | `string` — Controlled selected value. |
| `defaultValue` | `""` | `string` — Uncontrolled initial value. Empty string means nothing selected. |
| `open` | — | `boolean` — Controlled open state. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when the menu opens or closes. |
| `onValueChange` | — | `(value: string) => void` — Called when an item is selected. |

Also accepts native `div` attributes except `onChange` and `defaultValue` (`className`, `style`, `aria-*`).

### SelectItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Option identity. Required. |
| `disabled` | — | `boolean` — Blocks selection of this item. |
| `textValue` | — | `string` — Plain-text equivalent of the label when children are not a string. |

### SelectValue

| Prop | Default | Type |
|------|---------|------|
| `placeholder` | — | `string` — Shown when there is no selection. Falls back to Select `placeholder`, then `"Select..."`. |

### SelectContent

| Prop | Default | Type |
|------|---------|------|
| `position` | `"item-aligned"` | `"item-aligned"` \| `"popper"` — Menu placement. `popper` is a compact panel below or above the trigger. |
| `container` | — | `HTMLElement \| null` — Portal target. Otherwise the nearest `SelectPortal` or `document.body`. |

### SelectPortal

| Prop | Default | Type |
|------|---------|------|
| `container` | — | `HTMLElement \| null` — Portal target for nested `SelectContent`. |

### Parts

| Part | Role |
|------|------|
| `SelectTrigger` | Combobox field that opens the menu. |
| `SelectGroup` | Groups related items. |
| `SelectSection` | Section title in the menu. |
| `SelectIcon` | Optional icon slot; trigger already includes a chevron. |
| `SelectViewport` | Scrollable region inside the menu. |
| `SelectLabel` | Extra label inside the menu. |
| `SelectSeparator` | Divider between groups. |
| `SelectItemText` | Item label slot. |
| `SelectItemIndicator` | Selected-item indicator slot. |
| `SelectScrollUpButton` / `SelectScrollDownButton` | Scroll affordances in a long list. |
| `SelectArrow` | Menu arrow. |
