# Select

Figma Web Kit `Select` (`1116:1429`, `1117:1177`, `1144:2410`, `1144:2756`) 스타일을 반영한 커스텀 Select 컴포넌트입니다.

## 설치·임포트

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectSection,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Select placeholder="국가 선택" defaultValue="" onValueChange={(next) => console.log(next)}>
  <SelectTrigger>
    <SelectValue placeholder="선택하세요" />
  </SelectTrigger>
  <SelectContent>
    <SelectSection>Asia</SelectSection>
    <SelectItem value="kr">Korea Standard Time</SelectItem>
    <SelectItem value="jp">Japan Standard Time</SelectItem>
  </SelectContent>
</Select>;
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `placeholder` | `string` | — | 미선택 상태 라벨 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 필드 높이·패딩·타이포 |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | `false` | 비활성화 |
| `value` | `string` | — | 제어 값 |
| `defaultValue` | `string` | `""` | 비제어 초기값 |
| `open` | `boolean` | — | 제어 열림 상태 |
| `onOpenChange` | `(open: boolean) => void` | — | 열림 상태 변경 |
| `onValueChange` | `(value: string) => void` | — | 선택 값 변경 |

## Composition

- `SelectTrigger` — 필드 트리거
- `SelectValue` — 현재 선택 라벨/placeholder
- `SelectContent` — 메뉴 패널
- `SelectGroup` — 그룹
- `SelectSection` — 섹션 제목
- `SelectItem` — 선택 항목
