# Skeleton

Placeholder while content loads. Follows Web Kit **Skeleton** `570:6175`; background and shimmer use MCP alias colors, animation from **`refineui.css`**.

## Install & import

```tsx
import { Skeleton } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Skeleton width="100%" height={20} />
<Skeleton shape="circle" width={40} />
```

## Preview

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `width` | `number` \| `string` | — | Width |
| `height` | `number` \| `string` | — | Height |
| `shape` | `"rectangle"` \| `"circle"` | `"rectangle"` | Circle is typical for avatars |
