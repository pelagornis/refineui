# Skeleton

Skeleton is a placeholder for content that has not loaded yet. Use it to reserve layout so the page does not jump when real content arrives.

It is a static shape with a soft opacity pulse — not a sliding shimmer. For an in-progress process with no layout to reserve, use **[Spinner](/components/spinner/)**. For determinate work as a bar, use **[Progress](/components/progress/)**.

## Interface

### Skeleton

| Prop | Default | Type |
|------|---------|------|
| `width` | — | `number` \| `string` — Width of the placeholder. Rectangles default to full width. On a circle, one dimension is used for both axes. |
| `height` | — | `number` \| `string` — Height of the placeholder. Rectangles default to the skeleton line height. |
| `shape` | `"rectangle"` | `"rectangle"` \| `"circle"` — Line or block versus avatar-style disc. |

Also accepts native `div` attributes (`className`, `style`).
