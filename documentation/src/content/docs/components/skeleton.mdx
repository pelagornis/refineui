# Skeleton

콘텐츠가 로드되기 전 자리 표시입니다. Web Kit **Skeleton** `570:6175`를 따르며, 배경·쉬머는 MCP Alias 색, 애니메이션은 **`refineui.css`** 쉬머로 처리합니다.

## 설치·임포트

```tsx
import { Skeleton } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Skeleton width="100%" height={20} />
<Skeleton shape="circle" width={40} />
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `width` | `number` \| `string` | — | 너비 |
| `height` | `number` \| `string` | — | 높이 |
| `shape` | `"rectangle"` \| `"circle"` | `"rectangle"` | 원형은 보통 아바타 자리 |
