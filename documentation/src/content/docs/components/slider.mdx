# Slider

Slider is a styled `type="range"` input. Use it when the value is easier to choose by dragging than by typing — volume, opacity, a percent.

`size` changes rail thickness (`sm` / `md`). For an exact integer with steppers, use **[SpinButton](/components/spin-button/)**. For a read-only fill, use **[Progress](/components/progress/)**.

## Interface

### Slider

| Prop | Default | Type |
|------|---------|------|
| `min` | `0` | `number` — Lower bound. |
| `max` | `100` | `number` — Upper bound. |
| `step` | `1` | `number` — Increment between values. |
| `value` | — | `number` — Controlled value. |
| `defaultValue` | — | `number` — Uncontrolled initial value. |
| `onChange` | — | `(value: number) => void` — Called with the numeric value (not the native event). |
| `size` | `"md"` | `"sm"` \| `"md"` — Rail thickness. |

Also accepts native `input` attributes except `type`, native `onChange`, and `size` (`aria-label`, `disabled`, `className`, `style`).
