# Slider

Styled `type="range"` input. Web Kit **Slider** `526:1556` — use **`size`** for rail thickness (sm/md).

## Install & import

```tsx
import { Slider } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Slider min={0} max={100} defaultValue={50} onChange={(v) => console.log(v)} aria-label="Volume" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `min` | `number` | `0` | Minimum |
| `max` | `number` | `100` | Maximum |
| `step` | `number` | `1` | Step |
| `value` | `number` | — | Controlled value |
| `defaultValue` | `number` | — | Uncontrolled value |
| `onChange` | `(value: number) => void` | — | Value change |
| `size` | `"sm"` \| `"md"` | `"md"` | Rail thickness |

## Examples

### Controlled

```tsx
const [pct, setPct] = useState(30);
<Slider value={pct} onChange={setPct} min={0} max={100} />;
```
