# SpinButton

SpinButton is a numeric field with increment and decrement controls. Use it for quantity, a count, or any integer that is easier to bump than to type from scratch.

The value is always controlled: pass `value` and `onChange`. For a number typed on a single line without steppers, use **[Input](/components/input/)** with `type="number"`. For a value chosen by dragging, use **[Slider](/components/slider/)**.

## Interface

### SpinButton

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Current value. Required. |
| `onChange` | — | `(value: number) => void` — Called with the next numeric value. Required. |
| `placeholder` | — | `string` — Shown in the value input when drafting an empty string. |
| `min` | — | `number` — Lower bound. Clamps steps, Home, and typed commits. |
| `max` | — | `number` — Upper bound. Clamps steps, End, and typed commits. |
| `step` | `1` | `number` — Increment for the stepper and arrow keys. |
| `size` | `"md"` | `"sm"` \| `"md"` \| `"lg"` — Field height and type, aligned with Input / Select. |
| `disabled` | `false` | `boolean` — Disables typing and both steppers. |

Also accepts native `div` attributes except `onChange` (`aria-label`, `className`, `style`). Default `aria-label` is `"Spin button"`.
