# SpinButton

숫자 값을 **직접 입력**하거나 **위/아래 스테퍼**로 바꿉니다. Web Kit **Spin Button** `561:2067`과 `docs/design-specs-web-kit.md` Spin Button 절을 따릅니다.

## 설치·임포트

```tsx
import { SpinButton } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

값은 **제어 컴포넌트**로 `value` + `onChange`를 넘깁니다.

```tsx
const [n, setN] = useState(0);
<SpinButton value={n} onChange={setN} min={0} max={99} aria-label="수량" />;
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `value` | `number` | (필수) | 현재 값 |
| `onChange` | `(value: number) => void` | (필수) | 값 변경 |
| `min` | `number` | — | 최소 |
| `max` | `number` | — | 최대 |
| `step` | `number` | — | 증감 단위 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | 필드 높이·타이포 |
| `disabled` | `boolean` | — | 비활성 |

## 예시

### 범위 제한

```tsx
<SpinButton value={qty} onChange={setQty} min={1} max={10} step={1} />
```
