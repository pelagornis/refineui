# SpinButton

Enter a number **directly** or change it with **up/down steppers**. Follows Web Kit **Spin Button** `561:2067` and the Spin Button section in `docs/design-specs-web-kit.md`.

## Install & import

```tsx
import { SpinButton } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

Pass **`value`** and **`onChange`** as a controlled component.

```tsx
const [n, setN] = useState(0);
<SpinButton value={n} onChange={setN} min={0} max={99} aria-label="Quantity" />;
```

## Preview

The docs preview (`PreviewFrame` + `[data-refineui-preview]`) is **full width** of the content column, so with only the default `w-full` the spin button can stretch horizontally inside the gray box. The demo below uses **`className="w-auto"`** so the control keeps its intrinsic width. In your app, place it inside a **width-constrained parent** (form row, grid cell, etc.) and `w-full` will fill that slot.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | (required) | Current value |
| `onChange` | `(value: number) => void` | (required) | Value change |
| `min` | `number` | — | Minimum |
| `max` | `number` | — | Maximum |
| `step` | `number` | — | Step increment |
| `size` | `"sm"` \| `"md"` \| `"lg"` | `"md"` | Field height and typography |
| `disabled` | `boolean` | — | Disabled |

## Examples

### Bounded range

```tsx
<SpinButton value={qty} onChange={setQty} min={1} max={10} step={1} />
```
