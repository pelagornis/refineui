# Spinner

로딩 중임을 나타냅니다. Web Kit **Spinner** `550:3669`의 크기 스케일을 따릅니다.

## 설치·임포트

```tsx
import { Spinner } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Spinner size="md" />
```

## Preview

<div class="not-content">
  <SpinnerPreview client:load />
</div>

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `size` | `"xs"` … `"xxl"` | `"md"` | 지름·링 두께 |
| `label` | `ReactNode` | — | 라벨이 있으면 표시 |
| `labelPosition` | `"left"` \| `"right"` \| `"top"` \| `"bottom"` | `"right"` | 라벨과의 위치 |

## 예시

### 라벨 + 상단

```tsx
<Spinner size="lg" label="불러오는 중" labelPosition="top" />
```
