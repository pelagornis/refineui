# Spinner

Spinner shows that work is happening and the duration is not known. Use it on a button, a panel, or a page while a request or job runs.

For content that has a known layout but is not ready, use **[Skeleton](/components/skeleton/)**. For a known percent, use **[Progress](/components/progress/)**.

## Interface

### Spinner

| Prop | Default | Type |
|------|---------|------|
| `size` | `"md"` | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` \| `"xxl"` — Diameter and ring width. |
| `label` | — | `ReactNode` — Visible status copy. When set, shown beside or around the ring. |
| `labelPosition` | `"right"` | `"left"` \| `"right"` \| `"top"` \| `"bottom"` — Placement of `label` relative to the ring. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`). Children are not used.
