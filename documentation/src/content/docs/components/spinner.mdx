# Spinner

Indicates loading state. Follows Web Kit **Spinner** `550:3669` size scale.

## Install & import

```tsx
import { Spinner } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Spinner size="md" />
```

## Preview

<div class="not-content">
  <SpinnerPreview client:load />
</div>

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"xs"` … `"xxl"` | `"md"` | Diameter and ring width |
| `label` | `ReactNode` | — | Shown when set |
| `labelPosition` | `"left"` \| `"right"` \| `"top"` \| `"bottom"` | `"right"` | Label placement |

## Examples

### Label on top

```tsx
<Spinner size="lg" label="Loading" labelPosition="top" />
```
