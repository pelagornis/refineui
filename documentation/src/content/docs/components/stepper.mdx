# Stepper

Stepper shows progress across ordered stages with a numbered indicator, title, and description. Use it when each stage needs that extra context — account setup, long wizards, settings flows.

For a compact Progress track with markers on the rail (checkout headers, short wizards), use **[ProgressStepper](/components/progress-stepper/)** instead.

## Interface

### Stepper

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Controlled active step. Match this to a `StepperItem` `value`. |
| `defaultValue` | `0` | `number` — Uncontrolled initial step. |
| `onValueChange` | — | `(value: number) => void` — Called when a step is activated. With this callback (or when uncontrolled), items are focusable and can be activated with click, Enter, or Space. |
| `orientation` | `"horizontal"` | `"horizontal"` \| `"vertical"` — Layout axis. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### StepperItem

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `number` — Step identity. Required. Compared with the stepper `value` to resolve state. |
| `disabled` | `false` | `boolean` — Blocks activation. The step still shows its visual state. |

### Parts

| Part | Role |
|------|------|
| `StepperList` | Ordered list (`ol`). |
| `StepperIndicator` | 32px circle. Render a number or icon as children. |
| `StepperContent` | Title + description column. |
| `StepperTitle` | Stage name. |
| `StepperDescription` | Optional extra line. |
| `StepperSeparator` | Connector between items. Turns brand after a `complete` peer. |
