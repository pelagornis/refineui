# Stepper

Visual progress across ordered steps. Built from existing Foundation tokens (circle indicator, progress-track connector, brand / surface colors, motion). Not a Web Kit primitive — same **token-based composition** approach as Carousel / Bubble.

For a compact Progress track with markers on the rail, use **[ProgressStepper](/components/progress-stepper/)**.

## Install & import

```tsx
import {
  Stepper,
  StepperList,
  StepperItem,
  StepperIndicator,
  StepperContent,
  StepperTitle,
  StepperDescription,
  StepperSeparator,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Stepper value={1} onValueChange={setStep} orientation="horizontal">
  <StepperList>
    <StepperItem value={0}>
      <StepperIndicator>1</StepperIndicator>
      <StepperContent>
        <StepperTitle>Account</StepperTitle>
        <StepperDescription>Profile & email</StepperDescription>
      </StepperContent>
    </StepperItem>
    <StepperSeparator />
    <StepperItem value={1}>
      <StepperIndicator>2</StepperIndicator>
      <StepperContent>
        <StepperTitle>Plan</StepperTitle>
        <StepperDescription>Billing cycle</StepperDescription>
      </StepperContent>
    </StepperItem>
  </StepperList>
</Stepper>
```

## States

Each `StepperItem` derives `data-state` from its `value` vs the active step:

| State | When | Visual |
|-------|------|--------|
| `complete` | `value < active` | Brand-filled indicator · brand connector after it |
| `current` | `value === active` | Brand-subtle fill · scale + ring |
| `upcoming` | `value > active` | Neutral outline · muted label |

Pass a checkmark (e.g. `WebIcon` `checkmark`) as `StepperIndicator` children for completed steps — the indicator is a slot, not a convenience API.

## Props

### Stepper

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Controlled active step |
| `defaultValue` | `number` | `0` | Uncontrolled start |
| `onValueChange` | `(value: number) => void` | — | Change callback; enables click / keyboard activation |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` | Layout axis |

### StepperItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Step identity (required) |
| `disabled` | `boolean` | `false` | Blocks activation |

### Parts

| Part | Role |
|------|------|
| `StepperList` | Ordered list (`ol`) |
| `StepperIndicator` | 32px foundation circle |
| `StepperContent` | Title + description column |
| `StepperTitle` / `StepperDescription` | Label slots |
| `StepperSeparator` | Connector; turns brand after a `complete` peer |

Controlled without `onValueChange` is display-only. With `onValueChange` (or uncontrolled), steps are focusable and activatable via click / Enter / Space.
