# Switch

Switch is an on/off control. Use it for a single setting that takes effect immediately — notifications, dark mode, a feature flag.

`Toggle` is the same implementation (`data-refineui="switch"`). For a labeled option that can sit beside others, use **[Checkbox](/components/checkbox/)**. For a mutually exclusive set, use **[Radio](/components/radio/)**.

## Interface

### Switch

| Prop | Default | Type |
|------|---------|------|
| `checked` | `false` | `boolean` — On (`true`) or off (`false`). |
| `onCheckedChange` | — | `(checked: boolean) => void` — Called with the next value when toggled. |
| `disabled` | — | `boolean` — Blocks interaction and uses disabled track and thumb colors. |

Sets `role="switch"` and `aria-checked`. Also accepts native `button` attributes except `children` (`aria-label`, `onClick`, `className`).
