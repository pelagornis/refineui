# Switch

켜짐/꺼짐 상태를 나타내는 스위치입니다. Web Kit COMPONENT_SET 이름은 **Switch** `270:3057`이며, **`Toggle`**과 **동일한 구현**을 export합니다(`data-refineui="switch"`).

## 설치·임포트

```tsx
import { Switch } from "@refineui/react";
// 또는 동일 컴포넌트:
// import { Toggle } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
const [on, setOn] = useState(false);
<Switch checked={on} onCheckedChange={setOn} aria-label="알림" />;
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `checked` | `boolean` | 켜짐 여부 |
| `onCheckedChange` | `(checked: boolean) => void` | 클릭 시 상태 변경 |
| `disabled` | `boolean` | 비활성 (트랙·썸 색 변경) |

`role="switch"`, `aria-checked`가 설정됩니다. 나머지는 **`ButtonHTMLAttributes`**에서 `children` 제외.

## 예시

### 폼 기본값

```tsx
<Switch defaultChecked aria-label="다크 모드" />
```
