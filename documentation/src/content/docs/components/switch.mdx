# Switch

On/off switch. Web Kit COMPONENT_SET **Switch** `270:3057`. **`Toggle`** is the **same implementation** (`data-refineui="switch"`).

## Install & import

```tsx
import { Switch } from "@refineui/react";
// or the same component:
// import { Toggle } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
const [on, setOn] = useState(false);
<Switch checked={on} onCheckedChange={setOn} aria-label="Notifications" />;
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `checked` | `boolean` | On/off |
| `onCheckedChange` | `(checked: boolean) => void` | Called when toggled |
| `disabled` | `boolean` | Disabled (track and thumb colors) |

Sets `role="switch"` and `aria-checked`. Other props from **`ButtonHTMLAttributes`** except `children`.

## Examples

### Default in a form

