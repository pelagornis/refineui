# Table

Table is a dense semantic table for rows of related data — invoices, members, logs. Use it when columns have meaning and the user may scan, compare, or select a row.

Each part maps to a native table slot. There is no `columns` or `rows` convenience API. Wrap the table in **[Card](/components/card/)** when you need a bordered panel. For a long body, wrap it in **[Scroll Area](/components/scroll-area/)**; horizontal overflow is already built into `Table`.

## Interface

All parts extend the matching native HTML attributes (`TableHTMLAttributes`, `ThHTMLAttributes`, `TdHTMLAttributes`, and so on) plus optional `className`.

### TableHead

| Prop | Default | Type |
|------|---------|------|
| `scope` | `"col"` | `ThHTMLAttributes["scope"]` — Column header by default. Pass `"row"` for a row header. |

### Parts

| Part | Renders | Role |
|------|---------|------|
| `Table` | `<div>` + `<table>` | Padded scroll shell. `forwardRef` on `<table>`. |
| `TableHeader` | `<thead>` | Header strip. |
| `TableBody` | `<tbody>` | Body rows — hover / selected chips. |
| `TableFooter` | `<tfoot>` | Footer strip. |
| `TableRow` | `<tr>` | Row. Set `data-state="selected"` to select. |
| `TableHead` | `<th>` | Header cell. |
| `TableCell` | `<td>` | Body or footer cell. |
| `TableCaption` | `<caption>` | Accessible caption. |
