# Tabs

Tabs switch views in the same page. Use them when each panel is equally important and the user should stay on one URL.

The list is a `tablist` of `tab` buttons; each panel is a `tabpanel`. For a compact mutually exclusive choice that is not a page section, use **[Segmented Control](/components/segmented-control/)**. For site destinations and flyouts, use **[Navigation Menu](/components/navigation-menu/)**.

## Interface

### Tabs

| Prop | Default | Type |
|------|---------|------|
| `defaultValue` | `""` | `string` — Uncontrolled initial selected value. |
| `value` | — | `string` — Controlled selected value. |
| `onValueChange` | — | `(value: string) => void` — Called when selection changes. |

Also accepts native `div` attributes (`className`, `style`, `aria-*`).

### TabsTrigger

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Tab identity. Required. Must match a `TabsContent` `value`. |
| `disabled` | `false` | `boolean` — Removes the tab from keyboard selection. |

`children` is required (the visible label). Also accepts native `button` attributes except `type`.

### TabsContent

| Prop | Default | Type |
|------|---------|------|
| `value` | — | `string` — Panel identity. Required. Shown when it matches the selected tab. |

### Parts

| Part | Role |
|------|------|
| `TabsList` | `tablist` and the sliding underline indicator. |
| `TabsTrigger` | `tab` button. |
| `TabsContent` | `tabpanel` for the matching value. |
