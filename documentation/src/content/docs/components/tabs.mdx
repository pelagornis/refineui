# Tabs

In-page view switching with **`tablist` / `tab` / `tabpanel`**. Token-based underline track — **Figma Web Kit `Tabs` (`636:5371`)** is the pill visual shipped as [Segmented Control](/components/segmented-control/).

| Use | Component |
| --- | --- |
| Section panels under a full-width bar | **Tabs** |
| Compact mutually exclusive choice | [Segmented Control](/components/segmented-control/) |
| Site destinations + flyouts | [Navigation Menu](/components/navigation-menu/) |

## Install & import

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

Compose **`Tabs` → `TabsList` → `TabsTrigger`** and **`TabsContent`**. Uncontrolled: **`defaultValue`**; controlled: **`value`** + **`onValueChange`**.

```tsx
<Tabs defaultValue="a">
  <TabsList>
    <TabsTrigger value="a">First</TabsTrigger>
    <TabsTrigger value="b">Second</TabsTrigger>
  </TabsList>
  <TabsContent value="a">
    <p>Panel A</p>
  </TabsContent>
  <TabsContent value="b">
    <p>Panel B</p>
  </TabsContent>
</Tabs>
```

## Props

### `Tabs`

| Prop | Type | Description |
| --- | --- | --- |
| `defaultValue` | `string` | Initial value (uncontrolled) |
| `value` | `string` | Selected value (controlled) |
| `onValueChange` | `(value: string) => void` | Called when selection changes |

### `TabsTrigger`

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `string` | (Required) id matching a panel |
| `disabled` | `boolean` | Disabled |

### `TabsContent`

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `string` | (Required) Panel to show when selected |

## Accessibility

- `role="tablist"` / `tab` / `tabpanel`, with `aria-controls` · `aria-labelledby`.
- Arrow keys / Home / End move focus and selection.
