# Tabs

한 화면에서 섹션을 전환할 때 쓰는 탭입니다. Web Kit **Tabs** `636:5371` · **Tabs / Item** `636:5372` — **Pill** 세그먼트만 지원합니다.

## 설치·임포트

```tsx
import { Tabs } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Tabs
  defaultTab="a"
  items={[
    { id: "a", label: "첫 번째", content: <p>내용 A</p> },
    { id: "b", label: "두 번째", content: <p>내용 B</p>, disabled: true },
  ]}
  onChange={(id) => console.log(id)}
/>
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `items` | `TabItem[]` | (필수) | `id`, `label`, `content`, 선택 `disabled` |
| `defaultTab` | `string` | 첫 비활성 아님 탭 | 초기 선택 id |
| `onChange` | `(id: string) => void` | — | 탭 변경 시 |

## 접근성

- 탭 목록은 키보드(화살표)로 이동하도록 구현되어 있습니다.
- 패널과의 연결은 내부 `aria-*`로 맞춥니다.
