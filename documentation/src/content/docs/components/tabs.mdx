# Tabs

Tabs for switching sections on one screen. Web Kit **Tabs** `636:5371` · **Tabs / Item** `636:5372`. Compose like **Card**: **`Tabs` → `TabsList` → `TabsTrigger`** and **`TabsContent`** (same pattern as Radix/shadcn).
Matches latest Web Kit for Pill track/item radius, item padding, selected shadow, and hover tokens (`surfaceHover` / `foregroundPrimaryHover`).

## Install & import

```tsx
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsContent,
} from "@refineui/react";
import "@refineui/react/refineui.css";
```

Import alongside other RefineUI components from the **same package** (not a `@/components/ui/*` alias).

## Basic usage (composed API)

Same composition as shadcn `Tabs` · `TabsList` · `TabsTrigger` · `TabsContent`. Uncontrolled: **`defaultValue`**; controlled: **`value`** + **`onValueChange`**.

```tsx
<Tabs defaultValue="a" className="max-w-md">
  <TabsList>
    <TabsTrigger value="a">First</TabsTrigger>
    <TabsTrigger value="b">Second</TabsTrigger>
  </TabsList>
  <TabsContent value="a">
    <p>Panel A</p>
  </TabsContent>
  <TabsContent value="b">
    <p>Panel B</p>
  </TabsContent>
</Tabs>
```

## With Card (panel per tab)

Put a RefineUI **`Card`** inside each `TabsContent`. Below matches the docs site preview (`TabsDemo`).

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@refineui/react";

export function TabsDemo() {
  return (
    <Tabs defaultValue="overview" className="w-full max-w-[400px]">
      <TabsList>
        <TabsTrigger value="overview">Overview</TabsTrigger>
        <TabsTrigger value="analytics">Analytics</TabsTrigger>
        <TabsTrigger value="reports">Reports</TabsTrigger>
        <TabsTrigger value="settings">Settings</TabsTrigger>
      </TabsList>
      <TabsContent value="overview">
        <Card>
          <CardHeader>
            <CardTitle>Overview</CardTitle>
            <CardDescription>
              View your key metrics and recent project activity.
            </CardDescription>
          </CardHeader>
          <CardContent className="refineui-typo-body-4 text-refineui-alias-foreground-secondary">
            You have 12 active projects and 3 pending tasks.
          </CardContent>
        </Card>
      </TabsContent>
    </Tabs>
  );
}
```

## Props

### `Tabs`

| Prop | Type | Description |
| --- | --- | --- |
| `defaultValue` | `string` | Initial value (uncontrolled) |
| `value` | `string` | Selected value (controlled) |
| `onValueChange` | `(value: string) => void` | Called when selection changes |

### `TabsTrigger`

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `string` | (Required) id matching a panel |
| `disabled` | `boolean` | Disabled |

### `TabsContent`

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `string` | (Required) Panel to show when selected |

## Accessibility

- `role="tablist"` / `tab` / `tabpanel`, with `aria-controls` · `aria-labelledby`.
- Arrow keys / Home / End move focus.
