# Tag

Tag is a chip for keywords, categories, and filters. Use it when the user needs to see (and often remove) a selected value without opening a full form field.

`Tag` and `Chip` are the same component — either name is valid. For a non-interactive status or count, use **[Badge](/components/badge/)**.

## Interface

### Tag

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"default"` | `"default"` \| `"outline"` \| `"filled"` — Surface style. |
| `size` | `"md"` | `"sm"` \| `"md"` \| `"lg"` — Height and typography. Smaller than Button. |
| `avatar` | — | `ReactNode` — Optional leading slot (image or icon). |
| `onRemove` | — | `() => void` — When set, shows a remove button and is called when it is activated. |
| `disabled` | `false` | `boolean` — Blocks the remove button and disables pointer interaction. |

Also accepts native `span` attributes (`className`, `style`, `aria-*`).
