# Tag

Tag for filters, keywords, etc. The code export is **`Chip`**; **`Tag`** is the same component. Web Kit name: **Tag** `574:6578`.

## Install & import

```tsx
import { Tag, Chip } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Tag>React</Tag>
<Tag variant="outline" onRemove={() => {}}>
  Removable
</Tag>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `variant` | `"default"` \| `"outline"` \| `"filled"` | Style |
| `size` | `"sm"` \| `"md"` \| `"lg"` | Typography and icon |
| `avatar` | `ReactNode` | Leading slot |
| `onRemove` | `() => void` | Shows remove button when set |
| `disabled` | `boolean` | Disabled |

## Examples

### Avatar + remove

```tsx
<Tag avatar={<img src="…" alt="" width={16} height={16} />} onRemove={() => {}}>
  User
</Tag>
```
