# Tag

필터·키워드 등에 쓰는 태그입니다. 코드 export 이름은 **`Chip`**이며 **`Tag`**는 같은 컴포넌트입니다. Web Kit 이름은 **Tag** `574:6578`.

## 설치·임포트

```tsx
import { Tag, Chip } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Tag>React</Tag>
<Tag variant="outline" onRemove={() => {}}>
  제거 가능
</Tag>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `variant` | `"default"` \| `"outline"` \| `"filled"` | 스타일 |
| `size` | `"sm"` \| `"md"` \| `"lg"` | 타이포·아이콘 |
| `avatar` | `ReactNode` | 앞쪽 슬롯 |
| `onRemove` | `() => void` | 있으면 제거 버튼 |
| `disabled` | `boolean` | 비활성 |

## 예시

### 아바타 + 제거

```tsx
<Tag avatar={<img src="…" alt="" width={16} height={16} />} onRemove={() => {}}>
  사용자
</Tag>
```
