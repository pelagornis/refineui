# Textarea

Multi-line text input. Web Kit **Textarea** `529:5454`: padding **`sizeMedium` × `sizeSmall`**, min height **`controlTextareaMin`** (80px), typography **body2**. Horizontal padding may differ from Input `md` — see `docs/design-specs-web-kit.md` §2.

## Install & import

```tsx
import { Textarea } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Textarea name="bio" rows={4} placeholder="Tell us about yourself" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `error` | `boolean` | `false` | Error border |
| `success` | `boolean` | `false` | Success border |
| `fullWidth` | `boolean` | `false` | Full width |
| `disabled` | `boolean` | — | Disabled |

Remaining props follow **`TextareaHTMLAttributes`** (`rows`, `cols`, `value`, `onChange`, `maxLength`, etc.).

## Examples

### Max length

```tsx
<Textarea maxLength={500} placeholder="Up to 500 characters" />
```

### In a form

