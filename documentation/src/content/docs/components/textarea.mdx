# Textarea

Textarea is a multi-line text field. Use it when the answer is more than a single line — a bio, a comment, or notes.

Validation chrome matches **[Input](/components/input/)**. Pair it with **[Label](/components/label/)** or wrap it in **[Field](/components/field/)** for a label, hint, and error. For one line, use Input instead.

## Interface

### Textarea

| Prop | Default | Type |
|------|---------|------|
| `error` | `false` | `boolean` — Error border. Sets `aria-invalid`. |
| `success` | `false` | `boolean` — Success border. |
| `fullWidth` | `false` | `boolean` — Stretch to the parent width. |
| `disabled` | — | `boolean` — Disabled background, border, and text. |

Also accepts native `textarea` attributes (`rows`, `cols`, `value`, `onChange`, `maxLength`, `name`, `id`, `placeholder`, `aria-*`, `className`).
