# Textarea

Multi-line text field. Web Kit **Textarea** `529:5454`: padding **`sizeMedium` × `sizeXSmall`** (10×6), min height **`controlTextareaMin`** (80px), radius **`roundedLarge`**, typography **body2**. Focus, placeholder, and disabled styles pair with **`refineui.css`** `[data-refineui="textarea"]` (same interaction pattern as [Input](/components/input/)).

## Install & import

```tsx
import { Textarea } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## Basic usage

```tsx
<Textarea name="bio" rows={4} placeholder="Tell us about yourself" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `error` | `boolean` | `false` | Error border (`aria-invalid` set automatically) |
| `success` | `boolean` | `false` | Success border |
| `fullWidth` | `boolean` | `false` | Full width |
| `disabled` | `boolean` | — | Disabled background, border, and text |

Remaining props follow **`TextareaHTMLAttributes`** (`rows`, `cols`, `value`, `onChange`, `maxLength`, etc.).

## Examples

### Max length

```tsx
<Textarea maxLength={500} placeholder="Up to 500 characters" fullWidth />
```

### With validation (Field recommended)

Use `error` for the border; place messages in [Field](/components/field/) or adjacent text.

```tsx
<Textarea id="bio" name="bio" error rows={3} fullWidth />
<p role="alert">Please add a short bio.</p>
```

## Accessibility

- With `error`, `aria-invalid` is set automatically.
- Connect labels via [Label](/components/label/) or `<label htmlFor>`.
