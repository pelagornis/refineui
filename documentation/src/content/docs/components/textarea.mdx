# Textarea

여러 줄 텍스트 입력입니다. Web Kit **Textarea** `529:5454` 기준으로 패딩은 **`sizeMedium` × `sizeSmall`**, 최소 높이는 **`controlTextareaMin`(80px)**, 타이포는 **body2**입니다. Input `md`와 좌우 패딩이 다를 수 있습니다(`docs/design-specs-web-kit.md` §2).

## 설치·임포트

```tsx
import { Textarea } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Textarea name="bio" rows={4} placeholder="소개를 입력하세요" />
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `error` | `boolean` | `false` | 에러 테두리 |
| `success` | `boolean` | `false` | 성공 테두리 |
| `fullWidth` | `boolean` | `false` | 너비 100% |
| `disabled` | `boolean` | — | 비활성 |

나머지는 **`TextareaHTMLAttributes`** (`rows`, `cols`, `value`, `onChange`, `maxLength` 등)입니다.

## 예시

### 제한 길이

```tsx
<Textarea maxLength={500} placeholder="최대 500자" />
```

### 폼과 함께

```tsx
<Textarea name="comment" required rows={3} defaultValue="" />
```
