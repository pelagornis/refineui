# Toast

Transient notification message overlay.

<div class="not-content my-6">
  <ToastPreview client:load />
</div>

## Installation

```bash
bun add @refineui/react @refineui/tokens
```

## Usage

```tsx
import { Toast, Toaster, toast } from "@refineui/react";

// Add Toaster to your app root
<Toaster position="bottom-right" maxToasts={3} />

// Show a toast
toast("Settings saved successfully", {
  variant: "success",
  duration: 3000,
});

toast("Upload failed", {
  variant: "error",
  action: {
    label: "Retry",
    onClick: () => retryUpload(),
  },
});
```

### toast(title, options)

Function to show a toast programmatically.

**Options:**
- `description?: ReactNode` — Toast description
- `variant?: ToastVariant` — Visual variant
- `icon?: ReactNode` — Custom icon
- `action?: ToastAction` — Action button
- `duration?: number` — Duration in milliseconds (default 5000)
