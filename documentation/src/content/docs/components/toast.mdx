# Toast

짧은 피드백 메시지를 카드 형태로 보여 줍니다. Web Kit **Toast** `548:655`와 같이 폭 325px·패딩·**shadow4** 등을 따릅니다. **위치 고정·자동 사라짐**은 앱에서 래퍼로 구현합니다.

## 설치·임포트

```tsx
import { Toast, Button } from "@refineui/react";
```

## 기본 사용

```tsx
<Toast
  title="완료"
  message="복사되었습니다."
  variant="success"
  action={{ label: "실행 취소", onClick: () => {} }}
/>
```

## Props

| Prop | 타입 | 설명 |
|------|------|------|
| `variant` | `"default"` \| `"success"` \| `"error"` \| `"warning"` | 아이콘 액센트 |
| `title` | `ReactNode` | 제목 |
| `message` | `ReactNode` | 부가 설명 |
| `icon` / `iconName` | `ReactNode` / `string` | 왼쪽 아이콘 (우선순위: `icon` > `iconName`) |
| `action` | `ReactNode` 또는 `{ label, onClick, variant? }` | 우측 버튼 |

## 예시

### 보조 버튼

```tsx
<Toast
  title="라벨"
  message="설명"
  action={{ label: "보조", variant: "secondary", onClick: () => {} }}
/>
```

### 커스텀 아이콘

```tsx
<Toast title="메일" message="새 메시지" iconName="mail" />
```
