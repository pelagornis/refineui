# Toast

Toast is a short feedback card. Use it after an action succeeds, fails, or needs a brief undo — not for page-level status that should stay in the layout.

Mount **`<Toaster />`** once. Call **`toast()`** to push a card. For inline, persistent notices, use **[Alert](/components/alert/)**. For a blocking error the user must acknowledge, use **[Dialog](/components/dialog/)**.

## Interface

### `toast(title, options?)`

| Prop | Default | Type |
|------|---------|------|
| `title` | — | `ReactNode` — First argument. Card title. |
| `description` | — | `ReactNode` — Supporting text (`Toast` `message`). |
| `variant` | `"default"` | `"default"` \| `"success"` \| `"error"` \| `"warning"` — Accent and default icon. |
| `iconName` | — | `string` — Web Icon name when `icon` is omitted. |
| `icon` | — | `ReactNode` — Leading slot. Overrides `iconName` and the variant default. |
| `action` | — | `ReactNode` or `{ label: string; onClick?: () => void; variant?: "primary" \| "secondary" }` — Trailing control. |
| `duration` | `4200` | `number` — Milliseconds before auto-dismiss. |

Returns a `string` id for `dismissToast`.

### Toaster

| Prop | Default | Type |
|------|---------|------|
| `position` | `"top-center"` | `"top-left"` \| `"top-center"` \| `"top-right"` \| `"bottom-left"` \| `"bottom-center"` \| `"bottom-right"` — Viewport corner or edge. |
| `maxToasts` | `5` | `number` — Max concurrent cards. |
| `className` | — | `string` — Extra class on the root `<ol>`. |

### Toast

| Prop | Default | Type |
|------|---------|------|
| `variant` | `"default"` | `"default"` \| `"success"` \| `"error"` \| `"warning"` — Same as `toast()` options. |
| `title` | — | `ReactNode` — Title line. |
| `message` | — | `ReactNode` — Supporting text. |
| `iconName` | — | `string` — Icon name. Precedence: `icon` > `iconName` > variant default. |
| `icon` | — | `ReactNode` — Leading slot. |
| `action` | — | Same as `toast()` `action`. |
| `stackState` | — | `"entering"` \| `"idle"` \| `"leaving"` — Set by `Toaster`. Do not set this yourself. |

Also accepts native `div` attributes (`className`, `style`).
