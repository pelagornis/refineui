# Toast

Short feedback as a card matching **Web Kit Toast** `548:655` (width 325px, card padding `sizeLarge`, row gap `sizeMedium`, body column `sizeXSmall`, **shadow 4**, card radius **`roundedXLarge`**). `<Toaster />` renders a fixed viewport `<ol>` of `<li>` items; use **`position`** for `top-left` · `top-center` · `top-right` · `bottom-left` · `bottom-center` · `bottom-right` (default `top-center`). **Default stacking is collapsed like Sonner**; **hovering the `<ol>`** expands the stack vertically at even spacing.

## Install & import

```tsx
import { Toaster, toast, Button, Spinner, Avatar, AvatarImage } from "@refineui/react";
```

## Basic usage

```tsx
<Toaster position="top-center" />
<Button
  onClick={() =>
    toast("Done", {
      variant: "success",
      description: "Copied to clipboard.",
      action: { label: "Action", onClick: () => {} },
    })
  }
>
  Show Toast
</Button>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `variant` | `"default"` \| `"success"` \| `"error"` \| `"warning"` | Figma **Type** — default icon/color; root gets `data-variant` |
| `title` | `ReactNode` | Title |
| `message` | `ReactNode` | Supporting text |
| `icon` / `iconName` | `ReactNode` / `string` | **Toast / Icon** slot (`data-refineui="toast-icon"`); precedence: `icon` > `iconName` > variant default |
| `action` | `ReactNode` or `{ label, onClick, variant? }` | Right-side button |
| `stackState` | `"entering"` \| `"idle"` \| `"leaving"` | Set internally by `<Toaster>` only |

### `<Toaster />`

| Prop | Type | Description |
|------|------|-------------|
| `position` | `ToastPosition` | Default `top-center` — `top-left` \| `top-center` \| `top-right` \| `bottom-left` \| `bottom-center` \| `bottom-right` |
| `maxToasts` | `number` | Max concurrent toasts (default 5) |
| `className` | `string` | Extra class on root `<ol>` |

### Mobile

`refineui.css` uses **expanded stack** and **full scale** when **`(hover: none)` or `(pointer: coarse)`** instead of hover-expand, and `env(safe-area-inset-*)` for notches and home indicators. Below `max-width: 480px`, container inset, card padding, and row gap shrink via tokens; `Toaster` computes stack spacing with `sizeMedium`. For safe-area with notches, include `viewport-fit=cover` in your viewport meta tag.

## Examples

### Secondary action

```tsx
<Toast
  title="Label"
  message="Description"
  action={{ label: "Secondary", variant: "secondary", onClick: () => {} }}
/>
```

### Custom icon

```tsx
<Toast title="Mail" message="New message" iconName="mail" />
```

### Leading Spinner / Avatar (`toast` `icon` option)

Pass `icon` in `toast()` options. Forward `Spinner`, `Avatar`, etc. from `@refineui/react` directly.

```tsx
toast("Syncing", {
  description: "Processing…",
  icon: <Spinner size="xs" />,
});

toast("New message", {
  description: "From sender",
  icon: (
    <Avatar size="xs" layout="image" color="neutral" aria-hidden>
      <AvatarImage src="https://example.com/photo.png" alt="" />
    </Avatar>
  ),
});
```
