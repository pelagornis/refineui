# Toggle

Switches a two-state setting on or off.

## Installation

```bash
bun add @refineui/react @refineui/tokens
```

## Usage

```tsx
import { Toggle } from "@refineui/react";

<Toggle checked={isEnabled} onCheckedChange={setIsEnabled} />
```
