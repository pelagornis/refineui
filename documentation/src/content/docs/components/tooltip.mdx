# Tooltip

Tooltip shows a short hint next to a control on hover or focus. Use it to name an icon-only button, echo a shortcut, or clarify a truncated label.

It is not a place to put fields, links, or actions. For a click-opened panel, use **[Popover](/components/popover/)**. For a blocking explanation, use **[Dialog](/components/dialog/)**.

## Interface

### Tooltip

| Prop | Default | Type |
|------|---------|------|
| `trigger` | — | `ReactNode` — Target element. Required. |
| `content` | — | `ReactNode` — Tooltip body. Required. |
| `position` | `"Bottom"` | `"Top"` \| `"Bottom"` \| `"Left"` \| `"Right"` — Side of the trigger. |
| `align` | `"Start"` | `"Start"` \| `"Center"` \| `"End"` — Alignment along that side. |
| `delayMs` | `120` | `number` — Milliseconds before show. |
| `open` | — | `boolean` — Controlled visibility. |
| `defaultOpen` | `false` | `boolean` — Uncontrolled initial visibility. |
| `onOpenChange` | — | `(open: boolean) => void` — Called when visibility changes. |

Also accepts native `div` attributes (`className`, `style`).
