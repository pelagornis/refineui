# Tooltip

트리거에 마우스를 올리거나 포커스하면 설명을 띄웁니다. Web Kit **Tooltip** `90:1686`과 같이 패딩·`roundedMedium`·**body4**·**shadow8**을 따릅니다. Figma에는 **`position`×`align`** 12가지 조합이 있으나, React는 **`placement`** 네 방향만 지원합니다.

## 설치·임포트

```tsx
import { Tooltip, Button } from "@refineui/react";
import "@refineui/react/refineui.css";
```

## 기본 사용

```tsx
<Tooltip trigger={<Button variant="secondary">저장</Button>} content="⌘S로 저장" placement="top" />
```

## Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `trigger` | `ReactNode` | (필수) | 대상 요소 |
| `content` | `ReactNode` | (필수) | 툴팁 내용 |
| `placement` | `"top"` \| `"bottom"` \| `"left"` \| `"right"` | `"top"` | 방향 |
| `variant` | `"default"` \| `"inverted"` | `"default"` | 밝은 / 어두운 |
| `delayMs` | `number` | `120` | 표시 전 지연(ms) |

## 예시

### 키보드 포커스

```tsx
<Tooltip trigger={<Button variant="secondary">포커스</Button>} content="Tab으로 포커스 시에도 표시" />
```

### 아래쪽

```tsx
<Tooltip trigger={<span>링크</span>} content="설명" placement="bottom" />
```
