## Usage

```tsx
import { Tree, TreeItem, TreeItemContent, TreeItemTrigger } from "@refineui/react";

<Tree defaultExpanded={["src"]} defaultSelected="button">
  <TreeItem value="src">
    <TreeItemTrigger>src</TreeItemTrigger>
    <TreeItemContent>
      <TreeItem value="button">
        <TreeItemTrigger>Button.tsx</TreeItemTrigger>
      </TreeItem>
    </TreeItemContent>
  </TreeItem>
  <TreeItem value="package">
    <TreeItemTrigger>package.json</TreeItemTrigger>
  </TreeItem>
</Tree>
```

Built from Foundation spacing, radius, color aliases, and typography tokens (same density as Sidebar / Menu). Chevron expands branches; row click selects. Arrow keys follow the WAI-ARIA tree pattern.

### TreeItemTrigger

Focusable row label. Shows a chevron when the item has `TreeItemContent`.

### TreeItemContent

Nested `TreeItem` group. Mounted only while the parent is expanded.
