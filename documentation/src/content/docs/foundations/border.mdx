# Border

Stroke widths are Foundation keys. Default UI chrome uses `strokeWidthThin`. Border **color** comes from color aliases (`borderDefault`, `borderSubtle`, `borderFocus`), not from this scale.

## Usage

```tsx
<Box
  border="strokeWidthThin"
  borderColor="borderDefault"
  radius="roundedLarge"
  padding="sizeLarge"
  background="backgroundSurface"
>
  Outlined surface
</Box>
```
