# Color

Paint UI with **aliases** (`foregroundPrimary`, `backgroundBrand`). The palette is the Foundation source those aliases point at for light and dark. Do not paste hex or `colors.neutral900` into product UI.

`surfaceOverlay` is the modal scrim — Foundation RGBA, not a palette pair (`--refineui-color-alias-surface-overlay`).

## Aliases

Live CSS variables. Caption is `light / dark` palette keys.
