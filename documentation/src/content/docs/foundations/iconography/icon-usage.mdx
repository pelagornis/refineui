# Icon usage

## When to use

- Reinforce a label (search field leading icon, button with prefix glyph)
- Icon-only actions in dense toolbars (must have an accessible name)
- Status or affordance cues next to text (external link, chevron)

## When not to use

- As the only way to convey critical meaning without a text label
- Decorative clutter next to every heading

## Pairing

- Keep a token gap between icon and label (`sizeXXSmall` / `sizeXSmall`).
- Vertically center icons with the text line; do not offset with magic pixels.
- In buttons, prefer the component’s `layout="icon"` for icon-only, or children with `WebIcon` for label + icon.
