RefineUI ships system icons via `@refineui/web-icons` and the `WebIcon` component from `@refineui/react`.

## Install

```bash
bun add @refineui/web-icons
```

Import the icon font stylesheet once (docs and apps already do this alongside `refineui.css`).

## Usage

```tsx
import { iconSizes } from "@refineui/tokens";
import { WebIcon } from "@refineui/react";

<WebIcon name="search" size={iconSizes.small} color="currentColor" aria-hidden />
```

Use the `name` string that matches the glyph set. Prefer `currentColor` so icons inherit the surrounding text / button color tokens.
