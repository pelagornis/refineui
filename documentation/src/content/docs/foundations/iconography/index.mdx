Icons are vector glyphs from `@refineui/web-icons`, rendered through `WebIcon` (and component slots that accept icon children). Sizes come from `iconSizes` in `@refineui/tokens` — not from font size.

## Topics

- [Icons](/foundations/iconography/icons/) — Package and naming
- [Icon usage](/foundations/iconography/icon-usage/) — Pairing, contrast, and accessibility

## Quick rules

1. Use semantic color on icons (`currentColor` or foreground aliases), not palette hex.
2. Match icon size to the control (`iconSizes.small` next to `body` / button `sm`–`md`).
3. Decorative icons need `aria-hidden`; actionable icon-only buttons need an accessible name.
