# Foundations

Foundations are the shared visual and interaction language for Pelagornis products. Product UI consumes **semantic tokens** from `@refineui/tokens` — not raw hex, arbitrary pixels, or one-off curves.

## Areas

- **[Design tokens](/foundations/design-tokens/)** — Color, typography, spacing, sizing, radius, border, elevation, opacity, motion, and z-index.
- **[Layout](/foundations/layout/)** — Spatial rhythm, containers, grids, alignment, and responsive rules.
- **[Iconography](/foundations/iconography/)** — Glyph sizes, optical rules, and how icons sit next to text.

Layout primitives you compose in React live under **[Components → Layout](/components/stack/)**.
