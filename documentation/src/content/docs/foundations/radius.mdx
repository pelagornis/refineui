# Radius

Corners are Foundation keys (`roundedLarge`, `roundedXXLarge`). `roundedCircle` is the pill / full round.

## Usage

```tsx
<Box
  padding="sizeLarge"
  radius="roundedXLarge"
  border="strokeWidthThin"
  borderColor="borderDefault"
  background="backgroundSurface"
>
  Rounded surface
</Box>
```
