# Introduction to RefineUI

RefineUI is the unified design system for Pelagornis products. It provides a visual-first design language for designers, a code-first component library for developers, and first-class support for AI integration.

## Design System Architecture

- **[Foundations](/foundations/)**: Visual language, design tokens (colors, typography, spacing, elevation, motion), responsive layout, and iconography.
- **[Components](/components/)**: Visual-first component building blocks categorized semantically (`Actions`, `Forms`, `Navigation`, `Feedback`, `Overlays`, `Data Display`, `Content`, `Layout`).
- **[Development](/development/)**: Installation, theming, and motion in product code.
- **[AI Integration](/ai-integration/)**: Integration guide for AI coding assistants such as Cursor, Claude, and GitHub Copilot using `llm.txt`.

## Getting Started

Start with the [Getting Started guide](/intro/) to install RefineUI and build your first component.
