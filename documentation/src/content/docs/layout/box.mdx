# Box

Box is a surface. Use it when a region needs padding, a semantic fill, radius, and an optional border — all Foundation tokens. It does not add layout on its own; put a **[Stack](/layout/stack/)** or **[Grid](/layout/grid/)** inside.

For page-level horizontal inset with no fill, use **[Container](/layout/container/)**.

## Interface

| Prop | Default | Type |
|------|---------|------|
| `padding` | — | Foundation spacing key — Padding on all sides. |
| `paddingX` | — | Foundation spacing key — Inline padding. Overrides `padding` on that axis. |
| `paddingY` | — | Foundation spacing key — Block padding. Overrides `padding` on that axis. |
| `background` | — | Semantic `background*` / `surface*` color name. |
| `radius` | — | Foundation radius key (`roundedNone` … `roundedCircle`). |
| `border` | — | Foundation stroke width. When set without `borderColor`, color is `borderDefault`. |
| `borderColor` | — | Semantic `border*` color name. |
| `as` | `div` | Element type to render. |
