# Container

Container centers a full-width column and applies Foundation padding on the inline axis so page content does not sit on the viewport edges. There is no max-width token in Foundation yet — width follows the parent.

Use **[Box](/layout/box/)** when you need a surface (fill, radius, border), not page inset. Use **[Stack](/layout/stack/)** for the content inside.

## Interface

| Prop | Default | Type |
|------|---------|------|
| `padding` | `sizeXXLarge` | Foundation spacing key — Horizontal (inline) padding. |
| `as` | `div` | Element type to render. |
