# Grid

Grid places children on two axes. Use equal `columns` for a fixed track count, `GridItem` `span` to merge cells, or `minItem` so tracks wrap by a Foundation size.

For a single row or column, use **[Stack](/layout/stack/)**.

## Interface

### Grid

| Prop | Default | Type |
|------|---------|------|
| `columns` | — | `number` — Equal column tracks. Ignored when `minItem` is set. |
| `minItem` | — | Foundation size name — Minimum track width; auto-fits and wraps. |
| `gap` | — | Foundation spacing key — Row and column gap. |
| `columnGap` | — | Foundation spacing key — Overrides `gap` on columns. |
| `rowGap` | — | Foundation spacing key — Overrides `gap` on rows. |
| `align` | — | `"start"` \| `"center"` \| `"end"` \| `"stretch"` \| `"baseline"` |
| `justify` | — | `"start"` \| `"center"` \| `"end"` \| `"between"` \| `"around"` \| `"evenly"` |
| `as` | `div` | Element type to render. |

### GridItem

| Prop | Default | Type |
|------|---------|------|
| `span` | — | `number` (1–12) — Column tracks to occupy. |
| `rowSpan` | — | `number` (1–12) — Row tracks to occupy. |
| `as` | `div` | Element type to render. |
